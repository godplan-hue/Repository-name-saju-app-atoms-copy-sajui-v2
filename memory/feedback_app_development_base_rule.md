## 규칙: 앱 개발은 항상 기존 웹앱 기반으로

**절대 처음부터 새로 만들지 않는다.** 기존 jeomun.com 웹앱(Next.js)에 이미 있는 기능을 기반으로 확장한다.

**Why:** 새로 만들면 중복 개발 + 유지보수 비용 2배. 기존 코드가 이미 검증됨.

**How to apply:**
1. 기존 웹앱(`/gamjung`, `/momcare`, `/jigun` 등)에서 핵심 로직 확인
2. 결과지에 유료 콘텐츠 추가 (치유 카드 뽑기, 심층 코칭, 루틴 추천 등)
3. 요즘 인기 있는 기능(트렌드) 조사해서 추가
4. 토스 앱은 동일 개념을 `.ait`로 포팅하는 방식 (완전 새 개발 아님)

**유료 업그레이드 패턴 (결과지에 추가):**
- 🎴 카드 뽑기 (치유 메시지, 오행별 8장)
- 💡 심층 분석 (오행 코칭, 상황별 조언)
- 🛁 5분 셀프케어 루틴 (음악/음식/활동 3종 세트)
- 📊 나도 해보기 → 버튼 (바이럴 CTA, 모든 결과지 하단에 필수)
