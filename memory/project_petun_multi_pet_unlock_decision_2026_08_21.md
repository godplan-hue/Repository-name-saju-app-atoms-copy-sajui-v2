**현상**: 펫운(petun)에서 결제 후 24시간 동안, 같은 전화번호로 강아지 이름만 바꿔서 여러 번 새로 제출해도 전부 잠금해제된 결과가 보임. 다른 유료앱들(MBTI 등)과 동일하게 "번호 기준 24시간" 방식이라 특정 반려동물 1마리에만 결제가 묶이지 않음.

**결정**: 고치지 않고 그대로 둔다.

**Why**: 에스더님 본인도 반려동물을 키우고 있어서 반려동물 관련 지출이 많다는 걸 알고 있음 — "강아지 나도 키우는데 돈 많이 드니 여러마리 해봐도 그냥 두자"는 취지로 의도적으로 관대하게 두기로 결정. 버그가 아니라 제품 정책 결정.

**How to apply**: 펫운 잠금 로직(`app/petun/`) 관련 작업 시 이 부분을 "고쳐야 할 버그"로 착각해서 임의로 강아지별 결제 강제하는 코드 추가하지 말 것. 궁합·별자리 결제-스킵 버그 수정([[bug_gunghap_zodiac_skip_to_result_2026_08_21]])과는 별개 사안임.
