## 사주아이 강의 (유저가 직접 구매 후 분석)

- 슬라이드 15개 올렸고, 절반만 분석 완료
- **홍보 섹션(마지막)**: 2026년 7월 16일 & 8월 7일 최종 오픈 예정
- **결정**: 홍보 강의 먼저 보고 나서 SEO/서브도메인 전략 재정립하기로 함

### 강의에서 뽑은 핵심 인사이트

- **타겟**: 2030세대. 그들의 언어, 궁금증, 불편함 해소하는 방식
- **구식 말투 금지**: 젊은 세대 구어체, 이모지, 존댓말 X
- **락인 전략**: 사람들이 궁금하게 만들어서 계속 넘어가다 결제하는 구조
- **가격 전략**: 990원 저가 진입 → 추가 구매 유도
- **키워드 반응**: "사주"보다 **"990원 사주", "고양이 사주"에 더 크게 반응**
- **브랜드 검색량**: 사주아이 브랜드 검색량이 "사주" 일반 검색량을 뛰어넘음 → 콘텐츠 재미로 브랜드 자체를 검색하게 만든 것
- **공유 바이럴 구조**: 결과 공유하게 만들어서 자연 유입
- **고양이 컨셉**: 브랜드 정체성의 핵심

## 사주아이 UI/UX 방식

채팅 스타일 — 고양이가 먼저 말 걸고, 개인화된 질문 3개 먼저 제안:
> "안녕하세요, 문정님! 기분 좋은 토요일 저녁이네요. 바쁘게 일상을 보내시느라 고생 많으셨을 텐데, 오늘 밤은 복냥이와 함께 문정님의 흐름을 차분히 짚어보는 시간 가져볼까요?"
> - "자영업자로서 올해 하반기 금전 흐름은 어떻게 변화할까요?"
> - "50대 중반을 앞두고 지금 준비하는 새로운 일의 성과가 궁금해요."
> - "결혼 생활 속에서 지금 제 마음의 평안을 위해 무엇을 우선해야 할까요?"

→ 우리는 채팅 UI로 전환 완료. 하지만 **개인화된 첫 질문 3개 자동 제안**은 아직 미구현.

## Q&A 구조 설계 (논의 과정)

- 처음엔 카테고리 5개 × 20개로 시작
- 자녀운, 사업운 추가 요청 → 9개 카테고리 확정
- 30개는 너무 적다 → **40개씩으로 확정**
- 오행 5타입 답변 분기 추가 → **40문항 × 5오행 = 총 1,800개 답변**
- 무료 5개 공개 → 나머지 유료 잠금 방식

**9개 카테고리 확정:**
재물운 / 연애운 / 결혼운 / 사업운 / 직업운 / 성공운 / 건강운 / 자녀운 / 일반운세

## 홍보/마케팅 전략 (논의됨, 홍보 강의 본 후 재정립 예정)

### 앱스토어 ASO
- 앱스토어 표시 이름: **점운 - AI 사주풀이**
- 부제목 + 설명에 "사주", "990원 사주", "고양이 사주", "궁합" 키워드 반드시 포함
- 앱 이름만 바꾸는 게 아니라 부제목/설명 키워드 최적화가 핵심

### 바이럴 전략
- 결과 공유 → 자연 유입 (공유 기능 이미 있음)
- 연예인 사주, 팬과 아이돌 궁합 같은 2차 콘텐츠 → X(트위터) 팬덤 커뮤니티 확산 설계
- MZ세대 언어로 Q&A 질문 재작성

### SEO/블로그 전략
- 블로그 수백~1,000개 (각 키워드별 랜딩 페이지)
- 유튜브 쇼츠, 카카오채널 병행
- SNS 매일 꾸준히 쌓기

### 서브도메인 SEO 전략
- 앱 하나로 여러 서브도메인 운영 (파트너 서브도메인과 완전 분리, 내 홍보용)
- 예: `사주.jeomun.com`, `990원사주.jeomun.com`, `고양이사주.jeomun.com`
- 기술: Next.js에서 `hostname` 읽어서 랜딩 페이지 콘텐츠만 다르게 보여줌
- 파트너 서브도메인과 완전 분리
- **홍보 강의 보고 나서 전략 구체화하기로 결정**
