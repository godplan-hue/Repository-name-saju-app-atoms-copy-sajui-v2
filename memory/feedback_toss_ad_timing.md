## 광고 구조 확정 (에스더님 + AI 가이드 기반, 2026-07-25 재정비)

### ✅ 확정 광고 구조 (3단계)

| 순서 | 타이밍 | 유형 | 이유 |
|---|---|---|---|
| 1 | 무료 결과 진입 직후 1초 | 전면광고 (자동) | 가이드: "무료 결과 누른 후 1회" — 가장 자연스러운 위치 |
| 2 | 유료 결과 보기 버튼 | 리워드 (선택) | 가이드: "사용자가 선택한 광고 — 수용도 최고" |
| 3 | ~~유료 결과 50초 후~~ | ~~전면광고 (자동)~~ | ❌ 삭제 — 가이드: "읽는 도중 자동 광고 = 만족도 최대 하락" |

**자동 1번 + 선택 1번 = 총 2번** (Toss 심사 안전, 이탈률 최소)

---

### ❌ 하지 말 것 (가이드 기준)

- 앱 실행 즉시 광고 뜨는 것 → 이탈률 급등
- 결과 보기 전 광고 2회 연속 (입력후 + 결과전 동시에 넣는 것)
- 결과 읽는 도중 자동 전면광고 (유료결과 50초 후 — 삭제함)
- 버튼 누를 때마다 광고

---

### ✅ 해도 되는 것 (가이드 기준 ⭐⭐⭐)

- 앱 실행 후 10~30초 뒤 전면광고 1회 (입력 완료 후 뜨게 하면 OK)
- 추가 기능 사용할 때 1회 (다른 앱/기능으로 넘어갈 때)

---

### 리워드 광고 7초 fallback + 자동 결과지 복귀 (2026-07-26 최종 확정)

```typescript
const fallbackTimer = setTimeout(() => {
  setAdWatching(false); // 버튼 잠금 해제 → 결과지로 자동 복귀
  reloadRewardAd();     // 다음 광고 미리 로드
}, 7000); // 7초
```

- **7초**: 리워드 콜백이 안 오거나 광고 간 버튼이 먹통될 때 자동으로 결과지로 돌아감
- 이전 20초 → 7초로 확정 (에스더님이 "7초 때문에 다른 광고 버튼이 안 눌러진 게 맞았어" 확인)
- 광고 시청 완료 후 다음 섹션 버튼이 먹통되던 버그의 원인이 이 타임아웃이었음
- **전체 앱 동일 적용 (MBTI/다이어트/감정일기)** — 새 앱도 동일하게 사용
- 리뷰 보상: **전체 앱 1회만 가능** (reviewClaimed Toss Storage 키로 관리, 이미 전체 앱 적용 완료)
