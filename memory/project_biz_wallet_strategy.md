## 핵심 전략 (에스더님 직접 확정)

**비즈 월렛 = 미니앱 홍보 최적 방법**

1. 비즈 월렛 충전 (최소 5만원, 2026-08-12부터)
2. 미션 조건: 전화번호 입력(가입) 완료 시 100포인트(100원) 지급
3. 토스 혜택탭에 점운 앱 배너 노출 → 3000만 유저에게 브랜드 노출
4. 가입한 사람만 100원 지급 → 클릭만 한 사람은 비용 없음
5. 들어온 유저 모두 인앱 광고(배너/전면) 봄 → 광고 수익 발생
6. 광고 수익으로 포인트 비용 상쇄 → 결국 무료 홍보

## 핵심 구조

```
비즈 월렛 30만원 투자
  → 혜택탭 배너 노출 (3000만 유저 노출)
  → 유저 클릭해서 앱 진입
  → 가입(전화번호 입력) 시 100원 지급
  → 가입 안 해도 인앱 광고 수익 발생
  → 광고 수익으로 투자비 회수
  → 결과: 무료 광고 + 가입자 확보
```

## 왜 이득인가

- 가입 안 한 사람: 포인트 미지급 + 광고 수익 발생 → 우리 이득
- 가입한 사람: 100원 지급 + 광고 수익 발생 → 광고 수익이 100원 상쇄
- 예산 소진 천천히 됨 → 혜택탭 노출 기간 길어짐
- 한달 무료 광고판 효과

## ⭐⭐⭐ 2026-08-17 확정 — 실제 필요한 코드 + 다이어트 실패 원인 최종 확인

**다이어트 프로모션 스크린샷으로 실패 원인 확정**: "왜 나만 살이 안빠질까" 프로모션 — 상태 종료됨, 소진율 0.0%, 예산 0/50,000원, 종료일 2026.08.18. 예산이 단 1원도 안 나간 채 종료됨 → 앱 코드에 리워드 지급 함수가 없어서 아무도 포인트를 못 받았다는 뜻. [[feedback_diet_app_no_touch]]에 적힌 "grantPromotionReward 코드 자체가 앱에 없었다"는 진단과 정확히 일치.

**MBTI도 동일 문제로 확인됨** (2026-08-17, `jeomun-mbti/src` 전체 grep): `grantPromotionReward`/`promotionCode` 관련 코드 0건. dist 빌드 파일에만 SDK 흔적이 있을 뿐, 앱이 실제로 호출하는 코드는 없음. **즉 다이어트뿐 아니라 지금 만들어둔 어떤 프로모션도(다이어트/MBTI 둘 다) 코드 추가 전엔 절대 작동 안 함.**

**앱인토스 공식 문서로 확인한 정확한 API** (`developers-apps-in-toss.toss.im`):
```js
// 호출 전 반드시 지원 여부 체크
if (Promotion.grantReward.isSupported()) {
  const result = await Promotion.grantReward({
    promotionCode: "PROMOTION_CODE",  // 필수, 콘솔에서 발급된 코드. 없으면 에러코드 4100
    amount: 1000,                       // 지급할 포인트(원) 금액
  });
  console.log("포인트 지급 성공", result.key);
}
```
- 토스앱 **5.232.0 이상**에서만 동작
- **테스트 코드**: 콘솔 프로모션 상세페이지에 `TEST_{프로모션코드}` 형식으로 별도 발급됨 (다이어트 프로모션 실제 확인: `TEST_01KZG6GW5QX3PFH70TP9C5HAR5`, 실제 코드는 `01KZG6GW5QX3PFH70TP9C5HAR5`) — 이 TEST_ 코드로 `grantReward` 호출하면 실제 포인트 차감 없이 지급 로직만 테스트 가능

**결론/다음 순서**: 프로모션을 "다시 돌리기" 전에 반드시 ①해당 앱 소스에 `Promotion.grantReward` 호출 코드 추가 → ②TEST_ 코드로 먼저 테스트 성공 확인 → ③실제 프로모션 코드로 전환·시작 순서를 지켜야 함. 코드 추가 없이 예산만 충전하면 다이어트와 똑같이 소진율 0%로 끝남.

**프로모션 재충전/재검수 여부**: 앱인토스 공식 문서 어디에도 명시 안 됨 — 문서로 확인 불가한 부분이라 앱인토스 고객센터에 직접 문의 필요 (추측 금지).

## ⭐⭐⭐ 2026-08-21 확정 — 월렛 노출 앱 최종 4개로 확정, 나머지는 안 함

에스더님 직접 결정: "합격자소서·직운 이거두개만더하자나중애 다른건 일단빼자 너무힘드니 4개만노출시켜도될듯"

- **월렛 프로모션 설치 대상 최종 확정 = 4개 앱만**: 다이어트, MBTI(이미 완료) + 합격자소서(resume), 직운(jigun) **나중에 추가 예정**
- 나머지 13개 앱(사주·꿈해몽·맘케어·감정일기·가계부·궁합·행운번호·펫운·택일·대운·타로·별자리 등)은 **월렛 프로모션 설치 안 함** — 앱마다 코드 추가+TEST_코드 테스트+서류 작업이 너무 힘들어서 여기서 스코프 확정, 더 이상 늘리지 않기로 함
- **지금 당장 착수 아님** — "나중에" 하기로 함. 합격자소서·직운 월렛 작업은 에스더님이 먼저 꺼낼 때 시작할 것, 먼저 제안하지 말 것
- 시작할 때는 위 "순서" 섹션 그대로 따를 것: promotionCode 발급 → 코드 추가 → TEST_ 테스트 성공 → 시작하기

**Why:** 설치 노력 대비 효과를 고려해 결제 매출이 실제로 나는 앱 위주로만 하기로 판단. 4개면 충분하다고 결론.
