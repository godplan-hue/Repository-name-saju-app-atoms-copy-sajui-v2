## 핵심 요약

- **수익 공식**: 예상 수익 = 노출 수 × eCPM ÷ 1,000
- **예시**: 10만 노출 × eCPM 5,000원 = 50만원
- **출시 첫날부터** 광고 수익 시작 가능 (결제 기능 없어도)
- **3종 조합이 최고**: 배너 + 전면형 + 리워드 함께 써야 수익 극대화

---

## 광고 3종 비교

| 유형 | 노출 수 | eCPM | 특징 | 추천 위치 |
|---|---|---|---|---|
| **배너** | 가장 많음 | 가장 낮음 | 항상 고정 노출, 자동 누적 | 메인화면, 리스트화면 |
| **전면형** | 중간 | 중간 | 강제 노출 (스킵 가능) | 화면 전환 직전·직후, 결과화면 |
| **리워드** | 낮음 | 가장 높음 | 자발적 시청, 집중도 최고 | 잠금해제, 추가 혜택, "광고 보고 혜택" |

## 절대 하면 안 되는 것 (정책 위반 → 제재)

- 광고 클릭 즉시 보상 제공 ("광고 클릭하면 포인트") ← **즉시 제재**
- 동일 화면에 같은 포맷 광고 2개 이상 배치
- 광고를 콘텐츠처럼 위장 ("추천 서비스" 등)
- SDK Click/Impression 이벤트 변조
- 광고 영역 주기적 Refresh
- 사용자가 광고 종료 못 하게 막는 구조
- 결제/중요 흐름 중 광고 삽입
- **운영 ID로 테스트** (반드시 테스트 ID 사용)

## 광고 그룹 생성 방법

1. 콘솔 → 미니앱 선택 → 인앱 광고 메뉴
2. 광고 그룹 이름: **유형+위치 함께** (예: 메인_전면광고, 게임종료_리워드광고)
3. 광고 유형 선택 (배너/전면형/리워드)
4. 리워드: 보상 이름+수량 입력 (사용자 화면에 표시됨)
5. 미디에이션: 여러 광고 네트워크 자동 선택 (수익 최적화)
6. 생성 후 **광고 그룹 ID 확인** → 코드에 적용
7. ⚠️ **광고 그룹 ID 구글 등록까지 최대 2시간 걸림**

- 다음달 말일에 입금
- 성과 데이터: **매일 오전 10시 업데이트**

## 분석 탭 활용법

### 광고 노출 현황 (4단계)
1. 광고 요청 → 2. 광고 수신 → 3. 노출 시도 → 4. 노출 성공

- **요청 대비 수신 낮음**: 광고 네트워크에 채울 광고 부족 (No Fill)
- **수신 대비 시도 낮음**: load와 show 호출 타이밍 확인
- **시도 대비 성공 낮음**: SDK 버전·호출 순서 점검

### 수익 최적화 팁
- 노출 빈도 올랐는데 eCPM 떨어지면 → **광고 피로도 과다**
- 리워드 eCPM > 전면형 > 배너 순
- 비중 높은데 eCPM 낮은 유형 → 배치 줄이고 eCPM 높은 유형으로 교체

### ⚠️ 배너 광고 분석 미지원
- "배너 광고는 아직 지원되지 않아요" = **분석 탭에서 배너 eCPM 차트가 아직 안 나옴**
- 배너 광고 자체는 정상 작동 / 분석 데이터만 미지원
- SDK 2.7.0 이상 업데이트해야 분석 데이터 수집 시작

## 개발 연동 주의사항

- 광고 너무 자주 노출 금지 (사용자 경험 저하)
- 테스트는 반드시 **테스트 ID** 사용 (운영 ID 테스트 = 제재)
- 광고 재생 중 앱 사운드 일시정지 → 광고 종료 후 자동 재생
- 배너(WebView): WebView SDK 초기화 + 부착 + 이벤트 콜백
- 배너(React Native): InlineAd 컴포넌트 사용
