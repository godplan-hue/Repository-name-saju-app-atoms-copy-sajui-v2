## 실패 경험 (2026-07-28)

- 토스애즈 네이티브 광고 집행 → 4만원 소진, 유입 0명
- 원인: 미니앱 URL 랜딩 연결 안 됨 + 전환 추적 코드 없음
- CTR은 높았으나 실제 앱 유입 없음
- 잔여 비즈머니: 5만9천원 (일단 유지 — 나중에 jeomun.com 웹 광고 픽셀 연동 후 사용)

## 핵심 교훈

- **토스애즈로 미니앱 직접 연결 = 안 됨** (MMP/App Scheme 없음)
- 토스애즈는 jeomun.com(웹사이트) 광고용 — 픽셀 연동 필수
- 픽셀 없이 돌리면 유입 추적 불가, 데이터 없음
- 광고 전에 반드시: 픽셀 연동 → 소액 테스트 → 확인 후 증액

## 토스애즈 잔여 예산 활용 계획

- 5만9천원 그대로 유지
- jeomun.com에 토스 픽셀 코드 심은 후 웹사이트 광고로 재활용
- 랜딩 URL = jeomun.com, 전환 추적 픽셀 연동 필수
- 실행 시기: 포트원 KCP 카드 결제 승인 후 (결제 퍼널 완성 후)

## 올바른 미니앱 홍보 방법

**토스애즈 X → 비즈 월렛 프로모션 O**

토스애즈는 외부 광고라 미니앱 직접 연결이 어렵고,
비즈 월렛은 토스 앱 내부 시스템이라 연결 문제 없음.
