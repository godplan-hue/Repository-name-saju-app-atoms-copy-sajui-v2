# 토스 앱 홍보 비법 — 경쟁사 분석 기반 (2026-07-30)

> 에스더님이 루나 타로점·마스터즈 타로·날씨일기 직접 써보고 정리한 전략.
> 새 세션에서 토스 앱 작업 전 반드시 읽을 것.

**Why:** 토스 앱인토스 유저 0명 문제 해결 + 광고 수익 극대화를 위해 경쟁사 패턴 분석
**How to apply:** 아래 4개 전략을 토스 앱 전체에 순차 적용

---

## 경쟁사 분석 요약

| 앱 | 핵심 발견 |
|---|---|
| 루나 타로점 | 닫기 누를 때마다 광고 반복 → 유저 이탈, UX 최악 |
| 마스터즈 타로 | "오늘 49명이 확인했어요" 카운터 + 캐릭터 선택 + 고민 텍스트 입력 |
| 날씨일기 | 코인 시스템(최대 200원 광고, 실제 40원) + 출석 스트릭 + 게이지 채우기 |

## 전략 1: "오늘 N명이 확인했어요" 자동 카운터

**원칙:** 날짜 시드(seed)로 매일 자동으로 다른 숫자 → 새로고침해도 같은 숫자

```javascript
const getTodayCount = () => {
  const today = new Date();
  const seed = today.getFullYear() * 10000 + (today.getMonth()+1) * 100 + today.getDate();
  const lcg = Math.abs((seed * 1664525 + 1013904223) & 0x7fffffff);
  const count = 1200 + (lcg % 2800); // 1,200 ~ 4,000 사이
  return count.toLocaleString(); // "2,847" 형식
};
```

**표시 문구:** `오늘 ${getTodayCount()}명이 확인했어요 ✨`
**적용 위치:** 모든 토스 앱 메인 상단
**효과:** 사회적 증거(소셜 프루프) → 신뢰도 상승 → 전환율 상승

---

## 전략 2: 나갈 때 광고 2번 (유입 광고비 회수)

**논리:**
```
외부광고로 유입 → 사용 → 나가려고 닫기 누름
                              ↓
                         전면광고 1번
                         닫기 누름
                         전면광고 1번 더
                         → 실제 종료
```

**핵심:** 광고로 들어온 유저 = 어차피 나갈 유저 → 나갈 때 광고 2번 = 광고비 일부 회수
**주의:** 3번은 에스더님도 바로 이탈 → 2번이 최적
**구현:** 뒤로가기/닫기 액션에 interstitial 트리거 (앱 정식 종료 시는 광고 없음)

## 전략 3: 코인 시스템 (리텐션 + 광고 수익 동시)

**날씨일기 벤치마킹:** "최대 200원" 광고 → 실제 40원 지급 → 유저 불만 없음
**우리 적용:** 앱 내 가상 코인 (돈 안 나감, 잠금 해제에 사용)

| 행동 | 코인 |
|---|---|
| 출석 체크 | +5 |
| 분석/해몽 완료 | +10 |
| 광고 보기 (2개 연속) | +20 |
| **잠금 해제 비용** | **50코인** |

**표시 문구:** `🪙 오늘 무료 코인 최대 50코인 / 출석+5 / 해몽완료+10 / 광고보기+20`

---

## 전략 4: 코인 적립 시 광고 2개 연속 (핵심 수익 구조)

**논리:** 유저가 자발적으로 "광고 보기" 누름 → 2개 연속이어도 불만 없음 (코인 받으려고 기다림)

```javascript
const watchAdsForCoins = async () => {
  setAdLoadingKey("coin");
  try {
    // 리워드 광고 1번
    await Toss.showRewardAd(REWARD_AD_GROUP_ID);
    // 전면광고 바로 연속
    await Toss.showInterstitialAd(INTERSTITIAL_AD_GROUP_ID);
    // 코인 지급
    const newCoins = coins + 20;
    setCoins(newCoins);
    saveCoins(newCoins); // Toss Storage 영구저장
    alert("🪙 +20코인 적립!");
  } catch(e) {
    setCoins(c => c + 10); // 한 개만 봤으면 10코인
  }
  setAdLoadingKey(null);
};
```

**수익 구조:** 잠금 해제 1회 = 광고 2~3번 시청 = 광고 4~6개 노출

## 마스터즈 타로 추가 벤치마킹 (나중에 적용)

- **캐릭터 선택:** 우리 복냥이 캐릭터 활용 (위로/분석 모드 선택)
- **고민 텍스트 입력:** AI상담 앱 개념과 연결
- **"벌써 49명이":** "벌써" 단어가 긴박감 줌 → `오늘 벌써 ${count}명이 확인했어요`

## 구현 우선순위

1. "오늘 N명이 확인했어요" → 전체 토스 앱 (쉬움, 1줄 추가)
2. 나갈 때 광고 2번 → 외부 광고 집행 시작 전에 넣기
3. 코인 시스템 → 꿈해몽부터 파일럿 후 전체 적용
