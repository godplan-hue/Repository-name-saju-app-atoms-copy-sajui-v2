# 광고 핵심 비법 (에스더님 직접 정리 — 절대 삭제 금지)

---

## 1. 애드몹(AdMob) — 플레이스토어 앱 연결 홍보

- AdMob 광고 신청 → 구글 전체 네트워크에 앱 광고 노출
- 플레이스토어 앱 연결해서 홍보하는 법
- 현재 점운은 웹앱 → **나중에 플레이스토어 앱 출시 후 적용**

---

## 2. 메타 광고 라이브러리 활용법 (지금 당장 할 수 있음)

**방법**:
1. 메타 광고 라이브러리 접속 (facebook.com/ads/library)
2. "사주앱", "꿈해몽앱", "에어비앤비" 등 검색
3. **오래 걸려있는 광고 = 효과 좋은 광고** (광고주가 돈 계속 쓴다는 증거)
4. 그 광고 구조/카피/비주얼 벤치마킹해서 점운 버전으로 만들기

**핵심**: 잘 되는 광고를 찾아서 비슷하게 만든다 → 검증된 공식 그대로 활용

---

## 3. ⭐⭐⭐ 핵심 비법 — 경쟁사 고객 뺏어오기

> "(젤중요 이거보고 그대로 광고진행함)"

**구글 애드몹/애즈에서 경쟁사 URL + 키워드 타겟팅**:

```
광고 설정 시 → 게재위치(사이트주소) 입력:
- 사주아이 앱/사이트 URL
- 점신 앱/사이트 URL
- 2위 앱 URL
→ 그 사이트 방문자에게 점운 광고 노출!
```

```
키워드 타겟팅:
- "사주아이"
- "점신"
- 경쟁사 이름 키워드
→ 경쟁사 검색하는 사람에게 점운 광고 노출!
```

**결과**: 사주아이·점신 유저 전부 점운으로 끌어올 수 있음

## 4. 틱톡/숏폼 광고 카피 공식

**실제 작동한 카피**:
> "소름 돋게 말년에 재물복 터지는 여자띠"

- 네이버 블로그: https://naver.me/G8frhD4k
- 유튜브 참고영상: https://youtu.be/L_h_ZtLlj-I?si=do6uLZbwsXLlINCY

**공식**: `[소름/충격] + [시기(말년/올해)] + [결과(재물복 터진다)] + [타겟(여자띠/특정띠)]`

## 5. 경쟁사 광고 퍼널 구조 (에스더님이 직접 체험)

**사주이음(삼밀당) 퍼널**:
```
틱톡 영상 ("소름 돋게 말년에 재물복 터지는 여자띠")
    ↓ 영상 클릭
AMPM 사주 상담 신청 폼 (이름/연락처 입력)
    ↓
유료 비대면 상담 연결
```
- 사이트: https://home.ampm.co.kr/ae-flameyouth/estimate/

**점운 적용 퍼널**:
```
틱톡 영상 (같은 카피)
    ↓ 클릭
jeomun.com 무료사주
    ↓
990원 결제 (자동, 사람 필요 없음 → 무한 확장 가능)
```

## 점운 실행 순서

1. **지금 당장**: 메타 광고 라이브러리에서 사주앱 광고 벤치마킹
2. **결제 연동 완료 후**: 구글 애즈에서 사주아이·점신 URL + 키워드 타겟팅 광고 집행
3. **플레이스토어 앱 출시 후**: AdMob 연동해서 앱 프로모션

## Why: 에스더님이 직접 조사한 광고 비법. "젤중요 이거보고 그대로 광고진행"
## How to apply: 광고 집행 전 반드시 이 파일 읽고 경쟁사 URL/키워드 타겟팅 설정
