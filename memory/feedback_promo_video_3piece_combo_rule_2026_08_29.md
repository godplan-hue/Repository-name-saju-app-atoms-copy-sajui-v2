## 적용 원칙
- **캐릭터는 매번 새로 생성** — 영상 소재(사주/MBTI/궁합 등)에 맞는 의상·소품으로 점냥이 캐릭터 이미지를 그때그때 새로 만듦 (제미나이에 넣을 프롬프트 글로 제공)
- **영상 본편**: 미니인터뷰 코믹 포맷, 8초, 압축 1포인트(요소 여러개 나열 금지)
- **캡션**: 영상 내용과 무관하게 항상 고정 TOP5 템플릿 형식 사용 (영상은 코믹/캐릭터형이어도 캡션은 리스트형 후킹으로 별개 운영)
- 대상 앱마다(사주/MBTI/궁합 등) 위 조합을 그대로 재사용, 소재와 캐릭터 의상만 치환

**Why**: 매번 광고 문구/영상 구조를 처음부터 다시 만들면 시행착오가 반복됨. 이미 검증됐거나 확정된 3개 자료를 표준 조합으로 고정해두면 다음부터는 바로 실행 가능.
**How to apply**: "홍보영상 만들자"는 요청이 오면 이 문서를 먼저 확인하고, 3종세트 순서(캐릭터 프롬프트 생성 → 미니인터뷰 대본+Veo3프롬프트 → TOP5 캡션)로 바로 콘텐츠를 만들어 줄 것.
