에스더님 요청 "점운엠비티아이도 20개로 결과지늘려줘" → 웹앱(`app/mbti/`, jeomun.com)을 의미하는 것으로 판단.

**1차 작업(commit bd8323f8, 이 메모리의 이전 버전)**: 잠금화면 문구가 "18가지"였길래 토스의 신규 심층분석 5종(아우라/친구관계온도/고백타이밍/잼민력/공감능력) 중 2개(아우라·공감능력)만 포팅해서 20으로 맞췄다고 보고함.

**에스더님 정정**: "15개였는데 왜 18개라고 하냐" / "토스랑 똑같이 20개로 만들어" — git log 확인 결과 웹앱 잠금문구는 실제로 14가지→18가지→20가지로 변해왔고 "15"였던 적은 없음(15는 토스 앱이 원래 갖고 있던 심층분석 개수였고, 거기에 신규 5종을 추가해서 20이 된 것 — 에스더님이 두 코드베이스를 헷갈리신 것으로 보임). 다만 실질적 지적은 정확했음: 1차 작업에서 토스의 신규 5종 중 2개만 포팅하고 3개(친구관계온도/고백타이밍/잼민력)를 빠뜨렸음.

**2차 수정(2026-08-30, commit 8d281e43)**: 나머지 3개도 전부 포팅해서 토스와 완전히 동일한 심층분석 5종을 웹에도 반영. "20가지" 라벨을 유지하기 위해 잠금화면 불릿 20개 중 서로 겹치는 3쌍(①성격성향+강점/주의점 ②연애스타일+연애심층+궁합유형 ③직업+유명인+오행기질연결)을 병합해서 3자리를 확보한 뒤 새 3개(🌡️친구관계온도/💘고백타이밍/🐣잼민력)를 추가 — 최종 20개 유지.

**How to apply**: "토스 OOO엔 있는데 점운(웹) OOO엔 없다" 류 요청은 토스 파일에서 관련 함수/데이터를 전부 찾아 개수를 정확히 세고, 하나도 빠뜨리지 말고 전부 포팅할 것 — 일부만 옮기면 나중에 "왜 다 안 옮겼냐"는 재작업이 생김. 이번처럼 "N가지" 라벨을 유지해야 하면 겹치는 불릿을 병합해서 자리를 만들 것(항목 삭제 금지, 병합만).
