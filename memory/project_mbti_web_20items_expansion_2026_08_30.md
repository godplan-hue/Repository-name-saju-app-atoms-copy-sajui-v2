**3차 작업(2026-08-30, commit f152dc53)**: 에스더님 추가요청 — "20개는 그대로 다 나오게 하되, 맨 위 3개(성격성향/강점/주의할점)는 결제 없이 무료로 보이게 해줘 + 앞간판(/apps 목록 배지)도 무료/990원·24h로 바꿔 + 연애·직업·궁합·오행 몰아보기 카드도 추가해 + 내용은 토스랑 똑같이".

조사 결과 토스(`jeomun-mbti/src/App.tsx` 1577-1581행)의 실제 무료/유료 구조: 기본분석(성격성향)은 완전무료, 강점/주의점은 광고시청시 무료, 나머지 전부(연애/직업/궁합/오행/카드/심층분석)는 990원 결제. 웹앱은 광고 시스템이 없으므로 "광고시청 무료" 항목도 그냥 무조건 무료로 처리 — 토스 설계를 그대로 따른 것.

**적용 내용**:
- `app/mbti/result/[id]/page.tsx`: 성격성향(DimBar)/강점/주의할점 3개 카드를 `{unlocked && ...}` 게이트 밖으로 이동(무료), 각 카드 우측에 초록색 "무료" 배지 추가. 연애스타일/궁합유형/커리어+유명인/오행연결은 그대로 유료 유지.
- 같은 파일: 테토-에겐 카드와 돈스타일 카드 사이에 "🎁 연애·직업·궁합·오행 몰아보기" 카드 신규 삽입 (토스 원본 위치·내용 동일, `data.love`/`data.career`/`data.compat`/`data.ohDesc` 기존 필드 재사용 — 신규 API 필드 불필요).
- 같은 파일: 잠금화면 20개 불릿 중 1번("성격성향+강점+주의할점...")을 "🎁 연애·직업·궁합·오행 몰아보기 — 나를 완성하는 4가지 조각을 한 번에"로 교체 (나머지 19개 그대로, 총 20개 유지).
- `app/apps/page.tsx` 50행: MBTI 항목 `badge: "990원·24h"` → `badge: "무료/990원·24h"`.

**오행(`oh`) 필드 관련 확인 사항** (에스더님 질문 "토스엔 왜 생년월일 입력이 없냐"에 대한 답): 웹/토스 두 코드베이스 모두 생년월일을 입력받지 않음. `oh`는 MBTI 유형별로 고정된 하드코딩 매핑(예: INFJ=목, ENTJ=금)이며 실제 생년월일 사주로 계산하는 게 아니라 "사주로 MBTI를 알 수는 없지만 오행 기질이 이런 MBTI와 닮았다"는 컨셉의 의도된 기획 요소 — 버그 아니고 두 앱 일관됨.

**How to apply**: "토스 OOO엔 있는데 점운(웹) OOO엔 없다" 류 요청은 토스 파일에서 관련 함수/데이터/무료유료 구조를 전부 찾아 정확히 확인 후 포팅할 것. "N가지" 라벨 유지해야 하면 겹치는 불릿을 병합/교체(삭제 금지)로 자리를 만들 것. 무료전환 요청 시 토스의 광고시청조건부무료는 웹에서는 무조건무료로 치환하는 게 맞는 적응임(광고 시스템 없음).
