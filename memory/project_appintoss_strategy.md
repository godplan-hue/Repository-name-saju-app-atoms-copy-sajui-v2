### 표현 방식 주의사항

✅ **통과 유리한 표현**
- 별자리 성격 테스트
- 반려동물 성향 분석
- 행운 컬러·행운 아이템 추천
- 오늘의 기분 카드

❌ **심사에서 불리한 표현**
- "오늘 재물운 100%"
- "이 번호로 당첨됩니다"
- "타로가 미래를 확정해줍니다"
- "쉽게 돈 번다", "수익 보장"

→ **운세를 전면에 내세우지 말고 생활형 콘텐츠로 포장**

### 수수료 구조
- 무료 앱: 수수료 0원
- 유료 인앱결제: 앱마켓 15% + 토스 5% = 총 **20%**
- 990원 기준 792원 정산

---

### 예상 매출 시뮬레이션
```
월 노출 10만 명 → 이용 전환 3% = 3,000명
→ 유료 결제율 5% = 150명
→ 평균 결제 9,900원
→ 월 매출 약 148만원
(토스 메인 추천/인기앱 노출 시 수배 이상 가능)
```

1. 생활형 앱(가계부·감정일기·다이어트·맘케어·MBTI) 먼저 올려 계정 신뢰 쌓기

### 7가지 운영 전략

1. **15개 앱 = 15개 광고판** — 각 앱이 독립적으로 검색·발견될 기회 생성
2. **검색 키워드 전략** — 앱 이름: "점운 가계부", "점운 MBTI" (브랜드+기능 조합)
3. **리뷰 확보** — 초기 실사용자 리뷰 쌓기 (허위 리뷰 금지)
4. **무료→유료 전환** — 핵심 기능 무료 / 추가 기능 유료 구조
5. **콘텐츠 재활용** — 꿈해몽·MBTI·자소서·부업추천 콘텐츠 여러 채널에 재활용
6. **운영 우선순위** — 처음엔 3~5개만 안정화 → 반응 보고 확장
7. **점운 브랜드 통일** — 한 앱 만족 → 다른 점운 앱 찾아보는 효과
