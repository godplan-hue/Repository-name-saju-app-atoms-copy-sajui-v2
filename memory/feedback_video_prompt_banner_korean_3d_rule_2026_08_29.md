에스더님이 2026-08-29 확정: 점운 홍보영상(Veo3/Flow 등 AI 영상생성 프롬프트) 만들 때마다 매번 아래 3가지를 반드시 프롬프트에 포함시킬 것. [[feedback_promo_video_3piece_combo_rule_2026_08_29]] 3종세트 조합 위에 항상 추가되는 필수 항목.

## 1. 한글 오타 방지 지시 필수
- AI 영상 생성 모델이 한글 텍스트를 자막이나 배너에 넣을 때 글자가 깨지거나 오타나는 경우가 많음
- 프롬프트에 항상 "한글 텍스트는 정확한 맞춤법으로, 오타·깨진 글자 없이" 같은 명시적 지시를 넣을 것
- **한계 인지**: 이 지시를 넣어도 AI가 100% 정확하게 한글을 렌더링한다는 보장은 없음 — 결과물에 오타/깨짐이 나오면 캡컷/브루 등 편집앱에서 텍스트를 후반 작업으로 덧씌우는 게 더 확실한 대안

## 2. 영상 상단 고정 배너 텍스트 필수
- 영상 맨 위에 항상 고정으로 떠 있는 배너 텍스트를 넣을 것
- 패턴: **[점운] + [앱이름] + [가격 또는 무료여부]**
  - 사주: "점운 990원 사주"
  - MBTI(토스 무료버전): "점운 토스 MBTI 무료"
  - 다른 앱도 이 패턴 그대로 적용 (예: 궁합 무료면 "점운 궁합 무료", 유료전환 후면 "점운 궁합 990원")
- 앱별 가격 정책이 바뀌면 배너 문구도 그에 맞게 업데이트해서 넣을 것

## 3. 3D/4D 입체감 스타일 요청
- 영상이 평면적이지 않고 입체감 있게(3D/4D) 나오도록 프롬프트에 명시할 것
- 단, 기존 확정된 "실사 사진 스타일"(photorealistic) 방향과 충돌 가능성 있음 — 완전 3D 애니메이션(CG 캐릭터화)을 원하는 건지, 아니면 입체적 카메라감(시네마틱 뎁스/패럴랙스)을 원하는 건지 매번 결과물 보고 방향 조율 필요

**Why**: AI 영상에서 한글 깨짐/오타가 자주 발생하고, 브랜드명+가격 정보가 영상에 없으면 시청자가 어디서 뭘 하는 건지 인지 못 함. 매번 이 요청을 새로 설명하지 않도록 표준 체크리스트로 고정.
**How to apply**: 앞으로 점운 홍보영상 프롬프트를 만들 때마다 [[feedback_promo_video_3piece_combo_rule_2026_08_29]]의 3종세트에 이 3가지(한글오타방지+상단배너+3D/4D)를 항상 추가로 포함시켜서 제공할 것.
