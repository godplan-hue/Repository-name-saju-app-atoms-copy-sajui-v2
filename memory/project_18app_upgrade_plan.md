# 18개 앱 업그레이드 마스터 플랜 (2026-08-10 확정)

**핵심 원칙**: 토스보다 약하거나 빠진 기능만 토스 수준으로 올린다. 점운이 토스보다 더 많은 앱은 건드리지 않는다.

## 확정 결정사항

| 항목 | 결정 |
|------|------|
| 유료 잠금 방식 | 처음부터 완전 잠금 (부분 미리보기 없애기) |
| 결제 후 유지 | 24시간 유지 |
| 대운·택일 | 나가면 바로 닫힘 유지 — 절대 24시간으로 바꾸지 말 것 |
| 오늘 몇 명 기능 | 18개 전체 앱에 추가 (아침/점심/저녁 3번 숫자 변경) |
| 내 소개 | 탈잉 1위 추가/수정 |
| 수정 방식 | 앱 하나씩 순서대로, 에러 없이 안전하게 |
| 결제창 | 카카오페이 없는 앱 전부 연결 |
