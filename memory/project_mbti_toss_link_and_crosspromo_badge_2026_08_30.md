[[project_mbti_web_20items_expansion_2026_08_30]] 후속 작업 (2026-08-30, commit `199e0498`).

**요청 배경**: 이전에 "웹→토스 연결법이 뭐냐"는 질문에 SEO 랜딩페이지(`/mbti/toss/[slug]`)에 이미 minion.toss.im 링크가 있다고 답했으나, 에스더님이 "그런 거 본 적도 없고 MBTI 페이지엔 지금 그런 링크 안 보인다"고 지적 — SEO 랜딩페이지는 별도 페이지라 실제 이용 경로(첫화면/결과지)엔 링크가 없었던 것. **교훈: SEO 서브페이지에 뭔가 있다는 것만으로 "이미 연결되어 있다"고 답하면 안 됨 — 사용자가 실제로 보는 화면(메인 랜딩/결과지)에 있는지 확인할 것.**

**적용 내용**:
- `app/mbti/page.tsx`: 히어로 가격문구를 "16문항·2분완료·990원 심층분석" → "...기본 분석 무료·심층 분석 990원"으로 수정 (2곳: 상단 소개문 + CTA버튼 하단). CTA버튼 하단에 "전체 무료로 보려면 토스 MBTI에서 확인하세요 →" 링크(`https://minion.toss.im/pht8Fcyp`, 새탭) 추가.
- `app/mbti/result/[id]/page.tsx`: 심층분석 유료잠금 화면의 "₩990으로 전체 분석 열기" 버튼 바로 아래에 동일한 토스 링크 추가.
- **범위 제한**: 에스더님이 "딴건넣으면안돼"라고 명시 — MBTI 앱(첫화면+결과지)에만 링크 추가, 다른 앱(/main-v2, /apps 등)엔 추가하지 않음.

**크로스프로모 배지 수정** (`app/battle`, `app/movie`, `app/style`, `app/work` — 각 page.tsx 하단의 "다른 서비스" 4칸 그리드):
- MBTI·궁합·사주운세 배지를 "990원"/"990원~" → "무료/990원"/"무료/990원~"으로 변경 (이 3개 앱은 무료 미리보기+유료 심화 구조이므로).
- 직장버티기(`/work`)는 완전 무료 앱이라 배지 변경 안 함 — 에스더님이 명시적으로 제외 지시.
- 참고: 이 4개 크로스프로모 그리드는 서로 다른 조합(work.tsx엔 궁합 없음, battle.tsx엔 직장버티기 없음)이라 각 파일에서 실제 존재하는 항목만 수정함.

**How to apply**: 새 무료+유료 혼합앱(예: 앞으로 나올 앱)이 추가되면 이 4개 크로스프로모 그리드에도 등장하는지 확인하고 배지를 "무료/990원" 패턴으로 맞출 것. 완전무료 앱은 "무료"만 유지.
