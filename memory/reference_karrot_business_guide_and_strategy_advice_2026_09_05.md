## 당근비즈니스 구조 요약 (공식 가이드, 2026-09-05 공유)

- **비즈프로필**: 가게 무료 등록·소개, 소식/쿠폰/후기, 채팅 문의 — 업체 전용 프로필
- **비즈니스 도구**: 견적받기 / 예약관리 / 상품판매(당근 앱내 결제) / 포장주문 / QR오더
- **광고 = 동네인증 기반** — 노출시킬 동네를 직접 선택 가능
- **광고모드 2종**
  - **간편모드**: 피드광고+검색광고, AI가 소재제작~성과관리 자동화, 광고 처음인 사장님용
  - **전문가모드**: 타겟/예산/운영방식 세밀 설정, 성과분석·최적화 기능
- **전문가모드 전용 광고도구**: 카탈로그관리(다품목 일괄) / 전환추적관리(방문·구매·문의 추적) / 맞춤타겟관리 / 리드폼관리(문의·상담신청 수집) / 대량관리(여러광고 키워드 일괄)

## 점운 당근광고 운영 조언

이미 실제 성과 있음: [[project_first_ad_driven_db_inflow_2026_08_29]]에서 당근광고 "점운 990원 사주" 캠페인이 8/28부터 클릭 발생 → 같은 날 DB유입 → 990원 실결제까지 확인된 유일한 채널(기존 [[project_ad_strategy]]에선 구글50%+네이버30%+카카오20%로 당근 비중이 아예 없었음 — 실적 나온 지금은 재배분 검토 대상).

1. **지금은 간편모드 유지**: 비개발자·AI자동화 방식이 에스더님 워크스타일과 맞고, 이미 이걸로 결제전환까지 검증됨. 전문가모드는 광고 개수/예산이 늘어 세밀한 타겟팅·대량관리가 실제로 필요해질 때(지금 아님) 넘어갈 것.

2. **전환추적관리(전문가모드 도구)는 예산 늘리기 전에 먼저 붙일 가치 있음**: 지금은 "광고비 지출 대비 클릭수"만 보고 있음. [[project_first_ad_driven_db_inflow_2026_08_29]]에서 이미 결제완료 처리 중복호출 버그(pay_pending 오매칭, commit으로 수정완료)가 있었던 걸 감안하면, 클릭→990원 결제까지의 실제 전환율을 광고 플랫폼 안에서 직접 확인할 수 있어야 예산을 늘려도 되는지 판단 가능. 전환추적 픽셀/이벤트를 결제완료 페이지에 심는 작업 필요.

3. **동네 타겟은 넓게 잡지 말고 인구밀집 대도시부터 집중**: 사주앱은 전국 서비스라 "동네인증" 특성상 여러 동네를 다 고르면 예산이 분산됨 — 서울/경기/인천 등 소수 지역으로 좁혀 CTR·전환 확인 후 성과 좋은 지역 위주로 확장하는 게 초기엔 효율적.

4. **리드폼관리는 사주앱보다 파트너모집에 더 잘 맞을 수 있음**: "문의/상담신청"을 당근 앱 안에서 바로 받는 기능이라, 990원 셀프결제 상품보다는 [[project_kmong_partner_listing]] 같은 파트너 모집 광고에 써볼만함 — 우선순위 낮음, 여유될 때 테스트.

5. **소재는 기존 팁 재사용**: [[reference_karrot_ad_photo_title_tips_2026_08_28]]에 이미 있는 당근 사진/제목 작성팁을 계속 활용. 새로 만들 필요 없음.

6. **비즈프로필 자체는 우선순위 낮음**: 물리적 매장이 없는 온라인 서비스라 "동네 단골 만들기"(소식/쿠폰/채팅)용 비즈프로필의 이점이 크지 않음 — 광고 집행에는 비즈프로필 없이도 문제 없음, 지금은 스킵.

**Why**: 당근이 유일하게 990원 실결제까지 확인된 광고채널인데 예산배분 전략([[project_ad_strategy]])엔 아예 빠져있던 불일치를 바로잡기 위해 정리.
**How to apply**: 다음에 광고예산 재배분/전환추적 얘기 나오면 이 메모부터 확인. 전환추적관리 붙이기 전엔 "성과 좋다"는 판단을 클릭수만으로 내리지 말 것.
