## 공통 원칙

- 리워드 먹통 fallback: 20초 타임아웃
- 리워드 isSupported 체크 필수
- "광고 보기" 버튼 문구 절대 금지 → [[feedback-unlock-button-copy]] 참고
- 유료결과 50초 후 전면광고 → **삭제됨** (가이드: 읽는 중 광고 = 만족도 최대 하락)

## Why
- 섹션별 "🔓 열어보기" = 자율성 착각으로 거부감 최소화
- 무료 앱 패턴으로 자연스러운 리워드 수익 구조
- 가이드 ⭐⭐⭐⭐⭐ 추천: "사용자가 직접 선택한 광고 = 수용도 최고"
