## 계정: 슈니드 (Schneed) — 신발 쇼핑몰 광고
2026-08-29 에스더님이 캡처해서 공유한 실제 노출 중인 틱톡 광고 예시. [[reference_dailyclosetmagazine_tiktok_format_2026_08_29]], [[reference_soulcleanmaster_disney_tiktok_format_2026_08_29]]와 함께 3번째 벤치마킹 자료.

### 영상 구조 (자막나열형 언박싱/체험 후기)
- 말/음성 없이(🔇) 손으로 신발을 들거나 신는 모습을 연속 컷으로 보여주고, 매 컷마다 큰 손글씨체 흰 자막(검정 테두리)으로 후기성 멘트를 하나씩 나열
- 자막 순서(스토리텔링형 흐름): "이 샌들퀄리티에 첫구매 2만원대" → "샌들 정말 맞나요?"(놀람 유도) → "키높이 통굽인데 안정감 있어서 하루종일" → "종일 걸어도 괜찮아요" → "버클 잠그는 순간 느낌이 달라요" → "디테일이 확실히 고급스럽더라고요" → "제가 직접 이것저것" → "어울리는 옷이 없었어요" → "올릴 때마다 품절입니다" → "있을 때 잡으세요" → "링크 프로필"(최종 CTA)
- 장면 구성: 실내 언박싱 컷(손으로 들기) → 클로즈업 스튜디오 화보 컷(맨발 다리) → 착용 순간(버클 잠그기) → 야외 거리 착용샷(전신 하의+신발) → 제품+향수병 정물샷(품절임박 컷)
- 하단 고정: 계정명 "슈니드 · 5-7"(날짜) + "첫구매 2만원대 완전 특가 상품 …" + "자세히" 버튼

### 성과 지표 (캡처 시점)
좋아요 388 / 댓글 7 / 저장 5 / 공유 34 — **공유(34)가 좋아요 대비 이례적으로 높음** → "나도 사고 싶다"는 공감형 자막 나열이 지인 태그/공유를 유도하는 것으로 추정

### 핵심 포인트
- 광고 티 안 나는 "내가 써보니 이렇더라" 개인 후기 톤 자막을 순서대로 배치해 스토리처럼 읽히게 구성
- 마지막 2개 슬라이드는 "품절 임박" 긴급성 문구로 클릭 직전 압박감 조성
- CTA는 "링크 프로필"(자기 프로필의 외부링크) 방식 — 틱톡 프로필에 판매 링크를 걸어두는 구조

## 점운 적용 아이디어
- 신발 대신 "결과지 화면"이나 "궁합 점수 카드"를 손에 들고 보여주는 컷 → 자막을 "이 정도로 정확할 줄은" → "가격이 990원이라고?" → "무료로도 이만큼 나와요" 식 공감형 순서로 배치 가능

- CTA는 점운도 "프로필 링크"(틱톡 bio) 방식으로 MBTI/사주 링크를 걸어두는 구조 고려 가능
