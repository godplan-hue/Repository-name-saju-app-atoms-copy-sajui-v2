## 핵심 규칙

리워드 광고로 섹션 잠금 해제하는 버튼 문구에 **"광고"라는 단어를 절대 넣지 말 것.**

**Why:** 사용자는 "광고를 본다"는 느낌보다 "내가 선택해서 연다"는 느낌을 받아야 거부감이 없다. 심리학적으로 자율성 착각 — 같은 광고인데 본인이 클릭했다는 느낌만으로 불만이 확 줄어든다. "광고 보기" = 강요 느낌. "열어보기" = 내 선택 느낌.

## 올바른 버튼 문구

```
✅ "🔓 지금 열어보기 →"       ← 제일 좋음
✅ "잠금 해제하기 →"
✅ "확인하기 →"
✅ "지금 확인하기 →"
```

## 금지 문구

```
❌ "광고 보고 열기"
❌ "광고 1회 시청 후 열기"
❌ "광고 클릭하면 열림"
❌ "광고 보기"
```

## 적용 방식

버튼 클릭 → 리워드 광고 자동 재생 → 광고 끝나면 잠금 해제.
버튼 문구에는 광고 언급 없음. 사용자는 클릭하면 광고가 뜨는 걸 자연스럽게 받아들임 (무료 앱 리워드 광고 패턴 이미 익숙).

**How to apply:** 모든 토스 미니앱에서 리워드 광고 버튼 만들 때 무조건 이 원칙 적용. MBTI, 다이어트, 감정일기, 향후 모든 앱 동일.
