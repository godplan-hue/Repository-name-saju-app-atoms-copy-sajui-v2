## 핵심 요약

- **돈 안 듦** — 토스 포인트 아님, 우리 앱 안에서만 쓰는 가상 재화 지급
- **현금성 보상 불가** — 하트, 보석, 포인트 같은 인앱 재화만 가능
- **SDK 연동 필요** — 개발 작업 있음
- **지금 당장은 안 해도 됨** — 정산 정보 등록 + 990원 유료 전환이 우선

---

## 공유 리워드란?

공유 리워드는 연락처 모듈을 사용해서 토스를 사용하는 사용자의 연락처를 불러오고, 공유를 완료한 사용자에게 리워드를 제공하는 기능.

- 공유는 **토스 알림 푸시**로 진행
- 게임/비게임 서비스 모두 사용 가능
- 서비스 유형에 따라 사용자에게 노출되는 푸시 문구 달라짐

---

## 장점

- 친구 초대에 보상을 연결해 자연스럽게 트래픽을 만들 수 있음
- 추가 비용 없이 마케팅 효과
- 서비스 안에서만 사용할 수 있는 재화 제공 → 재방문 유도

---

## 발송 제한

- 하루 단위로 초기화
- 하나의 리워드 ID 기준, 한 사용자에게 하루 한 번만 발송 가능

---

## 콘솔 설정 항목

- **리워드 이름**: 내부 관리용 (예: 친구 초대 이벤트 보석 지급)
- **리워드**: 지급할 재화 단위 (하트, 보석, 포인트 등)
- **수량 및 금액**: 지급할 수량

---

## 주의사항

- 과도한 팝업이나 강제적인 공유 유도 금지
- 현금성 보상, 사행성 보상 등록 불가
- 개발 연동: `contactsViral` SDK 사용

---

## 점운 적용 계획

**지금 당장은 패스** — 이유:
1. MBTI 앱에 인앱 재화(하트/보석) 시스템이 없음
2. SDK 연동 개발 작업 필요
3. 정산 정보 등록 + 990원 유료 전환이 우선

**나중에 적용 시**:
- MBTI 결과 공유하면 → "심층분석 1회 무료" 같은 인앱 혜택 지급
- 친구가 앱 설치하면 공유한 사람도 혜택 → 바이럴 선순환

## ⭐ 2026-08-21 재확인 — 재화시스템은 이미 있음, 그래도 지금은 보류

- **정정**: "인앱 재화(하트/보석) 시스템이 없다"는 이전 판단이 틀림 — [[project_toss_promo_secrets]]에 이미 코인 시스템(`jeomun_coins`, Toss Storage 영구저장) 확정·적용돼 있음. 공유 리워드도 이 코인을 그대로 지급하면 되므로 재화 시스템 신규 구축은 불필요.
- **공유 확인 방식**: 우리가 직접 확인할 필요 없음 — 토스 `contactsViral` SDK가 초대 완료 여부를 자체 추적해서 콜백으로 알려줌 (월렛의 `Promotion.grantReward`와 비슷한 구조).
- **최종 결정**: 그래도 지금 당장은 안 함 — "일단 다 올리고, 나중에 필요하면 그때 다시 넣자"고 에스더님이 확정. 지금 우선순위(4개 앱 월렛/스마트발송 집중)에서 벗어나므로 보류.

**Why:** 재화시스템 부재는 더 이상 걸림돌이 아니지만, 그래도 지금 스코프를 늘리면 힘드니까 4개 앱 집중 전략 유지가 우선.
**How to apply:** 공유 리워드는 에스더님이 먼저 다시 꺼낼 때 착수. 먼저 제안하지 말 것. 착수 시엔 `contactsViral` SDK 연동 + 콘솔 리워드(코인 지급) 등록 순서로 진행.
