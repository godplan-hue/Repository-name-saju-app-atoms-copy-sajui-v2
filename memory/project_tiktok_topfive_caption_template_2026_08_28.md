## 확정된 틱톡 캡션 템플릿 (2026-08-28)

여러 번 시행착오 끝에 에스더님이 최종 승인한 형식:

```
"[주제] 사주 TOP 5

내 사주도 해당될까?
댓글에 생년월일 남기면 알려드려요 👇

점운 jeomun.com"
```

### 핵심 규칙
- **짧게** — 5개 항목 상세 설명(일주/오행/십성 등) 넣지 말 것. 제목 + 짧은 CTA만.
- **주제는 사주 자체에 관한 것** — "친구가 20만원 썼다" 같은 스토리/브랜드 훅 아님. [[competitor_sajucase_tiktok]] TOP5 리스트형 그대로.
- **가격(990원 등) 절대 언급 금지** — TikTok "Financial Misrepresentation" 오탐 거절 이력 있음 (990원 표기 때문).
- **끝에 "점운 jeomun.com" 필수 포함**.
- 주제 예시 (매번 다른 걸로, 이미 올린 주제 반복 금지):
  - "돈복 터지는 사주 TOP 5" — 이미 올림
  - "로또 맞을 사주 TOP 5" — 사용 가능
  - "결혼하면 남편 성공시키는 사주 TOP 5" — 승인됨, 다음 영상 후보
  - 이 외 [[competitor_sajucase_tiktok]]에 저장된 주제 풀 활용

### 영상 내용(슬라이드/본문)과 캡션은 별개
- 영상 자체에 넣는 자막/슬라이드 스타일은 [[competitor_sajucase_tiktok]] 참고 (금색 배경, 굵은 텍스트 슬라이드, 목소리 없어도 됨)
- 이 메모는 **캡션(영상 하단 텍스트)** 전용 템플릿

**Why:** 여러 라운드의 캡션 제안이 거부된 끝에("긴글쓰지마", "사주에관한글을쓰라고" 등) 이 형식으로 최종 승인받음. 매번 처음부터 다시 시행착오 겪지 않도록 고정 템플릿으로 저장.
**How to apply:** 새 틱톡 영상 올릴 때 이 템플릿에 주제만 바꿔서 바로 제공할 것. 길게 쓰거나 브랜드 스토리 훅으로 시작하지 말 것.
