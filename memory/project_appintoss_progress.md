## 결제 연동 구조 (인앱 결제 승인 후)

```typescript
import { checkoutPayment } from "@apps-in-toss/web-framework";  // TossPay 아님!

const orderId = `mbti-${Date.now()}`;
const { payToken } = await fetch("https://jeomun.com/api/toss-inapp", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ orderId, amount: 990, orderName: "점운 MBTI 상세분석" }),
}).then(r => r.json());

const { success } = await checkoutPayment({ params: { payToken } });
if (success) {
  await fetch("https://jeomun.com/api/toss-inapp", {
    method: "PATCH",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ payToken }),
  });
  setPaid(true);
}
```

- 서버: `app/api/toss-inapp/route.ts` (POST + PATCH + OPTIONS, CORS *)
- 환경변수: `TOSS_INAPP_SECRET_KEY` → Vercel에 추가 필요
