## 핵심 비법 (경쟁사에서 발견)

**구조**: 앱 결과지 버튼 → 네이버 블로그 → SEO 검색 유입 → 앱 발견

**경쟁사 사례**: "다이어트 DNA" 앱 (토스 앱인토스)
- 결과지 맨 아래 "체질 다이어트 성공 가이드 보기" 버튼
- 클릭하면 네이버 블로그 글로 연결 (동대문신광한의원 블로그)
- 블로그 글: "수음체질의 완벽 식단 가이드: 위장을 따뜻하고 가볍게 유지하세요"
- 효과: 블로그 글이 네이버 검색 상위 노출 → 새 유저 앱 발견

**Why 네이버 블로그가 쉬운가:**
- 구글은 도메인 나이·백링크 중요 → 신규 사이트 불리
- 네이버는 발행일 + 콘텐츠 품질 위주 → 새 글도 빠르게 상위 노출
- "수음체질 식단", "INTJ 오행 기질", "뱀꿈 해몽 의미" 등 롱테일 키워드 = 경쟁 거의 없음

**점운 적용 전략:**

| 앱 | 블로그 키워드 | 버튼 문구 |
|---|---|---|
| 다이어트 점운 | 오행 체질별 식단 가이드 5편 | "내 체질 다이어트 완전 가이드 보기 →" |
| MBTI 점운 | MBTI × 오행 기질 분석 16편 | "내 유형 심층 분석 더 보기 →" |
| 꿈해몽 | 꿈 종류별 해몽 사전 | "이 꿈의 의미 더 알아보기 →" |
| 사주 | 오행별 운세·직업·재물 가이드 | "내 사주 오행 더 알아보기 →" |

**실행 계획:**
1. 네이버 블로그 개설 (점운 공식 블로그)
2. 오행 5가지 체질 × 식단 가이드 5편 작성 (Claude가 초안 작성)
3. 다이어트 앱 결과지에 "내 체질 가이드 보기" 버튼 추가
4. 토스 앱 승인 후 외부 링크 버튼 추가 (승인 전은 앱 내부 콘텐츠만)

**콘텐츠 분량 계획:**
- 체질별 식단 가이드 5편
- MBTI × 오행 기질 분석 16편
- 꿈해몽 인기 키워드 50편
- 사주 오행별 가이드 5편
→ 총 76편, 일주일에 5편씩 = 3개월이면 완성

**How to apply:**
- 새 앱 출시 시 결과지에 항상 "더 알아보기" 블로그 버튼 공간 확보
- 블로그 글 작성 시 Claude한테 초안 요청 (앱 콘텐츠 그대로 활용 가능)
- 토스 앱 심사 중에는 외부 링크 버튼 제외, 승인 후 업데이트로 추가
