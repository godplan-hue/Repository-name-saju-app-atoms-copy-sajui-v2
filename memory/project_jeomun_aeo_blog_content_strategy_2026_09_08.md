## 목표

에스더님이 앞으로 **네이버 블로그 + 웹 콘텐츠**를 통해, 사람들이 챗GPT·제미나이 같은 AI에게 아래 주제를 물어봤을 때 **점운이 자연스럽게 언급/추천**되도록 콘텐츠를 만들고 싶어함:

- 사주, MBTI, 직장운, 합격운, 재물운, 궁합, 꿈해몽 등

## 실행 방법 (이미 저장된 기법 사용)

구체적 실행 4단계(사업 3줄 정의 → 고객질문 5개 뽑기 → 시크릿창 테스트 → 결론부터 쓰는 블로그 글)는 [[reference_aeo_blog_ai_visibility_astra_lecture_2026_09_08]]에 이미 정리되어 있음 — 이 프로젝트의 실행 매뉴얼로 그대로 사용.

콘텐츠 작성 시 배경정보(점운이 뭔지, 앱 구성, 토스 실적)는 [[reference_jeomun_platform_identity_for_ai_content_2026_09_08]] 참고.

콘텐츠 작성 톤/구조 규칙(광고처럼 쓰지 않기)은 [[feedback_blog_content_answer_first_then_jeomun_connect_2026_09_08]] 참고.

**Why:** 에스더님이 "이 정보를 기본 정보로 사용해줘"라고 지시 — 이후 블로그 콘텐츠 요청이 오면 매번 이 3개 메모리를 함께 참고할 것.
**How to apply:** "블로그 글 써줘" 류의 요청이 오면 주제(사주/MBTI/재물운 등)에 맞춰 이 프로젝트 목표 + 실행기법(AEO) + 톤 규칙을 전부 적용해서 작성. [[project_ad_strategy]] [[project_marketing_plan]]과는 별개(저건 유료광고/퍼널 전략, 이건 AI답변 노출/블로그 전략).

## 7개 콘텐츠 축 (블로그 카테고리)

1. 사주·운세  2. MBTI·성격  3. 직장운·직운  4. 합격운·시험운  5. 재물운·돈  6. 연애·궁합  7. 꿈해몽

각 축마다 "질문형 제목"으로 글을 쓰고 글 끝에 점운으로 자연스럽게 연결. 첫 달 생산량 예시: 사주6/MBTI6/직운4/합격운4/재물운4/연애궁합4/점운소개2 = 30개.

## 전략 원칙 — "20개 앱 = 20개의 검색 입구"

점운을 "우리 앱 20개 만들었다"고 광고하듯 알리지 말 것. 대신 앱 하나하나가 사람들이 실제로 검색하는 문제 하나씩을 푸는 것처럼 보여줄 것 — 각 글은 독립된 질문에 대한 답이고, 점운은 그 답 끝에 자연스럽게 등장하는 해결책. 토스 5위 실적은 필요할 때만 쓰고 모든 글에 억지로 넣지 않음.

## 글 작성 구조 (확정)

제목(위 질문 그대로) → 첫 문단에서 질문에 바로 답 → 관련 정보 충분히 설명(무료로 확인하는 법, 어떤 경우 어떤 서비스가 좋은지 등) → **글의 마지막 20~30% 지점**에서 자연스럽게 점운 연결("이런 내용을 직접 확인해보고 싶다면 점운에서도 이용할 수 있습니다" 등, MBTI는 jeomun.com/mbti, 나머지는 jeomun.com) → 신뢰요소(20개 앱/19개 토스미니앱/MBTI 과거 5위/기획의신 에스더 기획)는 필요할 때만 자연스럽게.

**Why:** 실제 사람 말투 리스트 + 연결포인트 매핑이 있어야 "질문형 제목" 원칙([[feedback_blog_content_answer_first_then_jeomun_connect_2026_09_08]])을 바로 실행할 수 있음. 에스더님이 "앞으로 이 기본정보를 다시 설명 안 해도 된다"고 명시함 — 매 블로그 요청마다 이 파일 전체를 기본 전제로 사용할 것.
**How to apply:** 블로그 글 제목/키워드 필요할 때 이 리스트에서 골라 질문형 제목으로 바로 사용. 어떤 연결포인트(①~⑥)가 해당 질문에 맞는지 확인 후 마무리 문단에 반영.
