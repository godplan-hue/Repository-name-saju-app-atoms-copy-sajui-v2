에스더님이 "이런거너무좋다" 로 확정 승인한 AI 영상 프롬프트 구조. 다음 앱 홍보영상 만들 때 이 템플릿 그대로 재사용할 것.

## 확정된 템플릿 (점운 사주 예시)

```
세로형(9:16), 8초, 무음(음성·내레이션·대사 절대 생성하지 않음), 실사풍.
손이 스마트폰을 들고 화면을 보여주는 1인칭 시점.

폰 화면 UI (모든 컷에서 이 화면 유지, 절대 빈 화면·다른 화면으로 바뀌지 않음):
상단 "점운" 로고, 그 아래 "990원 사주 결과" 타이틀, 중앙 원형 게이지 그래프 + "재물운 82점" 텍스트, 하단 오행 컬러 원형 카드 5개(빨강/파랑/노랑/초록/보라, 한자 하나씩).

0.0–1.0s: 손이 폰을 들어올림, 위 화면 표시. 자막: "이거 보고 소름 돋음"
1.0–2.5s: 원형 게이지 그래프 확대. 자막: "사주에 재물운 있는 사람들 특징"
2.5–4.0s: "재물운 82점" 텍스트 클로즈업. 자막: "내 사주 봤는데 진짜 있었음"
4.0–5.5s: 오행 컬러 카드 5개 좌우 스크롤. 자막: "무료로 이렇게까지 나온다고?"
5.5–6.5s: 손가락으로 화면 우측 상단 공유 아이콘 누름. 자막: "친구들도 다 해봄"
6.5–7.3s: 화면 정지, 확대. 자막: "안 보면 나만 손해"
7.3–8.0s: 폰 화면 클로징, "점운" 로고만 크게. 자막: "링크 프로필"

자막은 위 문구 8개를 정확히 그대로, 각 컷 끝까지 잘리지 않고 고정 노출. 다른 문구로 바꾸거나 축약하지 말 것.
배경: 밝은 카페 테이블. 손·폰·위에 명시된 화면 외 다른 브랜드 로고·간판·텍스트 절대 노출 금지.
```

## 반드시 지켜야 할 2가지 규칙 (이전 실패 원인)

1. **폰 화면 안에 보여줄 내용을 텍스트로 정확히 명시할 것** — "사주 결과지 떠있음" 처럼 추상적으로 쓰면 AI가 빈 화면/생뚱맞은 화면을 생성함. "점운 로고 + 990원 사주 결과 + 재물운 82점 + 오행 카드 5개"처럼 실제 앱 화면 요소를 문장으로 하나하나 나열해야 함.
2. **자막 문구는 "정확히 그대로, 잘리지 않게" 명시할 것** — 이 지시 없이 그냥 타임라인+자막만 주면 마지막 자막이 중간에 끊기거나("안 보면 나만" 이후 이상한 문구로 이어짐) 모델이 임의로 변형함.

## 재사용 방법 (다른 앱 영상 만들 때)

폰 화면 UI 블록만 해당 앱에 맞게 교체:
- 로고 텍스트 (점운 MBTI / 점운 궁합 등)
- 중앙 표시 내용 (MBTI 유형 카드, 궁합 점수 등)
- 하단 카드 내용

타임라인 자막 8줄 구조(소름돋음 훅 → 정보 → 검증 → 무료강조 → 사회적증거 → 손해프레임 → CTA)는 그대로 유지 가능.

## Why
에스더님이 이전 여러 시도(추상적 프롬프트, "generic" 배경 지시만 있고 폰 화면 내용 미지정)에서 계속 "화면이 점운 화면도 아니야", "자막 잘렸어" 로 반려한 뒤, 위 2가지를 명시적으로 추가한 버전에서 처음으로 확정 승인함.

## How to apply
새 앱 홍보영상 프롬프트를 짤 때마다 이 템플릿을 기본 골격으로 시작하고, 위 2가지 규칙을 빠뜨리지 말 것.
