## 광고 공식 분해

### 1. 제목 공식
```
[특정 띠] + [충격적인 결과]
```
- "소름 돋게 맞년생" → 공감/호기심 유발
- "'재물복' 터지는 여자띠" → 구체적 대상(여자) + 긍정 결과
- 쏘띠·토끼띠·닭띠처럼 여러 띠 나열 → "나 해당되나?" 클릭 유발

### 2. 비주얼 공식
- **황금빛 배경** (재물, 성공 연상)
- **강렬한 인물 이미지** (왕관, 카리스마)
- 굵고 큰 텍스트 → 썸네일에서 바로 읽힘

### 3. 본문 공식
1. 소름 돋는 예언/맞춤 정보 (믿음 유발)
2. "해당되신다면 프로필에서 신청" → 행동 유도
3. "예약 없이 결제하시면 상담 어려울 수 있습니다" → **긴박감/희소성**

### 4. 전환 구조
```
틱톡 영상 → "프로필 링크" → 블로그/상담 신청 → 유료 비대면 상담
```

### 5. 해시태그
- #사주 #운세 #사주점 #띠별운세 #사주이음
- 카테고리 키워드 + 브랜드 키워드 혼합

## 점운 적용 공식

### 점운 버전 제목 예시
- "소름 돋게 맞는 **[띠]** 올해 **재물복** 터지는 해"
- "**쥐띠·소띠·범띠** 2026년 놓치면 안 되는 운세"
- "AI가 분석한 **여자 [띠]** 올해 재물운 결과"

### 점운 버전 전환 구조
```
틱톡 영상 → jeomun.com → 무료사주 → 990원 결제
```
(비대면 상담 아닌 자동화 앱으로 전환 → 확장성 높음)

### 핵심 차이점
- 사주이음: 1:1 비대면 상담 (사람이 직접 상담 → 확장 한계)
- 점운: 앱 자동화 (무한 확장 가능) → 같은 광고로 훨씬 많은 전환
