앱 정식 오픈 전에 Firebase를 Blaze(종량제) 플랜으로 전환해야 한다.

**Why:** 무료 Spark 플랜은 저장 1GB·다운로드 10GB/월 제한 → 실 유저 생기면 금방 초과되어 앱이 동작 안 할 수 있음.

**How to apply:** 앱 오픈 일정 언급될 때마다 "Firebase Blaze 전환 하셨어요?" 반드시 확인시킬 것. 유저가 직접 잊지 말고 얘기해달라고 요청했음.
