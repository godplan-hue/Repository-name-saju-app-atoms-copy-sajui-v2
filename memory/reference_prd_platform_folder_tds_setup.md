# PRD 템플릿 + 플랫폼폴더 + TDS 다운로드 (2026-08-20 정리)

효주님 웨비나 4번 항목(새 앱 워크플로) 실행하려고 조사한 결과. 앱인토스 공식 사이트엔 "PRD 스킬" 다운로드 페이지가 따로 없음 — 효주님이 구글에서 찾은 건 일반 AI PRD 템플릿(GitHub에 여러 개 존재, 특정 하나로 안 정해짐). 그래서 우리 워크플로에 맞게 직접 정리함.

## 1. PRD 구술 템플릿 (다음 새 앱부터 이걸로 시작)

새 앱 아이디어 있을 때 Claude에게 이 순서로 5분 말하면 됨:
1. **뭘 만들고 싶은지** (한 문장)
2. **누가 씀** (타겟 유저, 몇 살, 어떤 상황)
3. **왜 궁금해하는지 / 왜 써야만 하는지** (안 쓰면 불편한 이유)
4. **필요한 화면 몇 개, 각 화면에서 뭘 함**
5. **돈은 어떻게 버는지** (무료+광고 / 990원 / 잠금)
6. **API 쓸지 안 쓸지** (우리는 기본 템플릿·정적데이터 우선, [[CLAUDE]] 절대원칙)

Claude가 이걸 구조화된 PRD 문서로 정리 + 빠진 부분 되물음. 이후 이 앱 관련 대화는 이 PRD를 기준으로 진행 → 매번 새로 설명 안 해도 됨.

## 2. 플랫폼 폴더 (MCP 토큰 절약) — 이미 하고 있음

효주님이 말한 "에빈토스 폴더 + 플랫폼 폴더"는 별도로 다운로드하는 게 아니라, 앱인토스 지식을 직접 문서로 정리해두고 MCP 대신 그 문서를 읽게 하는 방식.
**우리는 이미 이 방식을 쓰고 있음** — [[reference_toss_ai_miniapp_build_guide]], [[toss_app_build_guide]], [[project_toss_inapp_ad_guide_v2]], [[reference_toss_promotion_official_doc]] 등이 사실상 우리의 "플랫폼 폴더"임. 새로 만들 것 없음, 새 지식 생기면 계속 이 폴더에 추가하면 됨.

## 3. TDS(Toss Design System) 다운로드 — 정정됨 (2026-08-20 재확인)

> ⚠️ 이전 버전에서 "피그마 계정으로 로그인해서 복사(duplicate)해야 한다"고 썼던 건 틀린 정보였음. 웨비나 원문 재확인 결과 정정함.

- **실제 방식**: 앱인토스 개발자센터 사이트에 **zip 파일로 직접 다운로드** 가능 (피그마 로그인/복사 불필요 — 파일을 받는 단계는 그냥 다운로드임)
- 파일명: `TDS_Mobile_for_Apps_in_Toss_(2602).fig` (zip 안에 이 .fig 파일이 들어있음)
- 페이지: 개발자센터 "디자인 도구" 문서 쪽 (정확한 다운로드 버튼 URL은 사이트 구조상 자동으로 못 찾음 — `.html` 경로가 404 뜨는 페이지가 있어서 직접 검색해서 들어가야 함)
- **에스더님 하실 일**: 구글에서 "앱인토스 개발자센터 디자인 도구" 검색 → 해당 문서 페이지 들어가서 zip 다운로드 버튼 클릭 → 압축 풀면 `.fig` 파일 나옴 → 그 파일을 Claude(클로드 디자인 기능)에 업로드해서 20~30분 학습시키면, 그 다음부터 생성되는 화면이 토스 네이티브 스타일(버튼 둥글기·두께·색상 등)을 자동으로 따라감
- **로그인은 그 다음 단계에서만 필요**: `.fig` 파일을 직접 열어서 편집/확인하려면 피그마 앱(계정)이 있어야 함. 파일을 "받는" 것 자체는 로그인 없이 되는 다운로드임
- 라이선스: **앱인토스 개발/디자인/프로토타입 용도로만 사용 가능**, 다른 프로젝트 사용·상업적 활용·재배포 금지, 소유권은 Viva Republica(토스) — 위반 시 문제될 수 있음

## Why
에스더님이 "mcp tds등 찾아서 다운로드해서 저장해야하지 않아?" 물어봄. 조사해보니 PRD는 공식 파일이 없어 우리 워크플로용으로 직접 만들었고, 플랫폼폴더는 이미 하고 있던 것이었음. TDS는 처음엔 "피그마 계정으로 수동 복사해야 한다"고 잘못 안내했는데, 에스더님이 "MCP 다운로드하는거 있던데 PRD도 다운로드 있는거아냐?"라고 재차 확인해서 원문 웨비나 스크립트를 다시 읽었더니 실제로는 zip 파일 직접 다운로드 방식이었음 — 정정함.

**How to apply**: 다음 새 앱 기획할 때 PRD 구술 템플릿부터 사용. TDS는 에스더님이 개발자센터에서 zip 다운로드 후 Claude에 업로드해주시면 그때부터 활용. MCP는 별도로 다운로드할 게 없음 — [[reference_toss_ai_miniapp_build_guide]]에 이미 저장된 연결 명령어가 그대로 그 MCP임.
