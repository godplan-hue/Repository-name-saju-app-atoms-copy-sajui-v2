# 날씨 체크 (토스 미니앱) 수익 구조

**리뷰**: 4.3점 / 6,037개 (토스 탑 앱 수준)
**분석일**: 2026-08-08 에스더님 직접 캡처 분석

---

## 앱 구조 (3탭)

| 탭 | 내용 |
|---|---|
| 날씨 | 실시간 날씨 + AI 해석 + 옷차림 추천 + 미세먼지 + 시간별/주간 예보 |
| 운세 | 오늘 날씨와 궁합 좋은 띠 + 띠별 운세 순위 1~4위 + 점수 + 운 종류 |
| 미션 | 10개 앱 구경(5초씩) → 포인트 적립 (하루 최대 23P) |

---

## 핵심 수익 구조

### 사용자가 받는 것 (미끼)
- **연속 출석 보너스**: 5일 출석 시 총 20원 (1+3+1+5+10원)
- **미션 포인트**: 앱 구경 +1P / 광고까지 보면 +2P / 10개 완료 +3P 보너스 = 하루 최대 23원
- **모든 포인트 = 토스포인트 = 현금 1:1** (진짜 돈이지만 아주 작음, 월 최대 ~700원)

### 앱이 버는 것 (진짜 수익)
- **미션 탭 광고 수익**: 사용자가 광고 앱 5초 방문 → 그 앱(쿠팡/이니스프리 등)이 날씨 체크에 광고비 지불
- **사용자에게 2원 주고, 광고비로 수백원 받는 구조**
- **알림 권한**: "동의하고 알림받기" → 매일 날씨 알림 → 재방문율 극대화

### 재방문 유도 장치
- 연속 출석 보너스 (끊기면 리셋 → 다시 시작해야 함)
- 저금통 시스템 (쌓이면 이자처럼 증가)
- 행운의 연못 (동전 던져 소원 빌기)
- 피버 찬스 (한정 시간 보너스)
- 매일 날씨 알림 (오전 7:30)

---

## 날씨 데이터
- 기상청 실시간 API 사용 (공공데이터포털 무료)
- AI 날씨 해석 텍스트 제공
- 옷차림 추천 (아침/낮/저녁)
- 활동 추천 (환기/빨래/산책 시간대)
- 미세먼지 (미세/초미세/O3/CO/SO2)

---

## 점운 적용 전략

**차별화 포인트**:
- 날씨 + 오행 연결 ("비=水오행 상승 → 재물운 좋아요")
- 띠별 운세는 이미 점운이 갖고 있음
- 사주 기반 날씨 활동 추천 ("금일주 → 맑은 날 계약 좋아요")

**필요한 것**:
1. 기상청 무료 API (날씨 데이터)
2. 토스 비즈 월렛 (미션 포인트 시스템 - 30만원)
3. 광고 미션 탭 구현

**결론**: 미션 탭 광고 수익이 핵심. 사용자한테 소액 포인트 주면서 광고비로 훨씬 더 버는 구조.
