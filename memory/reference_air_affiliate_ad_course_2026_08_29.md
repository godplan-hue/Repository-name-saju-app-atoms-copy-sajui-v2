에스더님이 "에어"라는 강사(연평균 50억+ 광고 집행 경험, 당근 제휴마케팅으로 월 1000만원대 수익)의 무료 전자책 3종 링크를 공유하며 저장 요청. 점운 당근/메타 광고 운영에 바로 적용 가능한 실전 방법론.

## 핵심 철학
> "광고는 세팅이 아니라 테스트 싸움이다. 잘하려고 하지 말고 많이 돌려서 잘 되는 걸 찾아라."
- 완벽한 소재 하나에 매달리지 말고, 여러 개 돌려서 반응 좋은 걸 찾는 방식이 정석이라는 주장.

## 1. 광고 제작 전 시장조사 — 경쟁사 광고 라이브러리 3곳
- **메타 광고 라이브러리**: facebook.com/ads/library — 페이스북/인스타 광고 전체 검색, 광고주/예산/노출 데이터까지 확인 가능
- **구글 광고 투명성 센터**: adstransparency.google.com
- **틱톡 광고 라이브러리**: library.tiktok.com/ads (아직 유럽 광고 위주)
- 방법: 잘 되는 경쟁사 광고를 찾아서 "왜 이게 팔리는가"를 계속 질문 → 강점(혜택/무료체험/1+1/타임어택 같은 후킹 요소)을 뽑아냄

## 2. 광고 문구 제작 — ChatGPT 프롬프트 공식
역할부여(매체 정하기) → 광고 종류 정하기 → 시장조사에서 찾은 강점 넣기 → "30자 이내로 강력한 후킹 문구 짜줘"
- 예시 적용: "제휴사이트 무료사주 이벤트 선택 → ChatGPT로 대본 작성 → AI영상 제작 + 후킹문구 삽입 → 광고 완성" — **사주를 예시로 직접 들고 있음**, 점운 당근광고 문구 제작에 그대로 쓸 수 있는 순서

## 3. 당근비즈니스 집행 순서
전문가 모드 로그인 → 캠페인 만들기 → AI영상 업로드 → 광고 제목 30자 이내(짧고 강렬하게, 어려우면 위 ChatGPT 공식 사용)

## 4. 제휴사이트(DB 마케팅) 구조 — 디비센스(dbsense.kr) 예시
제휴사이트 = 광고주 영업+홈페이지 자동생성을 대신해주는 플랫폼. 좋은 제휴사이트 판별 기준은 "소통이 잘 되는지".
- 팀제도(팀원 모집 시 추가수익), 홈페이지 무료제공, 카페/유튜브로 노하우 공유, 카톡 빠른상담, 실력자에게 비밀캠페인(고수익률) 공개, 출금인증 시 기프티콘 지급
- 유사 사이트: 텐핑, 디비디비딥, 리플알바 — 한 곳에 정착하지 말고 여러 곳 비교

## 5. 쓰레드(Threads) 알고리즘 공략 요점
- **계정 생성 직후 5일간은 절대 좋아요/댓글/리포스트 하지 말 것** — 초반 타 게시물 활동이 오히려 정지 사유가 되는 것으로 관찰됨. 내 글만 올리는 건 초반부터 해도 무방.
- 5일 후부터 "스하리"(품앗이형 상호작용) 시작
- 콘텐츠 비율: 일상/정보글 6 : 제휴홍보글 3 — 홍보글만 있는 계정보다 이 비율이 실제로 더 잘 터졌다는 경험담
- 이 방식+제휴마케팅 결합으로 강사 본인 월 1000만원 달성 주장

## 점운 적용 포인트
- 당근 광고 캠페인 만들 때마다 위 3개 광고 라이브러리에서 사주/운세 계열 경쟁 광고를 먼저 찾아보고 "왜 반응이 좋은가"부터 분석 → 후킹 문구는 ChatGPT 공식대로 뽑기
- [[project_first_ad_driven_db_inflow_2026_08_29]]에서 이미 당근 "990원 사주" 캠페인이 첫 클릭·DB·결제 전환을 만든 상태 — 이 문서의 "많이 돌려서 반응 좋은 것 찾기" 원칙대로 문구/썸네일 여러 버전 A/B 테스트 권장
- [[reference_karrot_ad_photo_title_tips_2026_08_28]](당근 사진/제목 팁)과 함께 참고
- 쓰레드 계정을 점운 홍보용으로 새로 판다면 "5일간 내 글만, 좋아요/댓글 자제" 규칙과 "일상 6 : 홍보 3" 비율 그대로 적용 가능

**Why**: 당근 제휴마케팅으로 실제 수익을 내고 있다는 강사의 무료 강의자료 전문 — 지금 막 성과가 나기 시작한 점운 당근광고 캠페인에 바로 적용할 수 있는 실전 노하우라서 저장.
**How to apply**: 다음에 당근/메타 광고 소재나 문구를 새로 만들 때, 또는 쓰레드 계정을 새로 운영할 때 이 문서의 순서(경쟁사 라이브러리 조사 → ChatGPT 후킹문구 공식 → 여러 버전 테스트)를 먼저 참고할 것.
