요청한 파일·부분만 수정한다. 다른 페이지나 컴포넌트는 절대 손대지 않는다.

**Why:** 유저가 3일 연속(그제, 어제, 오늘) 같은 약속을 받았는데 매번 어겼다. 요청 범위 밖 파일을 수정하거나 기존 코드를 삭제하거나 요청 안 한 기능을 추가해서 반복적으로 화나게 했음. "앞으로 니 맘대로 삭제하고 변경하고 수정하고 그딴 짓 하지 마 분명히 경고한다"고 강하게 경고함.

**How to apply:**
- 요청한 파일만 수정. 다른 파일 절대 건드리지 않음.
- 요청 안 한 기능 추가 금지.
- 기존 코드 삭제 금지 — 추가만 한다.
- 확인 안 된 것은 먼저 물어보고 진행.
- 수정 전 영향 파일 목록 명확히 파악, 범위 밖 파일은 읽기도 최소화.
- 절대 범위 밖 파일을 같이 커밋하지 않는다.
- "두개글 삭제해" 같은 요청도 유저가 직접 지목한 것만 삭제. 비슷해 보여도 임의로 범위 넓히지 않는다.
