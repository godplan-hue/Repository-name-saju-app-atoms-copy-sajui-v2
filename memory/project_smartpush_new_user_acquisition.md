## 정정 사항 (2026-08-13)

이전에 "스마트발송은 내 앱에 방문 이력 있는 유저에게만 보낼 수 있다"고 알고 있었으나 틀렸음. 에스더님이 스마트발송 화면에서 직접 확인:

- "광고성" 탭 안에 **"신규 유입 유도하기"** 섹션이 별도로 존재 — 방문 이력 없는 신규 유저에게도 발송 가능
- MBTI 기준 이미 발송 중: 소재A "나의 MBTI 성격유형을 무료로 테스트해요" 2,346명 발송/CTR 0.68%/클릭16, 소재B "137명이 MBTI에 도전했어요" 2,326명 발송/CTR 1.42%/클릭33
- 발송완료 인원(2,300명대)이 MBTI 실제 방문자 수보다 훨씬 많음 → 비방문 신규유저 대상 발송이 실제로 작동 중인 근거

**Why:** 새 토스앱 올릴 때마다 "방문자 200~300명 먼저 모아야 스마트발송 가능"이라 전제하고 [[project_biz_wallet_strategy]] 비즈월렛부터 태우려 했는데 이 전제가 틀렸음 — 신규 유입 유도하기로 처음부터 무료 노출 가능.
**How to apply:** 새 토스 앱 출시 직후에도 비즈월렛 태우기 전에 먼저 스마트발송 "신규 유입 유도하기" 카테고리부터 확인·활용할 것. 무료 10만건 한도(9월까지, 워크스페이스당) 안에서 신규앱 알리는 용도로 우선 사용.

## 채널 전략 분리 (2026-08-13 확정)

- **jeomun.com(점운) = 빠른 결제 전환 목적**: 구글 검색광고(이미 찾고 있는 사람 타겟) + 알림톡 재발송(재방문 유도) 중심. Toss Ads는 봇트래픽 의심+비용 대비 효과 낮아 배제.
- **토스 미니앱들 = 매일 재방문+광고시청 목적**: 스마트발송 "신규 유입 유도하기"(무료, 방문이력 불필요) 우선 사용 → 필요시 비즈월렛(1원 리워드, 5만원부터) 추가. 일기류 앱은 [[project_ad_structure_master_2026_08_13]]의 2천포인트(출석+광고3회) 구조로 재방문 습관화.
