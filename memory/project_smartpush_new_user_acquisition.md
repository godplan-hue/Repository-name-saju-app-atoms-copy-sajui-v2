## 정정 사항 (2026-08-13)

이전에 "스마트발송은 내 앱에 방문 이력 있는 유저에게만 보낼 수 있다"고 알고 있었으나 틀렸음. 에스더님이 스마트발송 화면에서 직접 확인:

- "광고성" 탭 안에 **"신규 유입 유도하기"** 섹션이 별도로 존재 — 방문 이력 없는 신규 유저에게도 발송 가능
- MBTI 기준 이미 발송 중: 소재A "나의 MBTI 성격유형을 무료로 테스트해요" 2,346명 발송/CTR 0.68%/클릭16, 소재B "137명이 MBTI에 도전했어요" 2,326명 발송/CTR 1.42%/클릭33
- 발송완료 인원(2,300명대)이 MBTI 실제 방문자 수보다 훨씬 많음 → 비방문 신규유저 대상 발송이 실제로 작동 중인 근거

**Why:** 새 토스앱 올릴 때마다 "방문자 200~300명 먼저 모아야 스마트발송 가능"이라 전제하고 [[project_biz_wallet_strategy]] 비즈월렛부터 태우려 했는데 이 전제가 틀렸음 — 신규 유입 유도하기로 처음부터 무료 노출 가능.
**How to apply:** 새 토스 앱 출시 직후에도 비즈월렛 태우기 전에 먼저 스마트발송 "신규 유입 유도하기" 카테고리부터 확인·활용할 것. 무료 10만건 한도(9월까지, 워크스페이스당) 안에서 신규앱 알리는 용도로 우선 사용.

## 채널 전략 분리 (2026-08-13 확정)

- **jeomun.com(점운) = 빠른 결제 전환 목적**: 구글 검색광고(이미 찾고 있는 사람 타겟) + 알림톡 재발송(재방문 유도) 중심. Toss Ads는 봇트래픽 의심+비용 대비 효과 낮아 배제.
- **토스 미니앱들 = 매일 재방문+광고시청 목적**: 스마트발송 "신규 유입 유도하기"(무료, 방문이력 불필요) 우선 사용 → 필요시 비즈월렛(1원 리워드, 5만원부터) 추가. 일기류 앱은 [[project_ad_structure_master_2026_08_13]]의 2천포인트(출석+광고3회) 구조로 재방문 습관화.

## ⭐⭐⭐ 2026-08-21 확정 — 스마트발송 10만건/일 한도는 워크스페이스 전체 합산, 적용 대상 4개 앱으로 확정

에스더님이 콘솔에서 직접 확인·재질문: "우리워크스페이스당 10만건 스마트발송이되잔아 근데 앱당이아니라 모든앱다합쳐서10만건인데... 17개앱다신청하면 실제로9월말까지얼마안되 워크스페이스당이면 한개앱이아니라모든앱인거맞지?" → 이후 "혹시 각앱당10만건을주는건아니겟지저번애문의하니워크스페이스당이고추가는없다더라고"로 재확인.

- **확인**: 스마트발송 무료 10만건/일 한도는 **워크스페이스 전체 합산**(17개 앱 다 합쳐서 10만건) — 앱 개별 한도가 아니고, 토스 측에 문의한 결과 추가 배정도 없음. 위 20번째 줄에 이미 "워크스페이스당"으로 기록돼 있었고, 이번에 에스더님이 콘솔+문의로 재확인함.
- **결정**: 한도가 공유되므로 17개 전부에 스마트발송을 걸면 9월 말까지 배분이 얼마 안 남음 → **적용 대상을 4개 앱으로 집중**: MBTI, 직운(jigun), 합격자소서(resume), 다이어트(diet) — [[project_biz_wallet_strategy]]의 비즈월렛 노출 4개 앱 목록과 동일하게 맞춤.
- **사주(saju) 포함 여부**: Claude가 매출 대표 앱으로서 포함을 고려해볼 만하다고 제안했으나, 에스더님 답변 — "사주는 안에 수정할게 넘 많아서 언제 오픈할지 몰라, 오픈하면 그때 생각해보자". 즉 사주 앱은 내부 수정사항이 아직 많이 남아 정식 오픈 시점이 불확실 → 스마트발송 포함 여부는 **사주 오픈 시점에 다시 논의**, 지금은 4개 앱 목록에서 제외.

**Why:** 무료 한도가 워크스페이스 단위로 공유돼 앱을 늘릴수록 앱당 배분량이 줄어듦 — 비즈월렛과 같은 4개 앱(결제 매출이 실제로 나는 앱)에 자원을 집중하는 것이 효율적이라 판단.
**How to apply:** 새 토스 앱 스마트발송 세팅 전에 이 4개 앱 목록부터 확인. 사주(saju) 추가는 사주 앱이 정식 오픈될 때 에스더님이 먼저 꺼낼 때까지 기다릴 것 — 먼저 제안하지 말 것.
