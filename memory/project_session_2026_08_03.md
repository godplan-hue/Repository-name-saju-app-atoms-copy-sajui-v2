## 앱인토스 8월 바이브코딩 챌린지

- **기간**: 2026년 8월 3일(월) ~ 8월 26일(수)
- **테마**: 하찮아도 괜찮아
- **상금**: 1등 300만원 / 2등 각 150만원(2명) / 3등 각 50만원(5명)
- **노출 혜택**: 9월 첫째주~9월 27일 챌린지 전용 테마 지면 노출 (3000만 유저)

### 출품 자격 규칙

- 16개 앱 전부 콘솔에 올려져 있지만 실제 출시(심사통과)된 건 2개뿐
- **앱인토스에 문의 중**: "7월에 신청한 앱 중 올리긴 했지만 출시 안 한 앱은 이번 8월 챌린지에 출품할 수 없나요?"
- 확실히 가능한 것: 아직 신청서 안 낸 새 앱

## 신규 앱 4개 확정 (8월 챌린지 출품용)

> 목적: 챌린지 출품 + 총 20개 앱 (16+4) → 크로스프로모 4×5 그리드 완성

### 1. 오늘의 핑계 (jeomun-excuse)
- **컨셉**: 상황 선택 → 완벽한 핑계 생성
- **상황**: 지각 / 약속취소 / 연락두절 / 숙제미완성
- **강도**: 순한맛 / 중간맛 / 살인적인 핑계
- **결과**: 핑계 문장 2~3줄 + 설득력 점수
- **재미 요소**: 슬롯머신 애니메이션 + 설득력 게이지 바 + "이 핑계로 살아남은 N명" 카운터 + 더 강한 핑계 뽑기
- **경쟁**: 한국 시장에 없음 (블루오션)
- **바이럴**: 친구한테 핑계 카톡 공유

### 2. 나쁜 운세 (jeomun-badfortune)
- **컨셉**: 생년월일 입력 → 의도적으로 나쁜 운세만 말해줌
- **결과**: 오늘/내일/이번주 한 줄씩 (점점 더 나빠짐)
- **재미 요소**: 어두운 카드 뒤집기 + "다시 뽑으면 더 나빠질 수 있음" 경고 + 다시 뽑기
- **바이럴**: 친구한테 저주 보내기

### 3. 귀찮음 지수 측정기 (jeomun-lazy)
- **컨셉**: 5문항 클릭 → 귀찮음 레벨 측정 (1~100점)
- **결과**: 레벨명 + 드러누운 고양이 그림 + "나보다 더 귀찮은 사람 N명"
- **재미 요소**: 로딩바가 일부러 느릿느릿 차오름 (귀찮음 컨셉)
- **바이럴**: 직장인 공감 100%

### 4. 오늘 뭐 먹지? (jeomun-food)
- **컨셉**: 기분/날씨/상황 선택 → 음식 추천
- **결과**: 음식명 + 이유 1~2줄
- **재미 요소**: 슬롯머신 돌아가다가 딱 멈춤 + "오늘 이거 먹은 N명"
- **오행 연결**: 점운 브랜드 자연스럽게 노출
- **재방문율**: 매일 열어보는 앱

### 공통 요소 (모든 앱)
- 다시 뽑기 버튼
- N명 카운터 (사회적 증거)
- 카카오톡 공유 버튼
- 전면 광고 + 배너 광고
- API 없음 (순수 템플릿)
- 각각 하루면 완성 가능

### 결과 길이 원칙
- 스크린샷 한 장에 다 나와야 함
- 짧을수록 좋음 (길면 공유 안 함)
- "엄마 밥 줘" 에너지 — 공감 한 줄로 승부

**Why:** 챌린지 우승보다 챌린지 지면 노출(9월 한 달)이 진짜 목적. 3000만 유저 노출 = 마케팅비 0원.
**How to apply:** 4개 앱 모두 8월 26일 전 빌드+콘솔 등록 완료해야 함.
