## 노출이 되는 구체적 경로

```
토스 앱 켜면
├── 홈화면 "추천 미니앱" 섹션 → 자동 노출
├── 혜택탭 → 프로모션 설정 시 노출 (30만원)
├── 검색창 → 키워드로 검색 시 노출
└── 푸시 알림 → 토스가 직접 유저에게 발송
```

**우리 앱은 지금 이미 1번(추천)과 3번(검색) 구조 안에 있음**

## 성공 비법 7가지

### 1. 콜드 스타트가 없다
일반 앱스토어에 올리면 아무도 모름 → 토스는 출시하자마자 3천만 유저에게 노출됨

### 2. 완벽하지 않아도 된다
- 자몽다: 실무경험 0, 3일마다 업데이트
- 디스팟: 5일 만에 출시
- **"내가 준비를 다 마치면, 그때는 이미 늦었을 가능성이 크다"**

### 3. 리텐션이 핵심
- 마나바바 기준: **D+1 리텐션 40% 이상**이면 성공
- 운세·사주는 매일 보는 습관성 콘텐츠 → 리텐션 유리
- 토스 알고리즘이 리텐션 높은 앱을 더 밀어줌

### 4. 인앱결제 + 인앱광고 = 수익 두 배
- **인앱결제**: 유저가 우리한테 돈 냄 (990원)
- **인앱광고**: 다른 광고주가 우리한테 돈 냄 (노출당 수익)
- 토스 유저들 결제 친숙 → 전환율 높음

### 5. 나쁜 리뷰도 자산
- 자몽다: "안 좋은 리뷰가 없으면 서비스를 그칠 생각도 못했을 것"
- 리뷰 = 무료 컨설팅

### 6. 데이터 대시보드 적극 활용
- DAU, OS, 성별/연령대, 인앱/광고 매출 추이 → 실시간 확인
- 데이터로 의사결정 → 팀 내 싸움 줄어듦

### 7. OBT 기간 지금이 기회
- 오픈베타서비스 기간: **수수료 0% + 무료 광고** 제공
- 입점 미니앱 수가 아직 적음 = **블루오션**
