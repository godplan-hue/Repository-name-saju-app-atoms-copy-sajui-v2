**증상**: 에스더님이 "토스 다이어트 밑에 광고 잘림 / 메인빼고 페이지들마다 밑에 베너 카테고리글로막혀서안보임 / 메인빼고모든페이지하단이다안보이더라3-4페이지"라고 보고.

**원인**: `jeomun-diet/src/App.tsx`에서 탭 콘텐츠를 감싸는 div가 닫힌 뒤(1761줄) 공용 `diet-banner-ad` 배너(1764줄)가 렌더링되는데, 그 뒤에 "오늘" 탭에만 100px 하단패딩짜리 회사정보 푸터(1767줄)가 붙어서 여유공간을 만들어줌. 검색/프리미엄/기록 3개 탭은 그 푸터가 없어서 배너 바로 뒤에 곧장 `position:fixed` 하단 탭바(1777줄)가 겹쳐서 배너 전체가 가려짐.

**수정**: `diet-banner-ad` div에 `marginBottom: tab === "today" ? 0 : 100`을 추가 — 오늘 탭은 기존 그대로, 나머지 3개 탭만 배너 아래 100px 여백을 줘서 탭바에 안 가리게 함. commit `303a86d`, `jeomun-diet` 저장소.

**Why**: 광고가 안 보이면 무효 클릭/노출 처리 정책 리스크 + 수익 품질 저하 우려로 수정 결정(에스더님 승인 "그래그럼수정해줘").

**How to apply**: 새 토스 미니앱에서 탭 전환형 레이아웃 쓸 때, 공용 배너 div가 탭별로 하단 여유공간이 다르면 특정 탭에서만 고정 탭바에 가려질 수 있음 — 배너 아래 여백을 탭 조건 없이 고정값으로 통일하거나, 탭마다 최소 탭바 높이만큼 여백을 보장할 것. 빌드 후 토스 콘솔 재업로드 필요.
