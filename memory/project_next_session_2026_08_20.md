## 3. MBTI 유료 4개 콘텐츠 + 잠금목록 전체노출 + 전체앱 로그·광고전환 + 첫진입광고 제거 (내일, 2026-08-20 논의)

- **MBTI 새 유료항목 4개 추가 예정**: 최악궁합 TOP3+이유 / 나와 완전히 똑같은 유명인 매칭 / 테토-에겐 반대기운 매칭(연애스타일 제외) / 썸·짝사랑 상대 마음 몰래 훔쳐보기(상대방 생년월일 신규 입력 필요)
- **잠금 미리보기 문구 — 핵심 결정**: 지금 잠금박스에는 기존 5개 항목 이름만 보임. 여기에 새 4개까지 합쳐 **9개 항목 이름 전부**를 리스트로 보이게 할 것. 내용까지 미리 주는 게 아니라 "이름만" — 근데 그 이름 리스트 자체가 지금 안 보이니까(또는 부족하니까) 뭘 주는지 몰라서 결제를 안 하는 거라는 게 에스더님 지적. **무료로 내용을 더 주자는 얘기가 아니라, 유료 안에 뭐가 들었는지 잠금 화면에서 확실히 다 보여주자는 것 — 헷갈리지 말 것**
- **유료 콘텐츠 품질 기준**: 답변은 길고 "확실한 결과"를 주는 단정적인 문장이어야 함 (기존 5개 유료항목과 같은 톤·분량으로 새 4개도 작성)
- **전체 앱 로그(Analytics) 설치**: 결제 있는 앱뿐 아니라 결제 없는 앱도 전부 로그 설치 — 이탈 지점 파악 목적 ([[reference_toss_webinar_hyoju_growth_secrets]] "로그 0/19개" 갭 대응). 순서: 로그부터 전체앱 설치 → 데이터로 이탈지점 확인 → 그 다음 광고구조 전환
- **전면광고→리워드광고 전환**: 결과지 나오는 앱들 대상, 전면광고를 리워드광고로 바꿔 "결제하고싶게 만드는 결제형" 플로우를 별도로 추가하는 방향. **근거(에스더님 확정)**: 결과지는 어차피 무료로 주는 거라 리워드광고를 넣어도 사람들이 봄 — 광고 보기 싫은 사람은 자연스럽게 990원 결제로 넘어가는 구조가 됨 (광고=무료길, 결제=빠른길)
- **적용 범위 정정(에스더님, 2026-08-20 추가)**: "17개 앱 전부"가 아니라 **완전 무료 앱은 이 전환 대상에서 제외 — 그대로 둘 것**. 완전 무료 앱(궁합·행운번호·별자리 등, [[CLAUDE]] 서비스분류표 "🆓 완전 무료" 항목) 은 이미 결제로 유도할 유료 콘텐츠 자체가 없어서 "광고=무료길/결제=빠른길" 구조가 성립 안 함 → 손대지 않음. 리워드광고 전환은 **유료 결제 유도가 있는(또는 생기는) 앱들만** 대상. MBTI는 이번에 유료 4개 콘텐츠가 추가되므로 대상에 포함됨.
- **MBTI·다이어트 첫진입광고 제거**: ✅ 이미 완료됨 (이전 세션에서 처리됨) — 재작업 불필요, 할 일 목록에서 제외
- **잠금박스 문구 길이 — 추가 결정**: 기존 5개 항목도 이름만 있어서 너무 짧음 → 9개 항목(기존5+신규4) 전부 한 줄 이름이 아니라 왜 궁금한지 설명이 붙은 문장으로 길게 작성. 단, 이상한/깨진 문장 나오면 안 됨 — 직접 검수해서 작성
- **17개 앱 로그+광고전환 진행 방식 — 에스더님 명시적 지시**: 하나씩 넣고 결과 보면서 다음 앱 진행하는 방식 X — 너무 힘들어서 반복 못 함. **패턴 하나 만들어서(먼저 MBTI에 적용+빌드확인) → 17개 앱에 그대로 한 번에 복사 적용**하는 방식으로 진행하기로 함. 앱별로 결과 보고 판단하지 않고 한 번에 밀고 끝내는 것으로 확정

## Why
실제 결제가 발생했는데 유입경로 추적이 안 되는 상태로 구글광고를 켜면 돈만 쓰고 뭐가 효과있는지 모르게 됨. 랭딩페이지는 이미 만들어둔 자산인데 핵심 홍보 채널(토스 링크)이 빠져있을 가능성이 있어 방치하면 손해. MBTI는 유료 콘텐츠가 잠금화면에서 뭐가 들었는지 안 보여서 결제 전환이 낮을 수 있다는 게 에스더님 지적 — 로그가 없어서 실제로 어디서 이탈하는지도 확인이 안 되는 상태.

**How to apply**: 다음 세션 시작 시 이 문서부터 확인. 1번(전환추적)은 광고 켜기 전 반드시 선행, 2번(랜딩 토스링크)은 확인부터 시작해서 필요한 만큼만 제작, 3번(MBTI+로그+광고전환)은 ①→② 순서로 진행 — 17개 앱은 하나씩 확인하며 진행하지 말고 패턴 검증 후 한 번에 적용할 것 (에스더님 체력 문제로 반복 불가, 명시적 지시).
