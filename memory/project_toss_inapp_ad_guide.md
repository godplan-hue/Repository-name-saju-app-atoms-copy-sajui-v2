## 핵심 요약 (새 세션 빠른 참고용)

- **인앱 광고** = 유료 결제 없이 첫날부터 수익 가능
- 수익 공식: 노출수 × eCPM ÷ 1,000
- 예: 10만번 노출 × ₩5,000 eCPM = ₩500,000
- 3가지 유형: 배너(낮은 단가) / 전면형(중간) / 리워드(가장 높은 단가)
- **점운 적용**: MBTI 결과 직후 → 전면형 / 다이어트 메인 → 배너 / "운세 한 번 더" → 리워드

## 수익화 / 인앱 광고

인앱 광고는 유료 결제 없이도 앱에서 수익을 만드는 가장 빠른 방법이에요.
앱인토스에 광고를 등록하면, 별도의 결제 기능 없이도 앱 출시 첫날부터 수익을 만들 수 있어요.

### 인앱 광고란 무엇인가요
인앱 광고는 앱 화면 안에서 사용자에게 노출되는 광고예요.

광고 수익은 두 가지로 결정돼요:
- 얼마나 많이 보여줬는지 (노출 수)
- 한 번 보여줄 때 얼마를 버는지 (eCPM)

**핵심 공식**: 예상 수익 = 노출 수 × eCPM ÷ 1,000

예) 100,000번 노출 × ₩5,000 eCPM ÷ 1,000 = ₩500,000

### 인앱 광고 유형

#### 1. 전면형 광고
- 화면 전환 시점에 전체 화면으로 나타나는 광고
- 특징: 강제 노출 (사용자가 반드시 보게 됨)
- 추천 위치: 화면 이동 직전/직후 (예: 결과 화면 → 다음 단계)
- 노출 수: 중간 / eCPM: 중간

#### 2. 리워드 광고
- 사용자가 직접 '광고 보기'를 선택하면 재생되는 광고
- 특징: 자발적 시청 + 높은 집중도
- 추천 위치: 보상이 필요한 순간 (예: 추가 혜택, 이어하기)
- 노출 수: 낮음 / eCPM: 가장 높음

#### 3. 배너 광고
- 화면 상단이나 하단에 고정되어 지속적으로 노출되는 광고
- 특징: 항상 노출됨 (자동으로 쌓이는 트래픽)
- 추천 위치: 메인 화면, 리스트 화면
- 노출 수: 가장 많음 / eCPM: 가장 낮음

**세 가지 조합이 가장 효과적**:
- 배너 → 노출 수 확보 (기본 수익)
- 전면형 → 안정적인 수익 보완
- 보상형 → 높은 단가로 수익 상승

### 콘솔 설정 순서
1. 사업자 정보 등록
2. 정산 정보 입력 (검토 영업일 2~3일)
3. 광고 그룹 생성 (유형 선택: 배너/전면형/리워드)
4. 광고 그룹 ID로 개발 연동

**접속 경로**: 앱인토스 콘솔 → 워크스페이스 선택 → 미니앱 선택 → 인앱 광고

### 광고 그룹 이름 예시
- 메인_전면광고
- 게임종료_리워드광고

### 꼭 확인할 것
- 테스트 시 반드시 테스트용 ID 사용 (운영 ID 사용 시 제재)
- 광고 그룹 ID는 구글 등록까지 최대 2시간 소요
- 앱인토스 인앱 광고는 구글 애드몹 광고 정책 따름

### 정산 구조
- 매월 1일~말일 수익 → 다음 달 1일 업데이트 → 해당 월 말일 입금

### 광고 분석 (SDK 2.7.0 이상 필요)
- 광고 요청 → 수신 → 노출 시도 → 노출 성공 단계별 확인
- 광고 유형별 노출 빈도 + eCPM 추이 확인
- 접속: 앱인토스 콘솔 → 미니앱 → 인앱 광고 → 분석 탭

### 활용 팁
- 노출 빈도 올랐는데 eCPM 떨어지면 → 광고 피로도 원인
- 리워드 광고 eCPM이 가장 높으면 → 리워드 비중 늘리기
- 배너 광고는 아직 분석 탭 미지원
