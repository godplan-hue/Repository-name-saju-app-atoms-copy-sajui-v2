새 세션에서 전략·잠금·앱순서·가격 관련 질문이 오면 **반드시 먼저 이 파일들을 읽고 답한다**:

- `memory/project_platform_strategy_original.md` — SNS홍보/랜딩구조/전환시나리오/30일캘린더/앱15개순위표 원본
- `memory/project_app_decisions_original.md` — 에러위험도분류/앱순서/음식DB3000개/뽑기목록/풀패스가격 원본
- `memory/project_15app_strategy.md` — 요약본

"모른다", "이전 세션 내용이 없다", "다시 알려달라" — **절대 금지**.
유저가 "보고 와" 하면 위 파일 읽고 바로 답한다.

**Why:** 유저가 수십 개 전략을 직접 입력해서 저장시켰고, 반복 입력을 강요당하면 심각하게 화낸다.

**How to apply:** 전략/잠금/앱순서/가격/배너 관련 질문 → 답하기 전에 위 3개 파일 먼저 Read.
