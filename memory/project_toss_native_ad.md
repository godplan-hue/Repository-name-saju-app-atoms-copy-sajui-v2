## 신규 네이티브 광고 (2026-07-28 오후 2시 오픈)

- 기존 배너: 정해진 지면에 노출
- **네이티브**: 유저가 탐색하는 흐름 안에서 자연스럽게 노출 → 클릭률 높음
- **과금 방식**: 브릿지 페이지 CTA 클릭 시에만 과금 (단순 노출·첫 클릭 무료)
- **입찰**: tCPA (목표 전환당 비용) — 오토 타겟팅

### 캠페인 3종
| 목적 | 입찰 | 특징 |
|---|---|---|
| 구매 유도하기 | tROAS | Pixel 또는 MMP 연동 |
| **앱 설치 유도하기** | tCPA | MMP + App Scheme + 트래킹 링크 필요 |
| **잠재고객 모으기** | tCPA | 토스 양식 사용 — MMP 불필요 |

---

## ⚠️ 미니앱 제약사항

**앱 설치 유도하기 → 미니앱은 어려울 가능성 높음**
- MMP SDK: WebView 기반 미니앱에 설치 불가
- App Scheme: 토스 미니앱에는 Play Store/App Store 기준 App Scheme 없음
- 이 광고 유형은 네이티브 앱(Android/iOS) 기준으로 설계된 상품

**미니앱으로 할 수 있는 것:**
1. **잠재고객 모으기 (토스 양식)**: 이름·전번 수집 → 앱 실행 안 됨, 리드만 수집
2. **구매 유도하기**: Pixel 연동 가능 여부 확인 필요

## 점운 집행 계획

- **대상 앱**: MBTI 점운 + 다이어트 점운 + 감정일기 점운 (3개 동시)
- **예산**: 각 5만원씩 (총 15만원 테스트)
- **타이밍**: 첫날 오픈 = 경쟁 광고주 없음 → 선점 유리

### 내일 2시 할 것
1. tossads.toss.im 접속
2. 캠페인 만들기 → 미니앱 선택 가능한지 확인
3. 가능하면 **앱 설치 유도하기**, 안 되면 **잠재고객 모으기** 선택
4. 막히면 토스애즈 고객센터에 "미니앱 네이티브 광고 가능 여부" 문의
