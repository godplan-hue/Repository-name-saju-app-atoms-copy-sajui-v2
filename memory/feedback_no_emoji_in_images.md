토스 앱스토어 이미지/설명 텍스트에 이모지 절대 금지. 이모지 때문에 승인 여러 번 거부당함.

**Why:** 토스 콘솔 이모지 불가 정책. 승인 거부 반복됨. 에스더님이 이미지 여러 번 다시 만들어야 했음.
추가 사례(2026-07-26): 상세 설명에 ✔ 이모지 넣었더니 에스더님이 "이미지에 이모지 넣어야 하는 줄 알고" 이미지 50번 다시 만드는 사태 발생. 설명 텍스트 이모지도 혼란의 원인이 됨.

**How to apply:**
- 스크린샷, 앱 로고, 상품 이미지 — 이모지 없이 순수 텍스트만
- **상세 설명(텍스트)도 이모지 절대 금지** — ✔ · ✅ · 🔥 등 일체 금지. 순수 텍스트 + 기호(- · |)만 사용
- 스크린샷 배경은 감성적인 배경 (어두운 그라디언트, 자연 사진 등) 사용 권장
