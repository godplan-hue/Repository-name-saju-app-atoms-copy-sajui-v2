## 공지 내용 (2026-08-28 릴리즈)
- 미니앱 상세화면 + 문의답변에 "제작자 이름"이 노출되는 신규 기능
- 워크스페이스 단위 1개 설정 → 등록한 모든 미니앱(에스더님 기준 22개)에 동일하게 적용
- 사용자가 이 이름을 누르면 같은 제작자의 다른 미니앱 전체를 볼 수 있음 (브랜드 노출 효과)
- 설정 위치: 콘솔 > 내 정보 > 제작자 정보 (워크스페이스 생성 시에도 등록 가능)
- 제약: 공백포함 10자 이내, 한글/영문/숫자만 (특수문자·이모지·타 브랜드 도용 불가), 반영까지 ~10분
- 기존에 회사명을 입력해둔 곳은 그 회사명이 기본값으로 자동 노출됨

## 결정/권장 (Claude 제안, 콘솔 미확인 상태)
CLAUDE.md 브랜드 통일 원칙("브랜드는 계속 점운으로 통일한다")에 따라 제작자 이름도 **"점운"**으로 맞추는 걸 권장함. 사업자명(기획의신)이 기본값으로 들어가 있을 가능성 있음 — 콘솔에서 확인 후 "점운"으로 변경 필요.

## 남은 작업
- [ ] 에스더님이 콘솔 > 내 정보 > 제작자 정보에서 실제 등록된 값 확인
- [ ] "점운"이 아니면 "점운"으로 변경 (코드 작업 아님, 콘솔에서 직접 설정)
