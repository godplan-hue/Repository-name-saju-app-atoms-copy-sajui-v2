에스더님 지시: "앞으로 공유버튼 만들 때는 MBTI처럼 친구한테 공유하기 이런 문구가 더 좋은거같아, 거기에 '나 이거 손절각 몇 프로래' 이런식으로 붙이면 암튼 MBTI식으로 붙여줘."

**규칙**: 새로 만드는 모든 앱의 공유 버튼은
1. 버튼 문구: "친구한테 공유하기" 계열 (MBTI 앱 방식)
2. 공유되는 텍스트에 **결과 개인화 훅**을 넣는다 — 예: "나 이거 손절각 몇 프로래", "나 이거 OOO 나왔어" 식으로 본인 결과 수치/유형을 직접 노출해서 호기심 유발
3. 참고 원본: `app/mbti/result/[id]/page.tsx`의 공유 버튼 구현 방식

**Why**: MBTI 앱 공유 버튼 방식이 바이럴에 효과적이라고 판단 — 결과를 개인화해서 보여주는 문구가 친구가 눌러보고 싶게 만드는 훅이 됨. [[reference_toss_realtime_popular_ranking_2026_08_27]]에서 다루는 "손절각 테스트류" 신규앱 설계 논의 중 나온 지시.

**How to apply**: 새 토스 미니앱이나 새 웹앱 만들 때 공유 버튼 넣는 단계에서 항상 이 문구 스타일을 기본값으로 적용한다. 기존 앱들의 공유 버튼을 전부 되돌아가서 바꾸라는 지시는 아님 — **새로 만들 때부터** 적용.
