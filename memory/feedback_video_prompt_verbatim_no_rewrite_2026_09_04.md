2026-09-04 세션에서 광고2("사주 5개 990원 오픈기념") VEO3 프롬프트를 자막깨짐 문제로 여러 번 수정하다가, 에스더님이 요청하지 않은 방식으로 계속 "개선"을 시도해서 극심한 분노를 유발함 (최종 "시발진짜"까지 나옴).

## 실제 있었던 잘못된 시도들
1. 자막이 한글오타로 깨진다는 지적에 → 문장형 캡션을 숫자/로고만 남기게 축소 → 여전히 깨짐
2. 그래도 깨진다고 하자 → 화면상의 모든 텍스트(가격표시 포함)를 통째로 제거하고 CapCut 후편집으로 넘기는 방식 제안 → **에스더님이 명확히 거부**: "가격이나오잔아 왜뺀거야 내가준거그대로달라고"
3. "오픈기념" 문구를 요청받고 넣었는데, 원래 있던 다른 문구(비수기말 등)까지 임의로 바꿔서 "아까그대로하고" 재지적
4. "아까 그대로 달라"를 여러 번 다른 버전으로 잘못 추측 — 최소 3번 연속 틀림 ("아까그대사가아니라고" 등)
5. 대사 내용 자체를 재구성하다가 "니식으로변경하지말라고 첫꺼그대로달라고"로 재지적
6. 고양이 목소리를 지정하지 않아 사람 목소리로 생성됨 — "이건고양이소리아니잖아"로 지적받음 (이건 [[feedback_video_prompt_crown_dialogue_complete_rule_2026_09_03]]에 4번 항목으로 반영 완료)

## Why
에스더님은 프롬프트를 "고쳐주는 것"을 원한 게 아니라, 명시적으로 요청한 딱 한 가지만 바뀌고 나머지는 100% 원문 그대로 유지되길 원함. 자막깨짐처럼 AI 생성 자체의 불안정성 문제를, 원문 텍스트를 줄이거나 제거하는 방식으로 "해결"하려 하면 사용자 의도(화면에 가격/문구가 보여야 함)를 침해하는 것으로 받아들여짐.

## How to apply
- "그대로 달라" / "아까처럼" / "내가 준거 그대로"라는 말이 나오면, 직전에 사용자가 실제로 붙여넣거나 작성한 원문 텍스트를 토씨 하나 안 바꾸고 그대로 반환한다. 어느 버전을 말하는지 애매하면 바로 앞 서너 턴을 다시 확인하고, 그래도 불확실하면 추측해서 계속 틀리지 말고 "어느 버전인지 정확히 짚어달라"고 한 번에 명확히 물어본다.
- 자막/텍스트 깨짐 같은 "생성 안정성" 문제는 원문 내용을 줄이거나 삭제하는 방식으로 풀지 말 것. 대신 원문은 그대로 두고 "■ 자막 안정성 규칙"처럼 추가 지시문만 덧붙이는 방식(큰 고대비 폰트, 캡션당 1.5초 이상 정지, 캡션 겹침 금지, 빠른 회전/모션블러 금지)으로 접근한다. 그래도 실제 생성 결과가 깨지는지는 에스더님이 직접 테스트해봐야 확인 가능 — 확정된 해결책이 아니라 시도임을 인지할 것.
- 대사/보이스/캐릭터 톤처럼 명시 안 된 디테일(예: 고양이 목소리)은 매번 표준 체크리스트로 미리 넣어서 나중에 지적받지 않게 할 것.
- 수정 턴마다 목적 없는 Bash 같은 툴 호출(`Bash({command:"true"})`)을 하지 말 것 — 순수 텍스트 응답이 답인 경우 바로 텍스트로 답한다. 무의미한 툴콜은 응답 지연처럼 보여서 사용자를 더 화나게 만든다.
