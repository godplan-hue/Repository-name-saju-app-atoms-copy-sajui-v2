## ⭐⭐⭐ 토스 스마트 발송 — 무료 홍보 핵심 발견 (2026-07-29)

> **핵심**: 우리 앱 한 번도 안 써본 토스 유저한테 푸시 알림 10만건 무료 발송 가능

---

## 발송 종류

| 종류 | 대상 | 설명 |
|---|---|---|
| **신규 유입 유도** | 우리 미니앱 한 번도 안 쓴 토스 유저 | 토스 3,000만 유저 중 우리 앱 미사용자 전부 대상 가능 |
| **재방문 유도** | 우리 앱 써봤는데 안 돌아온 사람 | 07/28 기준 99% 미재방문자 → 다시 부를 수 있음 |

---

## 무료 할당량

- **워크스페이스당 10만건 무료**
- 앱마다 워크스페이스가 다르면 → 앱당 10만건 별도 적용 가능
- ⚠️ 기간 리셋 여부: 확인 필요 (월 리셋인지, 1회성인지 토스 콘솔에서 확인)

---

## 광고비 환산 (2026-07-29 계산)

| 조건 | 계산 |
|---|---|
| 10만건 발송 | 무료 |
| 푸시 오픈율 5~10% | 5,000~10,000명 실제 진입 |
| CPC 100원 기준 환산 | **50만~100만원** 광고 효과 (앱 1개당) |
| 앱 5개 적용 시 | **250만~500만원** 광고 효과 무료 |

→ 광고비 4만원 써서 0명 전환했는데, 스마트 발송은 무료로 수십만명 도달 가능

## 메시지 규칙 (토스 심사 통과 기준)

- **제목**: 최대 7자
- **내용**: 최대 25자
- **말투**: 해요체
- **마침표**: 끝에 반드시

### 앱별 메시지 예시

| 앱 | 제목 | 내용 |
|---|---|---|
| MBTI 점운 | `MBTI 운세` | `토스에서 무료로 내 사주 MBTI 확인해요.` |
| 다이어트 점운 | `오행 다이어트` | `내 체질에 맞는 음식을 무료로 알아봐요.` |
| 감정일기 | `오늘 감정 기록` | `토스에서 오늘 하루 감정을 기록해봐요.` |

## 타이밍 전략 (로빈 웨비나 기준)

- **낮 12시~2시**: 점심 시간 집중 발송
- **저녁 8시~10시**: 퇴근 후 릴렉스 타임
- AI 자동 최적화: 스마트 발송 설정 시 토스 AI가 최적 시간 자동 선택

## 설정 위치

토스 앱인토스 콘솔 → 앱 선택 → **스마트 발송** 탭

## 주의사항

- 광고성 발송: 마케팅 수신 동의한 유저만 발송 가능
- 기능성 발송: 동의 없이 가능 (결제 완료 알림 등)
- 우리 앱은 신규 유입 = 광고성 → 마케팅 동의 유저 대상
- ⚠️ 10만건 소진 후 추가 비용 발생 여부 확인 필요
