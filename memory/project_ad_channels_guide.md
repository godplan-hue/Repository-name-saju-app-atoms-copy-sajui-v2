# 사주앱 광고 채널 가이드 (에스더님 직접 정리)

## 1. 구글 애즈 ⭐⭐⭐
- 경쟁사 사이트 URL or 키워드 넣기 → 경쟁사 고객 뺏어오기
- 유튜브 관련 영상 아무거나 넣어도 됨 (사주/운세 영상 시청자 타겟)
- 영상 끝나면 내 사이트(jeomun.com) 연결
- **효과 제일 좋음**

## 2. 카카오모먼트
- 카카오톡에 광고 올라감
- 비용 더 들고 결과 좀 떨어짐
- 그래도 할 수 있으면 구글애즈랑 같이 하는 게 좋음

## 3. 네이버 키워드 광고 ⭐ 필수
- 국내 사용자 잡으려면 필수
- 사주/운세/꿈해몽 키워드로 검색 시 상단 노출

## Why: 에스더님이 직접 조사한 광고 채널 전략
## How to apply: 광고 시작할 때 이 순서대로 집행
