**링크드인 (LinkedIn)**
- 기존에 "유로브릿지" 옛 브랜드로 만들어둔 계정 발견
- 프로필 로고 → 점운(jeomun.com) 보라색 로고로 교체 완료
- "소개(About)" 섹션에 점운 창업 스토리 작성 완료 — 강사명 "에스더"로 표기
- 게시글 발행 완료 — #창업 #비개발자창업 #1인창업 #사이드프로젝트 #커리어전환 해시태그, jeomun.com 링크카드 포함
- 발행 확인: 노출 8명, 검색 노출 10건(인맥이 거의 없어 100%가 인맥 내로 잡힘 — 표본이 작아서 그런 것, 비정상 아님) → 공개 상태 정상 확인됨
- **미완료**: Experience(경력) 섹션에 남아있는 "유로브릿지 대표" 스킬 태그 정리 — 다음에 이어서 하면 됨 (본인이 URL설정 페이지로 새다가 흐지부지됨)
- Premium 무료체험은 게시글 노출 도움 안 되고 자동결제 위험 있어서 비추천함 → 안 함

**How to apply**: 다음 세션 시작하면 브런치 승인 여부 먼저 물어볼 것. 링크드인 Experience 정리 이어서 필요하면 도와줄 것. 오늘 만든 About/게시글 문구와 사실관계(54세, 25일/350시간, 19개앱, 토스미니앱17개중3개출시 등)는 항상 다른 채널과 일치시킬 것.
