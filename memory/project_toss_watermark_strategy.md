## 워터마크 전략 (확정)

**Why:** 스크린샷 공유 시 앱 이름이 없으면 바이럴 유입 불가. 메인 결과 카드 안에 박아서 항상 캡처되게.

### 위치: 메인 결과 카드 안 하단 (페이지 맨 하단 ❌)

```
┌─────────────────────────┐
│  INTJ · 전략가           │
│  오행: 금(金)            │
│                         │
│  강점: 전략적 사고...    │
│  단점: 완벽주의...       │
│                         │
│ 🔮 점운 MBTI | 토스 검색 │  ← 여기
└─────────────────────────┘
```

- 페이지 맨 하단 ❌ → 캡처 안 될 수 있음
- 메인 결과 카드 안 ✅ → 항상 캡처됨 (가장 많이 찍히는 부분)

### 앱별 문구 (⚠️ 이름 순서 절대 헷갈리지 말 것!)

| 앱 | 토스 등록명 | 워터마크 문구 |
|---|---|---|
| MBTI | **MBTI 점운** | 🔮 MBTI 점운 \| 토스에서 'MBTI 점운' 검색 |
| 다이어트 | **점운 다이어트** | 🥗 점운 다이어트 \| 토스에서 '점운 다이어트' 검색 |
| 감정일기 | **감정일기 점운** | 💜 감정일기 점운 \| 토스에서 '감정일기 점운' 검색 |
| 사주 (예정) | 점운 사주 | 🔮 점운 사주 \| 토스에서 '점운 사주' 검색 |

**⛔ 이름 순서 규칙 (절대 바꾸지 말 것)**
- MBTI → MBTI **앞**, 점운 **뒤** = `MBTI 점운`
- 감정일기 → 감정일기 **앞**, 점운 **뒤** = `감정일기 점운`
- 다이어트 → 점운 **앞**, 다이어트 **뒤** = `점운 다이어트` (예외, 이게 맞음)
- 매번 헷갈리므로 수정 전 반드시 이 파일 먼저 읽을 것

### 스타일
- 작고 흐리게 (color: #aaa, fontSize: 11)
- 방해 안 되게 — 결과 카드 하단 테두리 안쪽
- 텍스트 정렬: 가운데

### How to apply
새 토스 앱 만들 때마다 메인 결과 카드 안 하단에 동일하게 적용할 것
