## 광고발 첫 DB 전환 발생 (2026-08-29)

### 일반회원 DB 유입 확인 (캡처 시점)
2026-08-28~29 사이 신규 등록 다수 확인 (이름/전화/이메일/생년월일/성별/관계/경로 컬럼). 경로 컬럼에 "메인"/"점운내부"/"-" 혼재 — 아직 "당근"이나 "틱톡" 경로값이 명확히 안 찍혀 있어 정확한 유입 채널 구분은 안 되는 상태.

### 핵심 포인트
- 당근 "990원 사주" 광고가 8/28부터 실제 클릭(55건)을 만들어내고 있고, 비슷한 시점에 일반회원 DB가 늘기 시작 — 시점상 상관관계가 있어 보이나 확정은 아님(경로 컬럼에 "당근"/"틱톡" 값이 없어 정확한 소스 추적 불가)
- **다음 개선 포인트**: 유입경로 추적 시 당근/틱톡을 구분할 수 있는 UTM 파라미터나 랜딩 경로값을 추가하면 어떤 채널이 실제로 전환을 만드는지 명확히 알 수 있음 — [[project_admin_source_tracking_2026_08_28]]에 이미 당근 경로값이 추가되어 있는지 확인 필요

**Why**: 광고 집행 후 실제 DB 전환이 처음 눈에 띄게 발생한 시점 — 향후 광고 예산 배분(당근 vs 틱톡 vs 구글) 판단에 참고할 근거 데이터.
**How to apply**: 다음에 광고 성과를 논의할 때 이 시점을 "당근 광고 첫 전환 확인일"로 기준삼을 것. 유입경로 컬럼이 비어있는 문제는 [[project_admin_source_tracking_2026_08_28]] 작업과 연결해서 개선 여지 있음.
