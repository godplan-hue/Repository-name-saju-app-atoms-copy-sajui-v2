# 토스 앱 수정 시 절대 규칙 (에러 방지)

**Why:** 2026-07-30 에스더님이 9개 앱 한꺼번에 수정하다 에러 → 새벽 4시간+21시간 총 삽질
**How to apply:** 토스 앱(.ait) 수정할 때마다 반드시 이 순서 지킬 것

## 수정 순서 (절대 바꾸지 말 것)

```
1개 앱 수정
    ↓
npx ait build 빌드 확인
    ↓
에러 없으면 → 다음 앱
에러 있으면 → 그 앱 먼저 수정 후 → 다음 앱
    ↓
반복 × 9
```

## 절대 금지

- ❌ 9개 앱 한꺼번에 수정 → 어디서 에러났는지 모름
- ❌ 빌드 확인 없이 다음 앱으로 넘어가기
- ❌ 첫 번째 앱 패턴 확정 전에 나머지 복붙하기
