에스더님이 컴터 꺼져서 링크 다 날아갔을 때(2026-08-18) 직접 확인해서 확정한 링크들.

- **고객 DB (실결제 내역)**: https://jeomun.com/admin/direct-payments — 에스더님이 실제로 쓰는 고객DB 링크는 이거. 8개 탭.
- (참고) https://jeomun.com/admin/customers — 고객 관리
- (참고) https://jeomun.com/admin/free-leads — 무료 리드 모이는 곳인데 이름이 저장 안 됨(전화번호는 됨). 다른 곳에서 이름 확인 가능해서 문제 없다고 확인함, 고칠 필요 없음.
- **토스 미니앱 콘솔**: https://apps-in-toss.toss.im/workspace/58523/mini-app?utm_source=developercenter%2F — 워크스페이스 58523, 여기서 앱 빌드 업로드/광고/프로모션 전부 관리
- **토스페이먼츠 가맹점 관리자(결제/취소)**: https://app.tosspayments.com/ — 로그인하면 결제내역·취소 등 전부 확인 가능
