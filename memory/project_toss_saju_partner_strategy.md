## 토스 사주 앱 안에 파트너 모집 넣는 방법 (확정)

**Why:** 토스 앱 안에 직접 파트너 모집 폼/버튼 → "홍보 앱" 으로 심사 걸림. 블로그 링크 방식으로 우회.

### 구조

```
토스 사주 앱 안
→ "🔮 오행 체질별 사주 더 알아보기 →" 버튼
(콘텐츠 링크처럼 보이게 — "파트너" 단어 절대 넣지 말 것)
        ↓
네이버 블로그 글
"목화토금수 체질별 사주 완전 정리"
(실제 사주 콘텐츠 충실하게 작성 — 심사관이 봐도 정보글로 보여야 함)
        ↓
글 중간·하단에 자연스럽게
"점운으로 사주 부업 시작한 분들 후기..."
"파트너 문의: 카카오채널"
```

### 핵심 원칙
- 토스 앱 버튼 텍스트: **절대 "파트너", "부업", "모집" 단어 사용 금지**
- 버튼은 콘텐츠 링크처럼 보여야 함 ("체질별 사주", "오행 심층 분석" 등)
- 블로그 글은 실제 사주 콘텐츠를 충실하게 써야 함 (파트너 내용만 있으면 안 됨)
- 파트너 유도는 블로그 글 중간·하단에 자연스럽게 삽입
- 최종 전환은 카카오채널로 (jeomun.com 링크 직접 노출 금지)

### 효과
- 토스 심사관 눈엔: 사주 콘텐츠 링크
- 실제로는: 사주 정보 + 파트너 모집 동시에
- 블로그 글 자체가 SEO 콘텐츠로도 활용됨 → 일석삼조

### ⚠️ 적용 시점
- 토스 사주 앱 만들 때 처음부터 이 구조로 설계할 것
- 지금 있는 MBTI/다이어트/감정일기 앱에는 넣지 말 것 (타겟 안 맞음)
- 사주 앱 유저 = 사주에 관심 많음 = 부업 관심 있을 가능성 높음 → 타겟 딱 맞음

**How to apply:** 토스 사주 앱 기획·개발 시작 전 이 파일 반드시 읽을 것
