## 문제
분명 990원(또는 다른 금액) 결제를 완료했는데, 결과지에 유료 내용 대신 "오늘의 운세"(무료) 화면이 뜨고 "다시 결제해주세요"라고 표시됨. 다시 결제하면 그때는 유료 결과지만 정상적으로 나옴.

## 원인
메인 페이지 "🔮 3초만에 무료로 내 사주 보기" 버튼(`goFree()`)은 이미 저장된 프로필이 있으면 `/main-v2/analysis?fresh=1`로 바로 이동한다. `app/main-v2/analysis/page.tsx`는 `fresh=1`이 있으면 "이미 결제했으면 결과지로 바로 이동"하는 보호 로직을 건너뛰고 곧바로 새 무료 분석(`startAnalysis()`)을 실행했는데, 이 함수는 시작할 때 `v2_paid`/`v2_plan`/`price`/`v2_paid_cats`를 전부 지우고 `v2_result`를 무료 전용 결과로 덮어썼다.

즉, **결제를 마친 사용자가 나중에 다시 "3초 무료" 버튼을 누르면**(습관적으로, 또는 다른 걸 보려고) 결제 상태가 통째로 지워지고 무료 결과로 덮어써졌던 것 — 실제 결제/DB에는 문제가 없었고, 브라우저 로컬 상태만 초기화된 것이었음.

이 버튼 자체는 이번 세션 이전부터 있던 로직(`main-v2/page.tsx:769`)이고, 이번 세션에 추가한 `profile/page.tsx`의 "기존회원 확인" 화면([[project_free_button_profile_wipe_fix]])도 같은 `/main-v2/analysis?fresh=1` 경로로 연결되어 있어 동일하게 영향을 받았음.

## 수정 (commit 92e95be)
`app/main-v2/analysis/page.tsx` — `fresh=1`이어도, 이미 결제한 프로필이면(v2_paid=1 + v2_result 존재 + 이름 일치) 무료 분석을 새로 돌리지 않고 기존 결과지로 그대로 이동하도록 수정. 이름이 다른 사람이면(진짜 다른 사용자) 기존 로직대로 결제 상태를 초기화함.

추가로 `app/main-v2/result/page.tsx`의 "당신의 변화" 유료 탭에서 오늘 이미 다 본 경우 아무것도 안 뜨던 것을, 무료 탭과 동일하게 "오늘은 이미 받으셨어요, 내일 다시 만나요" 안내 문구가 뜨도록 수정.

**Why**: 결제 여부와 무관하게 "새로고침 하듯" 눌러볼 수 있는 버튼이 실제로는 유료 데이터를 파괴하는 부작용이 있었음 — 결제 자체엔 문제가 없었는데 사용자는 결제가 무효화된 것처럼 느낌.

**How to apply**: 앞으로 `v2_paid`/`v2_plan`/`price`/`v2_paid_cats`를 지우는 코드를 새로 추가할 때는 항상 "이 사용자가 이미 유효한 결제 상태를 갖고 있는 경우"를 먼저 확인하고, 이름이 같은 기존 결제자라면 지우지 않는 방향을 기본으로 할 것. [[feedback_no_speculative_defensive_code]]와 상충하지 않음 — 이건 추측성 방어코드가 아니라 실제 재현된 버그의 직접 수정.
