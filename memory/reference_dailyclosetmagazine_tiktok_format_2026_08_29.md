## 계정: Daily closet magazine (패션 큐레이션 틱톡 광고)
2026-08-29 에스더님이 캡처해서 공유한 실제 노출 중인 틱톡 광고 예시.

### 영상 구조 (슬라이드 나열형)
1. **훅 장면**: 소리 없이(🔇 표시) 감성적인 라이프스타일 컷 — 예: 남녀가 아이스크림 먹는 사진 + 큰 흰 굵은 글씨 자막 "나만 알고 싶은 코르티스 맛 반팔 | 포인트가 싫어서" — 클릭 욕구를 자극하는 "나만 알고 싶은" 톤
2. **제품 카드 슬라이드 반복** (5~6장): 상단에 계정 로고/이름 "Daily closet magazine" 고정 배치, 왼쪽에 제품 이미지, 오른쪽에 모델 착용컷, 하단에 브랜드명(예: TRIPPY GARMENT) + 제품명(영문) + 가격(예: 29,000 KRW) — 카드마다 디자인 톤 통일(흰 배경, 검정 굵은 텍스트)
3. **하단 고정 캡션 바**: 모든 슬라이드에 "유행 패션 정보 · 7-24" + 원본 후킹 문구("나만 알고 싶은티스 맛 반팔 | 포인트가 싫어서") + "자세히" 버튼 반복 노출 — 시청자가 스크롤해도 컨텍스트 잃지 않도록 고정
4. **클로징 브랜드 샷**: 지하철 광고판 합성 이미지에 "DAILY CLOSET MAGAZINE #192 - Curated Fashion & Lifestyle for the Modern Wardrobe" 문구 + 자막 "최신 패션 트렌드와 유행 패션정보 안내를 전달합니다" — 계정을 "매거진/잡지"처럼 브랜딩

### 성과 지표 (캡처 시점)
좋아요 126 / 댓글 0 / 저장 35 / 공유 2 — **저장(35) 비율이 좋아요 대비 매우 높음** → "정보 큐레이션/쇼핑리스트" 형 콘텐츠는 저장 위주로 소비된다는 신호

## 점운 적용 아이디어
- "제품 카드 슬라이드" 구조를 "앱 카드 슬라이드"로 변형 가능: 점운 로고 고정 헤더 + 앱 아이콘/스크린샷 + 앱명 + 한줄 소개 + "무료" 표시, 이런 카드를 여러 장 넘기며 "점운 매거진 #N" 식으로 브랜딩
- 훅 문구 톤 "나만 알고 싶은 ~" 은 사주/운세 콘텐츠에도 적용 가능 (예: "나만 알고 싶은 돈복 사주")
- 클로징에 "점운 매거진" 같은 브랜드 정체성 샷을 반복 노출하면 계정 자체의 신뢰도/각인 효과 기대

**Why**: 에스더님이 실제 노출 중인 틱톡 광고를 벤치마킹 자료로 캡처해서 저장 요청함.
**How to apply**: 앞으로 점운 틱톡/카드형 숏폼 기획 시 이 구조(훅→카드슬라이드 반복→클로징 브랜드샷)를 참고할 것. [[competitor_sajucase_tiktok]]의 TOP5 리스트형과는 다른 포맷 — 정보 큐레이션/쇼핑리스트 스타일.
