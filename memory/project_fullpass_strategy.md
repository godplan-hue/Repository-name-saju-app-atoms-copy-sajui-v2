# 점운 풀패스 가격 전략 (2026-07-14 확정)

## 풀패스 대상 앱 3개 (30일권)

| 앱 | localStorage 키 |
|---|---|
| 맘케어 | `momcare_unlock_until` |
| 감정일기 | `gamjung_unlock_until` |
| 가계부 | `budget_unlock_until` |

**꿈해몽은 풀패스 제외** — 현행 24시간 유지 (에스더님 확정)

## 가격 구조 (확정)

| 플랜 | 가격 | 포함 내용 |
|---|---|---|
| 앱 30일권 | ₩4,900 | 맘케어+감정일기+가계부 30일 |
| 풀코스 30일권 | ₩6,900 | 3개 앱 30일 + 사주 5개 운세 (재물/연애/건강/성공/올해운세) |

- 사주 5개 운세 단품 가격: 3,900원 × 5 = 19,500원 → 6,900원에 묶어 명확한 가성비
- 직운/합격자소서: 풀패스 제외, 1회 990원 별도 구매 (풀패스 홍보 시 "직운·합격자소서는 1회 별도 구매" 명시)

## 중복 처리 원칙
- 기존 맘케어/감정일기/가계부 이용 중인 사람이 풀패스 구매: 결제일 기준 30일 덮어쓰기 (연장 처리, 신경 쓸 것 없음)

## 구현 방식 (미래 — 포트원 KCP 완료 후)
- `localStorage.setItem("momcare_unlock_until", Date.now() + 30일)`
- `localStorage.setItem("gamjung_unlock_until", Date.now() + 30일)`
- `localStorage.setItem("budget_unlock_until", Date.now() + 30일)`
- 6,900원 플랜: 위 3개 + `v2_paid_cats`에 5개 카테고리 추가

## 절대 금지
- "구독" 단어 사용 금지 (카드사 심사 문제)
- "풀패스", "30일권", "전체이용권" 사용

## 유료화 전략 (2026-07-14 확정)

**첫 30일**: 결제 없이 자유롭게 사용 (무료 체험)
**30일 후 만료**: "사주 990원 결제하면 30일 다시 열립니다" 배너 표시
**재결제**: 사주 990원 → unlock_until 30일 연장

**업셀 문구 (확정):**
- "사주 990원 내면 육아일기·감정일기·가계부까지 공짜!"
- "3개 앱 30일 + 사주 5개 = 4,900원" → 풀패스 업그레이드 유도

**추가 개선 예정**: 만료 3일 전 배너 추가 ("3일 후 잠겨요 → 990원으로 연장")

## Why
- **Why:** 14개 앱 중 풀패스 대상이 3개인 이유: 무료 4개(MBTI/행운번호/궁합/펫운)는 이미 무료, 직운/합격자소서는 1회 영구 별도, 꿈해몽은 24시간 유지, AI상담/다이어트/가계부일기식은 미완성. 남은 게 맘케어/감정일기/가계부 3개.
- **How to apply:** 풀패스 관련 질문 오면 이 파일 먼저 읽고, 위 구조 그대로 답할 것. 꿈해몽을 풀패스에 넣자는 제안 절대 금지.
- 3개 앱은 사주 결제의 "보너스"로 포지셔닝 → 사주 재결제 동기가 됨. 별도 990원 받는 B안은 채택 안 함 (2026-07-14 확정).
