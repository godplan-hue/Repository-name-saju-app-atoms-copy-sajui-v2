경쟁사 분석, 링크, 스크린샷, 사용자가 올린 참고 자료는 **말 안 해도 자동으로** memory 파일에 저장한다.

**Why:** 사용자가 "앞으로 모든 앱 조사하는 것도 전부 말 안 해도 다 저장해" 라고 명시적으로 요청함 (2026-07-11).

**How to apply:**
- 경쟁사 스크린샷/내용 → `competitor_[앱명].md` 형식으로 저장
- 링크 공유 시 → reference memory에 저장
- MEMORY.md index에 항상 추가
- 커밋 시 memory 파일도 함께 커밋하지 않아도 됨 (로컬 저장만)
