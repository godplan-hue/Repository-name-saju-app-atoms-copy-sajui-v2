## 핵심 수정사항 (1번째 안에서 변경됨)

**"관계레이더"는 상대방의 실제 속마음·실제 행동을 몰래 알아내는 앱이면 안 됨.** 사용자가 입력한 관계 정보·연락 패턴·상황을 분석해 "관계 변화 가능성/패턴"을 보여주는 서비스로 설계. 이유: 결과 신뢰도 + 토스 검수 리스크(AI 활용 시 고지 등 정책 준수 필요, 위반시 반려 가능).

앱인토스는 체류시간+커스텀 전환지표 측정 가능 → 완료율→결과조회→결제→공유→재방문을 실제로 측정하도록 설계할 것.

**참고 사실**: "인스타 언팔한 사람 찾기"는 토스가 2026-08 공식 웨비나에서 직접 소개한 성공사례 — 혼자 만든 미니앱으로 하루 최대 150만원 매출. 토스가 강조한 성공요소: 결제전환, 구독, 재방문, 공유 이미지, 리뷰 요청 타이밍.

## 서비스 한 줄 정의

사용자가 특정 사람과의 관계 정보 몇 가지를 입력하면 관계 변화·거리감·연락주도권·안정성 등을 분석해 "내가 놓치고 있던 관계 신호"를 보여주는 관계 분석 미니앱.

핵심 문구: "요즘 나와 멀어진 사람이 있나요?" / "내가 놓치고 있던 관계 신호를 찾아보세요."

### 결과지 표시 규칙
