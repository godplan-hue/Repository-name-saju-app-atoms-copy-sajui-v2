에스더님이 "제일 반응이 좋아" 확정한 홍보영상 구조 + 틱톡 유료광고 거절 원인 정정판.

## ⚠️ 정정 (최초 진단 오류 수정)
처음엔 "영상 화면 안의 20만원→990원 가격대비 연출"이 틱톡 심사(주식스캠 오인)로 거절되는 거라 진단해서 화면에서 가격을 통째로 뺀 버전을 만들었으나, **에스더님이 실제 테스트해보니 화면에서 가격을 빼면 전환(디비유입)이 확 떨어짐** ("990원없음안들어와"). 에스더님 확인 결과 실제 거절 원인은 **틱톡 게시글 캡션(설명글) 텍스트에 "990원"을 적은 것** 때문이었음 — 영상 내용이 아니라 캡션 텍스트가 문제.

## 확정 결론
- **영상 화면 안**: 원본 그대로 가격 연출(20만원 X표시 → 990원 뱃지) **유지한다.** 반응/전환에 필수.
- **틱톡 캡션(게시글 텍스트)**: "990원" 등 숫자·가격 단어를 **절대 넣지 않는다.** 여기가 심사 거절 트리거.

## 확정 영상 대본 (가격 연출 유지 + 고양이 리뉴얼 + 음악 작게)
```
"점운" 홍보영상, 10초 세로형, 한복 입은 고양이 캐릭터.
고양이 디자인: 푸들처럼 풍성하고 몽글몽글한 곱슬 흰털, 크고 동그란 눈, 작고 동그란 코, 통통한 볼살 — 인형처럼 사랑스럽고 귀여운 얼굴로. (기존 디자인이 안 예쁘다는 피드백 반영, 못생긴 고양이 금지)

0~2초: 화려한 별빛+한지 질감 배경, 한복 입은 고양이가 부채를 펼치며 등장, "점운!" 외침.
2~4초: 부채 위 "점운" 로고가 금빛으로 반짝.
4~7초: 화면에 "20만원" 글자가 X표시와 함께 부서지듯 사라짐. 고양이 자신감 있게: "사주 20만원? 아니죠!"
7~9초: 가슴의 빨간 "990원" 뱃지 클로즈업, 금빛 파티클 폭발. 마지막 대사: "점운, 990원 사주 지금 시작!"
9~10초: "기획의신 에스더가 만든" 자막 (화면 하단, 작게)

배경음악: 아주 작은 볼륨(거의 안 들릴 정도)로만, 대사는 선명하게 들리게.
전체적으로 화사하고 고급스러운 색감, 빠른 컷 전환.
텍스트는 "점운", "20만원", "990원"만 정확히 렌더링.
```

## 틱톡 캡션 작성 규칙
- "990원"/"20만원"/숫자 가격 표현 절대 금지.
- 훅 문구 + 해시태그 위주로 작성. 예: "사주 이렇게 재밌어도 되나요? 🔮 이거 보고 소름 돋음 #점운 #사주 #운세"

## 핵심 규칙 정리
1. **가격 연출은 영상 화면 안에 남긴다** — 전환에 필수, 화면 콘텐츠 자체는 틱톡 심사에서 문제 안 됨.
2. **캡션(게시글 텍스트)에는 가격/숫자 절대 넣지 않는다** — 실제 거절 트리거는 이쪽.
3. 고양이는 "푸들처럼 풍성한 곱슬털 + 크고 동그란 눈 + 통통한 볼" 조합으로 귀엽게 — 이전 디자인은 "너무 못생겼다"는 피드백 있었음.
4. "기획의신 에스더가 만든" 자막은 영상 뒷부분(끝)에 작게 배치.
5. 배경음악은 아주 작게 — 대사가 잘 들리도록.

## Why
가격을 화면에서 빼면 전환이 떨어지고, 반대로 캡션에서만 빼면 심사도 통과하고 전환도 유지된다는 걸 실제 재시도로 확인함. 최초 진단(화면 자체가 문제)은 틀렸었고 에스더님이 직접 정정함.

## How to apply
앞으로 유료광고용 영상 만들 때: **화면 안 가격 표시는 유지, 캡션 텍스트에서만 가격 제거**가 기본 규칙. 화면에서 가격을 빼는 처방은 쓰지 않는다.
