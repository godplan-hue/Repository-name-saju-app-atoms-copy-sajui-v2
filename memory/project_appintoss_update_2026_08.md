앱인토스 팀에서 2026-08-12 발송한 업데이트 메일 내용 정리.

**공유하기 개선**
- 미니앱 공유 시 링크에 앱 고유 이미지 + 앱 이름 그대로 노출됨 (이전엔 공통 썸네일이었던 것으로 추정)
- 미니앱 상세페이지에 공유 버튼 신규 추가

**멤버별 콘솔 권한 부여**
- 워크스페이스 구성원마다 볼 수 있는 미니앱을 다르게 설정 가능
- 관리자 아닌 구성원은 정산 내역 열람 불가

**비즈월렛 충전 완화**
- 최소 충전액 30만원 → **5만원**으로 인하, 금액 직접 입력 가능
- [[project_biz_wallet_strategy]]에 반영함 — 프로모션 진입장벽 크게 낮아짐

**프로모션 1인 하루 최대 수령액 설정**
- 콘솔에서 "1인 하루 최대 지급 금액" 상한을 직접 설정 가능 (어뷰징/과다지급 방지)

**개발자센터 개편**
- 문서 통합 + 검색 정확도 개선 + GitBook 어시스턴트(문서기반 Q&A) 신규

**WebView SDK 3.0**
- SDK 이슈 발생 시 파트너 재배포 없이 앱인토스 서버에서 즉시 수정 가능 → 생태계 안정성 향상

**정책 변경 2건**
- 게임물은 게임물관리위원회 분류 방침에 맞춰 반드시 "게임" 카테고리로 등록해야 함
- 토스애즈 SSP 정책 개정 — 어뷰징 판단 기준 및 위반 시 제재·이의제기 절차 명확화 ([[project_toss_ads_lesson]] 어뷰징 의심 경험과 연관 — 향후 이의제기 시 참고)

**Why**: 점운은 토스 미니앱 17개 빌드(순차 출시 중)를 운영하며 비즈월렛 프로모션([[project_biz_wallet_strategy]])과 토스애즈([[project_toss_ads_lesson]])를 모두 쓰고 있어 이번 정책·기능 변경이 직접 영향을 줌.

**How to apply**: 다음 비즈월렛 프로모션 집행 시 5만원부터 시작 가능하다고 안내할 것. 하루 최대 지급액 설정 옵션을 프로모션 설계에 포함시킬 것. 새 미니앱(게임성 요소 있는 것) 출시 시 카테고리를 게임으로 등록해야 하는지 검토할 것.
