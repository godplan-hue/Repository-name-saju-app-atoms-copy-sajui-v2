# 로빈 앱인토스 웨비나 전체 정리 (1시간 10분)

> 저장일: 2026-07-24
> 출처: 로빈(날씨 체크 개발자) 무료 특강 — 앱인토스 성장 노하우

---

## 핵심 구조 — 토스 성장의 원동력

```
스마트 발송 = 토스가 타겟 유저에게 내 앱 푸시를 무료로 대신 보내줌
→ 하루 최대 10만 건 발송 가능
→ 클릭률 20~30% 유지 시 하루 2~3만 명 신규 유입 가능
→ 클릭률 4~5% 미만이면 토스가 자동으로 발송 줄임 (콘솔에 "발송 중"으로 뜨지만 실제론 멈춤)
```

## 핵심 역설 — 좁힐수록 더 많이 간다

```
넓은 세그먼트 → 낮은 클릭률 → 토스가 발송 줄임 → 유저 0
뾰족한 세그먼트 → 높은 클릭률 → 토스가 더 뿌려줌 → 유저 폭발
```

**모수보다 클릭률이 핵심**

---

## 세그먼트 설정 원칙

| 항목 | 설정 |
|---|---|
| 타겟 비율 | 50% (100% = 너무 넓음) |
| 조건문 | AND 위주 (OR 최소화) |
| 테스트 주기 | 주 단위 |
| AB 테스트 | 메시지 2개 동시 발송 가능 |

### 항상 제외할 것 (소거법)
```
금융 거래 프로필 → 고관여 투자자 (주식/파생상품 활발한 사람)
→ 소소한 포인트에 무반응 → 클릭률 0에 가까움 → 발송 효율 망침
```

### 점운 앱별 세그먼트 레시피

| 앱 | 포함 세그먼트 | 제외 |
|---|---|---|
| 사주/꿈해몽 | 사주/운세 소비 이력 + 40~50대 여성 | 고관여 투자자 |
| 행운번호 | 복권/로또 소비 이력 | 고관여 투자자 |
| 궁합 | 데이팅 앱 소비 이력 + 20~30대 | 고관여 투자자 |
| 직운 | 이직 관련 소비 + 직장인 + IT/사무직 | 고관여 투자자 |
| 맘케어 | 자녀 보유 + 육아 관련 소비 | 고관여 투자자 |
| MBTI | 심리테스트 소비 이력 + 20~30대 | 고관여 투자자 |
| 다이어트 | 헬스/다이어트 소비 이력 | 고관여 투자자 |

## 페르소나 2그룹 전략

```
그룹 1: 이 앱을 왜 쓰는가 (핵심 동기) → 직업/직종으로 역추적
그룹 2: 두 번째 이유 → 소비 패턴으로 역추적
→ 두 그룹 각각 별도 발송 + AB 테스트
```

### 날씨 체크 실제 사례
- 그룹 1: 건설/해운/토목 — 날씨가 생존과 직결
- 그룹 2: 자녀 보호자 — 미세먼지 체크
- 결과: D1 리텐션 60%, 7일 50% 이상, 전체 3위

## 수익 모델

### 광고 3종
```
배너 광고   → 조건 없이 자유 배치, 노출만 해도 수익
전면형 광고  → 특정 시점 전체화면 노출
리워드 광고  → 광고 시청 → 혜택 지급 (ECPM 가장 높음)
```

### 수익 공식
```
DAU 100 + ECPM 5~7만원 = 하루 1만원 (현실적 첫 목표)
노출수 × eCPM ÷ 1,000 = 수익
```

- 첫 수익: 광고 기반이면 거의 즉시 발생
- 정산: 이번 달 수익 → 다음 달 말일 입금
- DAU 높아지면 ECPM 상위 유지 어려워짐 (정상)
- ECPM 퍼센타일: 앱 대시보드에서 확인 가능
