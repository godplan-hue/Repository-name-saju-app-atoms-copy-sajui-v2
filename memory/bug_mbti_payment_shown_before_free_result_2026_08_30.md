[[project_mbti_toss_link_and_crosspromo_badge_2026_08_30]] 후속 작업 (2026-08-30, commit `5d644b1e`).

**버그**: 퀴즈 완료 후 결제창(`/mbti/pay`)이 먼저 뜨고, 브라우저 "돌아가기"를 눌러야 무료 3개 항목(성격성향/강점/주의점)이 나오는 결과지가 보였음.

**원인**: `app/mbti/page.tsx`의 `submit()`이 `alreadyUnlocked` 여부에 따라 `/mbti/result/${id}` 또는 `/mbti/pay?id=${id}`로 조건부 리다이렉트하고 있었음. 결과지는 이미 무료 3개항목을 무조건 렌더링하도록 되어있었는데(이전 세션 `f152dc53`), 리다이렉트 로직이 여전히 미결제자를 결제페이지로 먼저 보내고 있어서 무료항목이 묻혀버림.

**수정**: 조건 분기 제거, 항상 `/mbti/result/${id}`로 이동. `alreadyUnlocked` localStorage 체크 코드도 함께 삭제(사용처 없어짐).

**디자인 변경**: "전체 무료로 보려면 토스 MBTI에서 확인" 링크를 CTA 버튼 하단(스크롤해야 보임)에서 페이지 최상단으로 이동 + 금색/주황 그라디언트 배너(`linear-gradient(135deg,#facc15,#fb923c)`)로 눈에띄게 변경. 결과지(`app/mbti/result/[id]/page.tsx`)에도 "← 다시 테스트하기" 링크 바로 아래에 동일 배너 추가, 기존 하단(결제버튼 아래) 링크는 제거.

**Why**: 에스더님 방침 — "여기서엠비티아이로돈안벌거라서" (웹 MBTI로 수익화가 목적이 아니라 토스 미니앱으로 유입시키는 게 목적) → 토스링크는 스크롤 없이 바로 보이는 최상단 + 눈에띄는 색이어야 함.

**부가 수정**: 개인정보 동의 문구 "...서비스 제공에 활용하며, 3년간 보유 후 파기합니다." → "3년간" 앞에 `<br />` 추가해 줄바꿈.

**How to apply**: 앞으로 웹 MBTI(또는 유사 무료유도앱) 퀴즈 제출 흐름을 건드릴 때는 반드시 "제출 → 결과지 직행" 경로를 유지할 것 — 결제 게이트는 결과지 내부(잠금 UI)에서만 걸어야 함, 제출 리다이렉트 단계에서 걸면 무료 콘텐츠가 묻힘.
