## 전략 의견 (원문 보존)

### 앱 이름 — 점운 유지, 부제목에 "사주" 넣기
앱 이름 바꾸면 지금까지 한 개발·도메인·결제 계약 다 날아가요. 유지하되:
- 앱스토어 표시: **점운 - AI 사주풀이**
- 홈페이지 H1: AI 사주풀이 | 점운
- URL: jeomun.com/saju, jeomun.com/ai-saju, jeomun.com/mugyo-saju 등

이걸로 "사주" 키워드 검색 유입 충분히 가능해요.

---

### 지금 바로 만들 수 있는 것 (전부 API 비용 0원)

**1순위 — 결과지 하단 "질문 탭" (사주아이 방식)**
결과지 맨 아래 [자주 묻는 질문]:
- 💰 언제 돈이 잘 벌리나요?
- 💕 결혼은 언제가 좋을까요?
- 💼 이직해도 될까요?
- 👶 자녀운은 어떤가요?
- 💪 건강은 괜찮을까요?

→ 클릭하면 사주 원국(일간, 월지 등) 기준 템플릿 답변 출력
→ API 호출 없음
이미 사주 원국 계산 다 되어 있으니 조건만 연결하면 돼요.

**2순위 — 결과지 상단 "AI 검색창" (무료 템플릿 답변)**
"오늘 나에게 물어보기" → "올해 사업해도 될까요?" 검색
→ 키워드 매칭 → 템플릿 답변 → API 0원
체류 시간 가장 많이 늘려요.

**3순위 — SEO 페이지 (나중에)**
1000개는 나중이고, 지금은 핵심 20개부터:
- jeomun.com/saju/1990 (1990년생 사주)
- jeomun.com/saju/gapok (갑목 사주)
- jeomun.com/saju/today (오늘의 사주)
Next.js로 정적 생성 가능해요.

---

### 에러 위험도

| 항목 | 위험도 | 이유 |
|------|--------|------|
| SEO 1000페이지 한 번에 | 높음 | Next.js 빌드 시간 폭발, Vercel 한도 초과 가능 |
| AI 검색창 키워드 매칭 | 중간 | 질문이 예상 밖으로 오면 빈 답변 뜸 |
| 질문 탭 조건 분기 | 낮음 | 사주 원국 조건만 잘 설계하면 안정적 |

**추천 진행 순서**: 결과지 질문 탭 → 검색창+템플릿 → SEO 20개

## DDoS 방어 (Cloudflare)

코드 작업이 아니라 Cloudflare 연결.
방법: cloudflare.com 가입 → 사이트 추가 → jeomun.com → DNS 네임서버 교체
→ **이미 완료 (saanvi/anirban.ns.cloudflare.com)**

## TTS와 이미지

TTS는 화면에 텍스트로 렌더링된 것만 읽어요.
- 이미지 안의 글자 → 읽을 수 없음 ❌
- 화면에 보이는 텍스트 → 읽을 수 있음 ✅
Q&A 답변은 순수 텍스트 + 이모지로 만들면 됩니다. 이미지 필요 없어요.
