## 사이트
https://www.topview.ai/home?lang=ko

Kling, Seedance, Wan, MiniMax, Nano Banana 등 여러 AI 영상/이미지 모델을 크레딧 하나로 쓰는 통합 영상 제작 툴. UGC 광고, 브랜딩 광고, 소셜 콘텐츠, 제품 광고 템플릿 제공 — 점운 홍보영상(인스타 릴스/유튜브 쇼츠/X)에 사용 예정.

## 무료 요금제 없음 + 월간 결제가
- **무료 플랜 없음** — 최소 단위가 Pro부터, 가입 시 소량 체험 크레딧 줄 가능성은 있으나 페이지에 명시 안 됨(가입화면에서 직접 확인 필요)
- 월간(약정없이 매달 결제) 정가: Pro $29/월, Business $75/월, **Ultra $150/월**

## 한시 프로모션 — ⚠️ Ultra "연간" 결제 전용, 월간 결제엔 적용 안 됨
- **Seedance 2.5** (720p·30초): **60일간 무제한** 생성
- **Seedance 2.0 계열 / Wan 3.0 / MiniMax H3 / GPT Image 2**: **365일간 무제한** 생성
- ⚠️ "2달에 얼마"로 따로 파는 게 아니라 **Ultra 연 1회 $599.90 결제 시에만 포함되는 60일 한정 보너스**. 60일 지나면 Seedance도 다시 월 500크레딧 한도 안에서만 사용 가능
- ⚠️⚠️ **Ultra 월간($150/월)으로는 이 무제한 혜택을 받을 수 없음** — 월간은 그냥 매달 500크레딧 한도 안에서 쓰는 일반 요금제. "일단 월간으로 저렴하게 테스트해보기"가 안 통하는 구조 — 혜택을 받으려면 처음부터 연간 $599.90 선결제 필요

## 점운 홍보영상 제작 사용법
1. Ultra 연간 결제(직접 진행 필요, Claude가 대신 결제 불가)
2. 메인 화면 중앙 "마케팅 영상을 AGENT에게 말하면 바로 제작" 입력창에 프롬프트 입력
   - 예: `점운 고양이 캐릭터가 990원 사주 결과지를 보여주며 "지금 바로 확인해보세요"라고 말하는 15초 세로형 광고`
   - 모델은 무제한 기간인 Seedance 2.5 / Wan 3.0 지정해서 크레딧 소모 없이 생성
3. 입력창 아래 템플릿 태그 활용: UGC 광고 / 브랜딩 광고 / 소셜 콘텐츠 / 제품 광고
4. 사이드바 "필름 스튜디오"/"드라마 스튜디오" = 대사·여러 컷 스토리형 영상, "Motion Studio" = 짧은 모션그래픽
5. 완성 영상 다운로드 → 세로형은 인스타 릴스/유튜브 쇼츠/X, 가로형은 유튜브 일반 업로드
