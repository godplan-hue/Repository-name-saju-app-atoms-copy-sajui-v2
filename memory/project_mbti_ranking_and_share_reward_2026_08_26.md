**최종 결정**: 광고로 여는 4개 섹션(직업/스트레스/인간관계/성장) 중 **직업(career)** 섹션을 광고잠금 → **공유리워드 잠금**으로 전환. 공유하면 자동으로 바로 열림.

**구현 내용** (`C:\Users\moon6\OneDrive\바탕 화면\jeomun-mbti\src\App.tsx`, commit `4a9e001`):
- 기존 죽은코드였던 `shareAndUnlock`(전체 24h 잠금해제, 어디서도 안 불림) → `shareToUnlockSection(sectionKey)`로 교체. 특정 섹션 하나만 unlockedSections에 추가하는 방식으로 변경.
- career 섹션 항목에 `shareUnlock: true` 플래그 추가.
- 버튼 렌더링 분기 추가: `sec.shareUnlock`이면 "📤 공유하고 바로 열기 →" 버튼(노란색) 표시, 클릭시 `shareToUnlockSection("career")` 호출.

- ⚠️ **코드는 GitHub push 완료. 실제 토스 앱에 반영하려면 `ait build` → 콘솔 재업로드 → 심사 필요** (아직 안 함).

## 진짜 "공유 리워드"(연락처모듈 기반) vs 지금 구현 차이

토스 공식문서상 진짜 "공유 리워드"는 연락처모듈로 토스 사용 친구에게 알림 발송 → 상대가 실제 확인/설치 완료해야 공유자에게 보상 지급되는 방식. 지금 구현한 건 단순 `tossShare()`(카톡 공유시트 열기) 호출 성공만으로 바로 언락 — 실제 도달/완료 여부 검증 없음. 나중에 어뷰징(그냥 눌렀다 취소하고 언락되는 경우)이 문제되면 진짜 연락처모듈 API로 업그레이드 고려.
