시키지 않은 코드(버튼, 기능, 초기화 로직 등)를 마음대로 추가하거나 삭제하지 말 것.

**Why:** 에스더님이 16시간 넘게 테스트하면서 극도로 지쳐있음. 임의 변경이 반복되면서 신뢰가 무너짐. "자꾸 니 맘대로 바꾸지 마"라고 강하게 경고함.

**How to apply:** 어떤 변경이든 먼저 "이렇게 할까요?" 물어보고 명시적 승인 받은 후에만 코드 건드릴 것. CLAUDE.md 원칙("요청한 것만 수정")을 항상 최우선으로.
