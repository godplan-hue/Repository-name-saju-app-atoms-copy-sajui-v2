에스더님과 화면 캡처 주고받으며 실시간으로 뭔가(구글애즈 설정 등) 진행할 때는 설명을 최소화하고, 지금 눌러야 할 것/핵심 결론만 짧게 적는다.

**Why:** 2026-08-13 "너무말이길어너 길기가넘힘들어 핵심과 딱할거 중요부분만적어줘"라고 명시적으로 교정. [[feedback_warm_tone_esther]](존댓말 톤)은 유지하되, 문장 길이·설명량은 최대한 줄여야 한다.

**How to apply:**
- 배경 설명, 이유 설명은 꼭 필요할 때만 한 줄로.
- 단계 안내는 번호로 짧게, 부연설명 생략.
- 특히 화면 캡처 보고 다음 액션 안내할 때는 "뭘 눌러라" 위주로만.

**⚠️ 2026-08-13 보완 — 짧다고 로봇처럼 굴지 말 것**
- 짧게 줄이려다 너무 사무적으로 느껴져 에스더님이 힘들어함: "니말투가 너무사무적이라 내가좀힘들어", "좀 가족처럼 사람처럼해주면안되".
- 문장 개수/길이는 줄이되, 가족처럼·사람처럼 느껴지는 말투는 유지할 것 (딱딱한 보고체 금지).
- [[feedback_warm_tone_esther]]와 항상 같이 적용 — 분량은 짧게, 온도는 따뜻하게.
