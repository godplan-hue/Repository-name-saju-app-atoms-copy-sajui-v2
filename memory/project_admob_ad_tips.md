# 광고 비법 핵심 정리 (2026-08-09)

## 1. 광고수익으로 광고비 충당하는 구조
- 앱 안에 광고 달기 → 광고 수익 발생 → 그 돈으로 다시 광고 → 선순환
- 날씨체크 앱이 하는 구조: 토스 인앱광고 수익 → 홍보비로 재투자
- 점운 적용: 토스 TossAds 수익 → 비즈 월렛 프로모션 or 토스애즈 재투자

## 2. 바이럴이 광고보다 강하다
- 사람들이 좋아하는 콘텐츠 = 광고 없어도 공유됨
- "나도 해보고 싶다" 심리 → 자발적 확산 → 광고비 0원
- 점운 전략: MBTI/궁합/행운번호 결과지 공유 버튼 → 바이럴 핵심 무기

## 3. 키워드 = 질문 형식
- 사람들이 검색할 때 쓰는 말 그대로 키워드 세팅
- "사주 잘 맞아?" → 키워드: "사주 잘 맞는 앱"
- 블로그/SEO 콘텐츠도 질문 형식으로 제목 작성

## 4. Play Store 앱 광고 (나중에)
- 구글 앱 캠페인 → 스토어에서 직접 노출
- 현재는 웹앱이라 해당 없음 (네이티브 앱 출시 후 적용)

---

## 애드몹(AdMob) 필요 여부

**현재는 필요 없음**

| 상황 | 광고 도구 |
|---|---|
| 토스 미니앱 | TossAds (이미 적용됨) |
| jeomun.com 웹 | 구글 애드센스 (나중에 필요하면) |
| 네이티브 앱 출시 시 | 그때 AdMob 필요 |

- AdMob = 구글플레이/앱스토어 네이티브 앱 안에 광고 다는 SDK
- 현재 점운은 웹앱 + 토스 미니앱 구조 → AdMob 설치 불가, 필요도 없음
- 나중에 안드로이드/iOS 네이티브 앱 출시하면 그때 AdMob 연동

## Why: 에스더님이 광고비법 스크린샷 보내며 애드몹 필요 여부 질문 (2026-08-09)
## How to apply: 현재는 토스 TossAds에 집중. 네이티브 앱 계획 생기면 AdMob 검토
