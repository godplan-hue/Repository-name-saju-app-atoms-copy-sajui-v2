## 1. 사전 점검
- 게임·비게임 출시 가이드 모두 확인
- 앱 번들 압축 해제 기준 100MB 이하
- 대용량 리소스는 외부 CDN에서 다운로드 구성 (Lazy Loading 권장)

## 2. 검토 요청
- 테스트 1번 이상 완료해야 검토 요청 버튼 활성화
- 검토는 영업일 기준 최대 3일 (카테고리에 따라 7일+)
- 한 번에 한 버전만 제출 가능
- 수정 버그 발견 시: 요청 취소 → 새 번들 업로드 → 다시 검토 요청

## 3. 반려 시 처리
- 반려 사유 보기 → 문제 해결 → 새 번들 업로드 → 검토 요청
- 추가 문의: 채널톡

## 4. 출시
- 승인 이메일 수신 → 콘솔에서 '출시하기' 버튼 → 전체 사용자에게 즉시 반영
- 출시 전 충분한 테스트 필수

## 5. CORS 주의사항 (SDK 버전별 도메인)
**SDK 3.x**
- 실제 서비스: `https://<appName>.web.tossmini.com`
- QR 테스트: `https://<appName>.private-web.tossmini.com`

**SDK 1.x~2.x**
- 실제 서비스: `https://<appName>.apps.tossmini.com`
- QR 테스트: `https://<appName>.private-apps.tossmini.com`

> Firebase Realtime Database REST API는 기본적으로 모든 도메인 허용 → CORS 별도 설정 불필요

## 6. 출시 후 관리
- **업데이트**: 새 .ait 업로드 → 검토 요청 → 승인 → 출시 (기존 앱 대체)
- **롤백**: 앱 출시 메뉴에서 이전 버전 선택 → 출시하기 (즉시 반영)
- **긴급 핫픽스**: 채널톡으로 바로 문의
- **모니터링**: 오류 로그, API 응답 지연, 사용자 피드백(신고하기 → 신고 내역)

## 7. 사후 검수
- 출시 후에도 검수 진행 가능
- 법·정책 위반 시 긴급 운영 중단 가능

## 점운 적용 경험
- 다이어트 앱: 16개 크로스프로모 포함해도 통과 ✅
- MBTI/가계부 반려 원인: 앱 이름이 워크스페이스 내 유사 앱으로 분류됨 (크로스프로모 때문 아님)
- 해결책: 한글 앱 이름 변경 (점운 제거) → 심사 통과
