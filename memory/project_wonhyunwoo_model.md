# 원현우 점신 운영 방식

## 핵심 구조 (택갈이 모델)
- 사주 분석 프로그램 원가: 1~4천원
- 파트너가 "표지(브랜드)"만 만들어서 자기 상품으로 3~7만원에 판매
- AI + 미리캔버스로 표지 제작
- 100페이지 PDF 자동 생성 → 고객 이메일 자동 발송

## 파트너 영업 흐름
1. 파트너가 크몽·당근·인스타·쓰레드·X·네이버엑스퍼트 등에 홍보글 작성
2. 고객이 채팅으로 문의 (생년월일, 시간 등 전달)
3. 파트너가 계좌번호 안내 → 입금 확인
4. PDF 자동 생성 후 고객 이메일 발송
5. 추가 질문 → 원현우 본사 명리학 팀이 대신 답변

## 관리 방식
- 파트너 고객 정보: 엑셀로 직접 기입 관리
- 고객 문의: 본사 직원(명리학 팀)이 파트너 대신 응대
- 결제: 계좌이체 수동 방식

## 점운과의 차이
| 항목 | 원현우 점신 | 점운 |
|------|------------|------|
| 결제 | 계좌이체 수동 | Toss 자동 결제 |
| 고객응대 | 본사 직원이 대행 | 파트너가 직접 |
| 고객관리 | 엑셀 수동 | Firebase 자동 |
| 결과물 | PDF 이메일 발송 | 웹 결과지 |
| 파트너 관리 | 수동 | 대시보드 자동 |

## 점운의 약점 (원현우 대비)
- 파트너가 고객 문의 직접 응대해야 함 → 파트너 부담
- 해결 방향: FAQ 자동응답, 카카오 오픈채팅 연동, 파트너 대시보드 내 문의함

## 마케팅 퍼널 (스레드 + 유튜브)

### 무료 유입 채널
- **스레드**: 띠별 점수 게시글 (예: "12월은 반전운 달이다 🔥 소띠85점 용띠76점...") → 조회 1만회
  - 댓글로 생년월일/성별 받아서 개인 답변 → 문의 유도
- **유튜브**: AI 생성 노인 얼굴 + 운세 제목 숏츠 → 구독자 7천명, 동영상 30개
  - 설명란에 "무료 운세 이벤트" + 링크
- **무료 오늘의 운세 랜딩**: 이름/전화번호/생년월일 수집 → "무료운세 확인하고 쿠폰받기"

### 쿠폰 전략 (긴급성 가격)
1. 무료 운세 제공
2. 나중에 쿠폰 발송: "원래 3만원 → 2만원 할인 → 지금만 1만원!"
3. 긴급성으로 구매 전환

### 핵심 인사이트
- "정말 쉽지만 대충하면 안 됨 — 다양한 테스트 필요"
- 무료로 유입 → 연락처 수집 → 쿠폰으로 전환
- 유튜브는 AI 얼굴 + 자극적 제목 → 오늘의 운세 무료 랜딩으로 연결
- "오늘의 운세" 월 500만 검색량 활용

## 원현우 전체 수익 구조 (핵심 — 3중 수익)

### 실제 돈 흐름
```
수강생 → 원현우: 강의비 270~280만원 (4주 강의)
   ↓
수강생이 자기 상호명/랜딩페이지로 고객에게 3~7만원에 판매
   ↓
수강생 → 원현우: PDF 원가 1,000~3,000원 (건당)
   ↓
원현우 팀 → 고객: PDF 이메일 자동 발송 + 문의 대신 응대
```

### 3중 수익 구조
1. **강의비** 270~280만원 × 수강생 수
2. **건당 PDF 원가** 1,000~3,000원 × 판매 건수
3. **플랫폼**: coredev.co.kr (saju.coredev.co.kr) — PDF 생성 플랫폼 직접 운영 추정

### 플랫폼 (coredev.co.kr)
- 파트너 전용 상품 마켓플레이스
- 상품 목록: 월별운세(1,000원), 신년운세(3,000원), 궁합사주(3,000원), 이혼운세(4,000원), 재물사주(3,000원) 등 50종 이상
- 원가 1,000~4,000원 → 파트너가 3~7만원에 판매 → 차익이 파트너 수익
- 반려동물 궁합도 상품화 (다른 곳은 애매해서 안 만드는데 원현우가 만들어둠)

### 파트너(수강생) 역할
- 자기 상호명으로 랜딩페이지 개설 (카카오채널, 크몽, 인스타 등)
- 홍보·영업·결제(계좌이체) 수동 처리
- 고객 연락처+생년월일 원현우에게 전달 + 현금 송금
- 이후는 원현우 팀이 전담 (PDF 발송 + 문의 응대)

### 점운 대비 분석 업데이트
| | 원현우 점신 | 점운 |
|---|---|---|
| 파트너 진입비 | 270~280만원 강의비 | 월 구독료 (낮음) ✅ |
| 결제 | 계좌이체 수동 | Toss 자동 ✅ |
| PDF vs 웹 | PDF 이메일 | 웹 결과지 ✅ |
| 고객응대 | 본사 대행 | 파트너 직접 ⚠️ |
| 상품 다양성 | 50종+ | 10종 수준 ⚠️ |
| 파트너 관리 | 수동 엑셀 | 대시보드 ✅ |

### 점운의 핵심 열세
- **상품 종류**: 원현우 50종 이상 vs 점운 10종 — 콘텐츠 확장 필요
- **고객 응대 자동화**: 원현우는 본사가 대신해줌 → 파트너 진입 장벽 낮춤
- **강의 커뮤니티**: 수강생 = 마케터 군단 → 자체 유입 엔진

## 원현우 PDF 강점 포인트 (슬라이드 추가분)

### 제품 포지셔닝
- **100페이지 PDF** → "3만원에 말이 안 되는 분량" → 가성비 만족도 높음
- **전화사주 비교**: 5분=1.2만원, 30분=7만원 → AI PDF 3만원이 훨씬 이득 포지셔닝
- **전화사주는 듣고 나면 까먹음** → PDF는 생각날 때 다시 꺼내볼 수 있음 = 비대면의 핵심 장점
- **명리학 기반** → "아예 틀린 말은 하지 않게 제작" → 파트너가 자신 있게 판매 가능

### 대량 판매 논리
- 전통 점쟁이(1인 생산) vs AI 공장(무한 대량 생산)
- 파트너 역할: "고객 응대만 하면 끝!" → 나머지는 자동화

## coredev 랜딩페이지 시스템 (핵심 기능)

### 파트너가 랜딩페이지 직접 생성
- 캠페인 유형: 1인용 / 2인용 선택
- 패키지 구성: 상품명+가격 직접 세팅 (신년운세 30,000원, 연애운 12,000원 등)
- 입금 계좌: 은행명/계좌번호/예금주 직접 입력 → **파트너 통장으로 바로 입금**
- 구매 버튼명 직접 설정 ("구매 신청하기", "삶의 흐름 살아보기" 등)
- AI로 상세페이지 이미지 만들어서 랜딩 상단에 삽입

### 고객 구매 흐름 (계좌이체 방식)
```
파트너가 랜딩페이지 생성 (coredev)
    ↓
고객이 랜딩페이지 방문 → 정보 입력 → "구매 신청하기"
    ↓
시스템이 고객에게 자동 카톡/문자 발송 (입금 안내)
    ↓
고객이 파트너 계좌로 이체
    ↓
파트너가 주문 확인 → coredev에서 PDF 생성 → 고객 이메일 발송
```

### 랜딩페이지 관리 화면
- 목록: 캠페인명, 유형, 패키지, 공유링크, 방문수, 결과조회수, 전환율, 생성일
- 실제 예시: 진경비서-궁합(2인), 인스타그램용(1인), 오늘의 운세(1인) 등 여러 개 운영

### 실제 랜딩페이지 예시
- **저가형**: "신년운세 상담 가능 실컷 물어보세요 9,900원" — 노란 배너 + 입력폼
- **고급형**: "명리진경 진경비서" — 책 3권 이미지 + 고전 디자인
  - 진경비서 총집편 28,900원 / 재물편 13,900원 / 4월 운명록 13,900원
  - CTA: "삶의 흐름 살아보기"

### 커스터마이징 범위
- PDF 내 원국 표 스타일: 기본/친근한/전통 직인/세련된 선택 가능
- PDF 이미지 테마: 성디, 수목, 벡터, 가로 등 (50~52개 이미지)
