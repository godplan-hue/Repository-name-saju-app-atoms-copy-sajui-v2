### MBTI 전화번호 기반 Toss Storage 구조 (2026-07-26 추가)

**Toss Storage 키 구조 (전화번호 기반)**

| 키 | 내용 |
|---|---|
| `mbtiLastPhone` | 마지막으로 퀴즈 완료한 전화번호 |
| `mbtiResult_{phone}` | 해당 번호의 퀴즈 결과 JSON (answers + userName) |
| `mbtiPaidUntil_{phone}` | 해당 번호의 24시간 잠금해제 만료 timestamp |
| `mbtiReviewClaimed_{phone}` | 해당 번호의 리뷰 보상 수령 여부 |

**동작 원리:**
- 앱 시작 → `mbtiLastPhone` 확인 → 있으면 해당 번호 결과 자동 로드 → 결과지 바로 표시
- 같은 번호 + 24시간 내 → 잠금 자동 해제 상태 유지 (퀴즈 다시 안 해도 됨)
- 다른 번호 입력 → 저장 없음 → 퀴즈 처음부터 + 전면광고 + 섹션 잠김
- 퀴즈 완료 시 → `mbtiLastPhone` + `mbtiResult_{phone}` Toss Storage 저장
- 테스트 버튼 → 해당 번호 모든 키 초기화 + `mbtiLastPhone` 삭제
