## 1순위: MBTI + 다이어트 퀴즈→전화번호 순서 변경

### 변경 내용
- **현재**: 앱 시작 → 이름+전화번호 입력 → 퀴즈 → 결과
- **변경 후**: 앱 시작 → 퀴즈 → 마지막 문항 아래 이름+전화번호 입력 → 결과

### 이유
- 2026-07-28 광고 집행: 366명 진입 → 전화번호 **0명**
- 첫 화면에서 전화번호 요구 → 낯선 사람들 즉시 이탈
- 퀴즈 다 풀면 "결과 보고 싶다" → 전화번호 입력 의향 생김

### 대상 파일
- `jeomun-mbti/src/App.tsx`
- `jeomun-diet/src/App.tsx`

### 구현 방식
- 퀴즈 마지막 문항 선택 후 → 다음 화면에 이름(선택)+전화번호(필수) 입력란
- 입력 완료 → Firebase 저장 → 결과지 표시
