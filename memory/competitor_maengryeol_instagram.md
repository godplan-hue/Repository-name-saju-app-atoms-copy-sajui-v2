# 맹렬 인스타 수익화 강의 핵심 정리

> 에스더님이 무료강의 듣고 직접 캡처. 점운 인스타 릴스 마케팅에 적용 예정.
> 과정명: "내 인스타에 설치하는 '공짜 DB 자판기' 수익화 설계반 (1기)"
> 일정: 7/28(월) ~ 8/11(월), 온라인 3주, 매주 라이브 강의 + 과제 피드백

---

## 핵심 철학

### 1. "새벽 1시의 언어"
- 지갑을 여는 건 임상 용어가 아니라 **감정적·날것의 표현**
- 타깃이 새벽 1시에 좌절하며 쓸 법한 말 10개를 Reddit·커뮤니티·SNS 불만 글에서 실제 말투 그대로 추출
- 예시:
  - "일 년을 매일 올렸는데 조회수가 아직도 세 자리야... 나 지금 뭐 하는 거지."
  - "조회수만 높고 팔로워·돈은 안 돼..."
  - "이번 달은 벌었는데 다음 달은 0일 수도 있어. 통장 보면 불안해서 잠이 안 와."
- 이 문장을 **헤드카피 & 릴스 첫 3초**에 그대로 사용 → "내 머릿속에 들어왔다 나갔나?" 반응

### 2. 목적별 콘텐츠 퍼널 (아무거나 20개 금지)
```
노출 → 흥미 → 욕구 → 신뢰 → 구매
```
- **노출**: 떡상형 릴스 (넓은 공감·후킹)
- **흥미**: 노하우 맛보기, 사례 공개
- **욕구**: 성과 인증, Before/After
- **신뢰(기억)**: 세계관·스토리, 반복 시그니처
- **구매**: 무료 미끼 안내, 특강·상품 CTA

## AI 애니릴스 제작 7단계 (힉스필드 사용)

1. **떡상 영상 찾기** — 솔트피드로 터진 영상 찾고 왜 터졌는지 분석
2. **사실관계 검토** — 제미나이에 캐릭터 이미지 생성 프롬프트 요청
3. **기준 캐릭터 제작** — 프롬프트 + 로고 이미지로 힉스필드에서 흰 배경 T포즈 캐릭터 생성
4. **씬별 이미지 만들기** — 대본을 씬으로 나누고, 씬별 이미지 프롬프트로 기준 캐릭터 + 장면 생성
5. **영상 프롬프트 생성** — 완성된 씬 이미지 첨부해 동작·대사·말투·배경음악·효과음 포함 영상 프롬프트
6. **씬별 영상 제작** — 힉스필드에서 씬별 영상 생성
7. **최종 릴스 완성** — 캡컷에서 하나의 릴스로 편집

## 사용 도구

| 도구 | 용도 |
|------|------|
| **솔트피드** | 인스타 떡상 릴스 찾기 + 다운로드, 제작자별 분류 |
| **제미나이** | 대본 분석, 캐릭터 생성 프롬프트, 새 대본 작성 |
| **힉스필드** | AI 애니 캐릭터 이미지 + 씬별 영상 생성 |
| **캡컷** | 최종 릴스 편집 |
| **리드젠(leadgeny.kr)** | GPT/제미나이로 코딩한 랜딩페이지 배포 + DB 수집 |
| **알파겟이야** | 유튜브 링크 → 조회수 구간만 골라 5분 만에 쇼츠 추출 |
| **미니 맥스** | 클론 보이스 (마이크 녹음 없애기) |
| **Claude Projects** | 지식 먹이기 → 미끼 전자책 1시간 완성 |
| **카카오톡 채널** | DB 담는 그릇 + 자동 응대 |

## 상품 4단 구조 (계단식 가격)

| 단계 | 가격 | 목적 | 예시 |
|------|------|------|------|
| ① 저가 | 1~5만 | 팬 만들고 첫 지갑 열기 (미끼) | PDF·떡상 릴스 VOD·템플릿 |
| ② 중가 | 30~50만 | 꾸준한 매출의 본상품 (강의) | 체계화한 VOD 미니클래스 |
| ③ 고가 | 165~550만 | 문제 직접 해결 (코칭/대행) | 6주 라이브·1:1 코칭·대신 세팅 |
| ④ 구독형 | 월 3~9만 | 데일리 체크·멤버 커뮤니티 | 월간 라이브 코칭 |

> "중가는 새로 만들지 말고 고가 과정을 편집하면 된다"
> "저가는 수익이 아니라 '첫 결제 경험' 미끼"
> "진짜 매출은 고가에서 터진다"

## 미끼 전자책 제작 프로세스

1. Claude Projects에 내 지식 먹이기 (음성·영상 대본·코칭 기록)
2. 프롬프트: "가치 있지만 얇게, 유료로 업셀되게. 목차부터."
3. 디자인 대화: "여백 줄이고 타이트하게, SVG 일러스트 넣어줘"
4. 완성 직후: "미끼 전달하고 유료 전환시키는 이메일 시퀀스 써줘"
5. GPT/제미나이로 랜딩페이지 코딩 → 리드젠에 얹어 배포

## 맹렬 1기 과정 커리큘럼

- **WEEK 1**: 기획·상품 — 뾰족한 미끼 + 저·중·고 상품 라인업 설계

가격: 기본 48만원 / 1:1 밀착 120만원 (선착순 2명)

## 점운에 적용할 것

- 타깃 "새벽 1시의 언어" 추출 → 사주 고민 관련 커뮤니티 불만 글 분석
- AI 애니릴스로 점운 콘텐츠 제작 (솔트피드+제미나이+힉스필드+캡컷)
