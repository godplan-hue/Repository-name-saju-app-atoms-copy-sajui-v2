**⛔ 2026-08-21부로 이 규칙은 완전히 해제됐다. "수정 금지"인 토스 미니앱은 더 이상 없다.**

에스더님 명시적 지시: "다이어트이제수정된다고저장해랫잔아 이제수정안되는토스앱ㅇ은없어" — 다이어트를 포함해 어떤 토스 미니앱(jeomun-diet/jeomun-mbti/jeomun-gamjung/jeomun-momcare/jeomun-budget 등)도 이제 자유롭게 수정 가능. jeomun.com 웹사이트(saju-app-atoms) 쪽은 원래부터 제한 없었음(변화 없음).

**How to apply:** 이제 "OO 토스앱 건드려도 돼요?" 같은 확인 질문 자체가 필요 없다. 다른 앱과 완전히 동일하게 바로 작업 진행. 다만 작업이 실제 배포/출시된 버전이나 다른 앱에 영향을 주지 않도록(에러 없이) 신경 쓸 것 — 특히 죽은 코드를 다시 넣거나 되살리지 않도록 주의.

**Why (과거 배경, 참고용):** 이 규칙은 원래 2026-08-08 토스 미니앱 `jeomun-diet`에서 git reset으로 소스가 영구 소실된 사고 이후 그 프로젝트 하나에만 조심스럽게 적용하려던 것이었다. 이후 범위가 불명확하게 저장돼 웹앱까지 확대 해석되는 실수가 반복됐고(2026-08-15, 2026-08-17 각각 정정), 2026-08-17엔 "명시적 작업 승인 시엔 그 범위 안에서 수정 가능"이라는 예외 조항까지 추가됐었다. 2026-08-21, 에스더님이 이 예외를 넘어 규칙 자체를 완전히 폐지하기로 확정했다.

**참고— 실제 이 세션에서 한 일 (2026-08-21):** gamjung·budget·diet 3개 앱에서 `registerMode`(전화번호 변경/번호전환) 기능을 소스코드에서 완전 삭제. 다른 번호로 전환 시 영구저장 데이터가 유실되는 사고가 과거 있었기 때문에, 전화번호는 절대 수정 불가로 확정(육아일기 momcare의 `editMode`와 동일 정책 — momcare는 전화번호는 잠그고 다른 정보만 수정 가능한 화면이 있고, 그 외 3개 앱은 정보수정창 자체가 없음). diet는 UI 진입버튼은 이미 이전 커밋(`79998f4`)에서 제거돼 있었지만 죽은 코드(state·함수·분기·JSX)가 남아있어 gamjung/budget과 동일하게 정리함 (commit `28d6884`). 이 정보수정창들은 다시 만드는 것이 아니라 완전히 제거하는 작업이었음 — 향후 세션에서 실수로 이 기능을 되살리지 않도록 주의.
