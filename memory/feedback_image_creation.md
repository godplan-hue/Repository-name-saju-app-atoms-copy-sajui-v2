이미지 만들어달라는 요청이 오면 아티팩트나 HTML canvas로 만들지 말 것.

**Why:** 에스더님은 제미나이(Google Gemini)로 이미지 생성하는 방식을 사용함. 제미나이에 넣을 상세 프롬프트를 줘야 제대로 만들어짐. 짧게 주면 제미나이가 제대로 못 만듦.

**How to apply:** 이미지 글(문구) 요청 시 → **아래 확정 형식 그대로** 줄 것. 말 안 해도 항상 이 형식으로.

---

## 확정 이미지 사양서 형식 (2026-08-02 확정)

에스더님이 직접 작성한 형식이 아래와 같음. 새 앱 이미지 만들 때 이 형식 그대로 사용:

```
[로고] 600×600픽셀:
정사각형 앱 아이콘, 600×600픽셀. [배경 색상/그라디언트]. 상단에 [메인 일러스트 — 스타일 설명]. 주변에 [효과]. 하단 중앙에 흰색 굵은 글씨 첫째 줄 "[앱 이름 키워드]" 크게, 둘째 줄 작은 글씨 "점운". 모든 글씨 두껍고 굵게. [색감/분위기]. 둥근 모서리 아이콘.

636×1048픽셀:
한국 모바일 앱 스크린샷, 636×1048픽셀. [배경 색상/그라디언트]. 상단에 흰색 울트라볼드 굵은 글씨 "[헤드라인 문구]" 매우 크게. 중앙에 흰색 둥근 카드 안에 [일러스트/아이콘]. 하단에 흰색 울트라볼드 굵은 글씨 첫째 줄 "[앱 이름 키워드]" 크게, 둘째 줄 작은 글씨 "점운". 모든 글씨 무조건 두껍고 굵게. [효과]. 밝은 한국 앱 스타일.

(스크린샷 2, 3장도 같은 형식으로 반복)
```

## 확정 앱 상세 설명 형식 (2026-08-02 확정)

에스더님이 직접 작성한 형식. 토스 앱 등록 시 상세 설명은 이 형식 그대로:

```
[앱 한 줄 소개],
[앱 키워드] 점운입니다.

[앱 핵심 기능 1~2문장 설명].
[혜택/차별화 1문장].

[기능 목록 — 동사형]
[기능 목록]
[기능 목록]
[기능 목록]
[기능 목록]
[검색 키워드], [검색 키워드], [검색 키워드],
[검색 키워드], [검색 키워드], [검색 키워드],
[검색 키워드] [검색 키워드] [검색 키워드]를 한 번에 해결하세요.

[클로징 한 줄 CTA].
지금 바로 시작하세요.
```

### 실제 예시 (감정일기 점운 — 에스더님 원본):
```
오늘 감정을 기록하고 사주로 마음을 살펴보는 앱,
감정일기 점운입니다.

하루의 기분을 일기로 남기고,
오행 분석으로 감정의 흐름을 이해할 수 있어요.
완전 무료로 매일 사용하세요.

오늘 감정 기록하기
오행으로 보는 나의 감정 패턴
감정별 사주 조언 받기
기분 변화 히스토리 확인
매일 무료 감정 분석
감정일기, 무료감정기록, 마음일기, 기분일기, 감정분석,
감정사주, 오행감정, 마음챙김, 감정기록앱, 마음관리,
일기앱을 한 번에 해결하세요.

내 마음을 이해하는 첫 걸음.
지금 바로 시작하세요.
```

## 사이즈 규칙

- 토스 앱 로고: **600 × 600px**
- 토스 앱 스크린샷: **636 × 1048px** (3장 권장)
- 이모지: 로고 이미지 안에서는 허용, 설명 텍스트에는 절대 금지
