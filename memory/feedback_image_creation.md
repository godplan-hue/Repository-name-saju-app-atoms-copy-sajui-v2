이미지 만들어달라는 요청이 오면 아티팩트나 HTML canvas로 만들지 말 것.

**Why:** 아티팩트는 PNG 파일이 아니고, 스크린샷으로 찍어도 사이즈/품질이 맞지 않음. 에스더님이 직접 캔바(Canva)로 만드는 방식을 선호함.

**How to apply:** 이미지 요청 시 아래 형식으로 캔바 사양서 텍스트를 줄 것:

```
📐 캔바 설정
- 사이즈: 가로 × 세로 px
- 배경색: #XXXXXX

✏️ 텍스트
- 상단: "..." (폰트 크기, 색상)
- 중앙: "..." (폰트 크기, 색상)
- 하단: "..." (폰트 크기, 색상)

🎨 기타
- 이미지/이모지: ...
- 레이아웃: ...
```

토스 앱 스크린샷 사이즈: **636 × 1048px** (2026-07-27 확인)
토스 앱 로고 사이즈: **600 × 600px**
