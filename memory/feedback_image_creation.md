이미지 만들어달라는 요청이 오면 아티팩트나 HTML canvas로 만들지 말 것.

**Why:** 에스더님은 제미나이(Google Gemini)로 이미지 생성하는 방식을 사용함. 제미나이에 넣을 상세 프롬프트를 줘야 제대로 만들어짐. 짧게 주면 제미나이가 제대로 못 만듦.

**How to apply:** 이미지 글(문구) 요청 시 → **제미나이 프롬프트 형식으로 자세하게** 줄 것. 말 안 해도 항상 이 형식으로:

```
[장수/용도] 가로×세로px:
배경색(#코드), 상단 텍스트 스타일+내용, 중앙 일러스트/아이콘 설명, 
카드 안 텍스트 스타일+내용, 하단 텍스트/버튼 내용, 
효과(반짝이 등), 전체 스타일(한국어 앱 스타일)
```

각 장을 구분해서 장별로 따로 줄 것.

토스 앱 스크린샷 사이즈: **636 × 1048px**
토스 앱 로고 사이즈: **600 × 600px**
