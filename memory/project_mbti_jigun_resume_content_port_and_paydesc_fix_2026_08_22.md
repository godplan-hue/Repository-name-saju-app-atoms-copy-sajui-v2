토스 미니앱(jeomun-mbti/jigun/resume)에 먼저 추가됐던 신규 콘텐츠를 jeomun.com 웹앱(app/mbti, app/jigun, app/resume)에도 이식하는 작업. 기존 잠금/결제 로직은 전혀 안 건드리고 콘텐츠만 추가함.

**1차 커밋 `b46da1f` (콘텐츠 이식, push 완료):**
- MBTI: 돈스타일/전생/흑화/이중생활 4종 추가, 기존 990원 잠금 재사용, 잠금화면 "14가지"→"18가지" 표기도 수정됨
- 직운: TOP4/부업경고/로드맵/수입시뮬 등 5개 섹션 추가, 기존 24시간 잠금 그대로
- 합격자소서: 감점표현/면접관선호/합격스토리라인/인기기업/연봉타이밍 5개 섹션 추가, 기존 잠금 그대로

**2차 커밋 `a41eec6` (직운·합격 pay페이지 버그 발견+수정, push 완료):** 에스더님이 "MBTI는 결제전 설명이 수정됐는데 직운·합격은 안된 듯"이라 지적 → `app/jigun/pay/page.tsx`, `app/resume/pay/page.tsx`의 결제 전 소개문구가 콘텐츠 이식 전 옛날 항목만 나열돼있었음. 신규 섹션 이름 추가해서 수정.

**3차 커밋 `b60769b` (MBTI도 같은 버그, push 완료):** 에스더님이 "엠비티아이도 옛날내용같은데" 재지적 → 확인해보니 `app/mbti/result/[id]/page.tsx`의 결과지 내 잠금오버레이는 "18가지"로 이미 맞게 반영돼있었지만, **별도로 존재하는 `app/mbti/pay/page.tsx` 결제페이지**에는 옛날 5개 항목(연애/커리어/스트레스/인간관계/성장)만 있고 신규 5개(돈스타일/전생/흑화/이중생활/썸)가 빠져있었음. MBTI도 직운/합격처럼 결과지 잠금화면과 별개의 `/pay` 페이지가 따로 있다는 걸 처음엔 놓쳤음.

**결론: 990원/24시간 개별결제 앱 3개(MBTI/직운/합격자소서) 전부 `/pay` 페이지 설명 최신화 완료.**

**Why:** 결제 전 설명에 새로 추가한 콘텐츠가 안 보이면 유저가 "이게 다야?" 하고 결제 안 할 수 있음 — 무엇을 파는지와 결제 페이지 안내가 어긋나면 전환율에 직접 영향.

**How to apply:** 앞으로 결과지에 새 섹션/콘텐츠 추가할 때마다, 그 앱에 별도 `/pay` 결제페이지가 있는지 **반드시** 확인하고 있으면 설명 문구도 같이 업데이트할 것. 결과지 안에 잠금 오버레이가 있다고 해서 `/pay` 페이지 설명도 자동으로 맞다고 착각하면 안 됨 — MBTI에서 이 착각으로 한 번 놓쳤음. 두 곳(결과지 잠금 오버레이 + `/pay` 페이지)을 항상 세트로 확인할 것.
