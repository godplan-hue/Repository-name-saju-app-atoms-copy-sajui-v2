## 현재 결제 현황 (2026-07-17 확인)

**현재 연동된 PG: 페이업(PayUp)**
- 토스페이먼츠 아님 — 페이업이 실제 카드 결제 처리 PG
- 월 카드 결제 한도: 200~300만원

**파트너 결제 방식 (현재 수동)**
- 파트너들이 자기 고객에게 현금 수령 → 에스더에게 계좌이체
- jeomun.com 자동 카드 결제 시스템 파트너에게 미적용
- 파트너 판매 최소가: 9,900원 (990원 불가)

**카드 한도 문제**
- 월 200~300만원 한도 → 대량 마케팅/결제 불가
- KCP·카카오페이 PG 승인 나야 한도 해소됨

**크몽 전략이 현실적인 이유**
- 크몽은 크몽 자체 결제 → jeomun.com 카드 한도와 무관
- 파트너 모집 가입비를 크몽에서 받으면 한도 제약 없음

**Why:** 토스페이먼츠로 알고 있다가 에스더가 직접 정정해줌
**How to apply:** 결제 관련 코드/설명 시 항상 "페이업"으로 칭할 것. "토스페이먼츠 카드 결제 되잖아요" 같은 말 절대 금지.
