# 16Personalities 경쟁사 분석

**URL**: 16personalities.com/ko
**글로벌 1위 MBTI 사이트**

## 퀴즈 구조
- 10단계 (페이지당 약 6문항) → 총 약 60문항
- 7점 척도 (그렇다 ←○○○○○○○→ 그렇지 않다)
- 이전 페이지 버튼, 상단 진행바 (X/10단계)
- 마지막 페이지에 이메일 입력 (선택)

## 결과 페이지 구조 (INFJ 옹호자 예시)
1. **헤더**: 유형명(옹호자) + 코드(INFJ-T) + 배경 일러스트
2. **우측 사이드바**: 섹션 네비게이션 + 공유/비교 버튼 (PC)
3. **성격 특성 (4개 슬라이더)**:
   - 63% 내향형 / 57% 직관형 / 53% 감정형 / 93% 계획형 / 75% 민감형 (5번째 축!)
   - 각 축에 영문 설명 + 그림
4. **설명 본문**: 2~3 단락 깊은 성격 묘사
5. **커리어 패스**: 강점/약점 체크리스트 + 잠금 콘텐츠 일부 블러
6. **개인적 성장**: 강점/약점 + 잠금
7. **인간관계**: 강점/약점 + 잠금
8. **유명인**: 같은 유형 유명인 캐릭터 슬라이더
9. **공유 모달**: 두 가지 링크 (유형 URL / 개인 결과 URL)
10. **비교 모달**: 파트너 초대 or 직접 입력
