## 유저 상황
- 지금 당장 매출 필요 (경제적으로 매우 어려운 상태)
- SNS/인스타 마케팅은 약함
- 크몽 상위 2% 프라임 계정 보유
- 탈잉 2년 1위 계정 보유

## 빠른 매출 방법 (우선순위 순)

### ① 크몽 "AI 사주 분석" 서비스 등록 ← 제일 빠름
- 카테고리: 운세/사주
- 서비스명: "AI 사주 분석 — 생년월일만 알려주세요"
- 가격: 9,900원 (기본) / 29,000원 (심층)
- 방법: 고객이 생년월일 보내면 → 점운 앱으로 결과 생성 → 링크 전달
- 코드 작업 불필요, 오늘 바로 가능
- 프라임 계정이라 노출 유리

### ② 카카오 모먼트 광고
- 하루 1만원부터 시작
- 타겟: 20-40대 여성
- 키워드: "990원 사주"

### ③ 탈잉 "Claude로 앱 만들기" 강의
- 47세 컴맹 → 800시간 → 앱 출시 스토리
- 탈잉 1위 계정 보유
- 이 스토리는 진짜 희귀하고 잘 팔림

### ④ 경쟁사 키워드 광고 ← 핵심 비법 (포트원 연동 완료 후)
- 점신(1900만 유저) 키워드 타겟 → 점운 광고 노출
- 카카오 모먼트 + 구글 애즈 둘 다 가능
- 점신 키워드 경쟁자 적어서 클릭당 100-300원 예상
- 하루 1만원 = 30-100명 유입 가능
- 점신 먼저 테스트 → 성과 나오면 사주아이로 확장
- 유저가 광고 비법 알고 있음 (구매대행으로 경험, 이번엔 제대로 적용)
