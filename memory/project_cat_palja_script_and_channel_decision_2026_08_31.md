## 고양이 "내 팔자야" 스크립트 (30초 숏폼, 확정 초안)

패턴: 권위 있어 보이는 사주 용어(사납다/역마살)를 던지고 → 고양이 일상(20시간 잠, 캣타워~소파 이동반경)으로 반전 개그, 마지막에 재물운(집사가 벌어다 바침)으로 마무리 + "점운에서 무료로 확인" CTA. 가격 문구 없음.

1. 고양이 늘어져 누움 — 자막 "고양이도 사주 보면 이럴까?" / 내레이션 "어젯밤 심심해서 내 사주를 봤다"
2. 고양이 화면 보는 척 — 내레이션 "근데... 이게 뭔 소리야" / 자막 "결과: 팔자가 사납다"
3. 고양이 발라당 — 내레이션 "나 하루에 20시간 자는데 뭐가 사납다는거야" / 자막 "역마살 있음(돌아다니는 팔자)"
4. 캣타워↔소파 왔다갔다 — 내레이션 "역마살은 무슨... 내 이동반경은 캣타워에서 소파까지인데"
5. 고양이 클로즈업, 시크한 표정 — 내레이션 "근데 재물운 하나는 진짜였다" / 자막 "재물운: 최상 (집사가 다 벌어다 바침)"
6. 밥그릇 앞 고양이 — 내레이션 "역시 난 될놈이었어" / 자막 "사주는 모르겠고 일단 간식 내놔 🐾"
7. 엔딩 CTA — 자막 "너의 팔자는 어떨까? → 점운에서 무료로 확인"
