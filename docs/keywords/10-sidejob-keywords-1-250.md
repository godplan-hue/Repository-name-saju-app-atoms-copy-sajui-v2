## 점운 핵심 차별화

> **기획의신Esther님 강점: 콘텐츠 기획·전자책·강의·1인창업 경험**  
>  
> 사용자 경험·관심사 입력 → AI가 1개 리포트로:  
> 적합 부업 후보 → 시장성·경쟁도 → 예상 준비 기간 → 필요 역량  
> → 실행 순서 → 콘텐츠 아이디어 → 수익모델 예시  
> → (선택) 사주 성향 기반 "가장 잘 맞는 분야" 참고 정보  
>  
> → **실행 가능한 사업 설계 플랫폼** (단순 추천 앱 X)
