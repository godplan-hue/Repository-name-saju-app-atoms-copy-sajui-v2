# 점운 SEO/GEO 5년 로드맵 (12편)

> 출처: AI 경쟁사 분석 (2026-07-05)  
> 핵심 질문: 어떻게 하면 점신·사주아이처럼 검색이 폭발하는가?

---

## 1단계 — 오픈~3개월: 구글·네이버가 점운을 인식하게 만든다

**목표 페이지 수**: 3,000~5,000개 (중복 없이, 실제 도움이 되는 콘텐츠)

**필수 카테고리**:
- ✅ 사주
- ✅ 꿈해몽
- ✅ 오늘운세
- ✅ 띠운세
- ✅ 별자리운세
- ✅ 이름풀이
- ✅ 궁합
- ✅ 타로

**자동 생성 일일 콘텐츠**:
- 오늘운세 / 오늘행운번호 / 오늘행운색 / 오늘명언 / 오늘재물운 / 오늘연애운

**하루 목표**: 페이지 50~100개

---

## 2단계 — 3~6개월: AI 검색 최적화(GEO)

질문형 검색 → AI 답변 → 관련 서비스 연결 흐름 구축

```
"꿈에서 뱀이 나왔어요."
→ AI 답변
→ 관련 꿈
→ 관련 운세
→ 관련 사주
→ 관련 상담
→ 관련 상품
→ 회원가입
```

---

## 3단계 — 6개월~1년: 서비스 확장 연결

```
부업 → 창업 → 취업 → 자소서 → 육아 → AI상담 → 전체 연결
```

## 점운의 핵심 차별점

**경쟁사**: 검색 → 결과 → 끝

**점운**:
```
검색
→ AI
→ 관련 서비스 추천
→ 회원가입
→ 구독
→ 다음날 재방문
→ 포인트
→ 리포트
→ AI코치
→ 평생회원
```

## 추천 핵심 기능: AI 인생 대시보드

> 사용자마다 첫 화면이 다름 (개인화)

- 오늘운세 / 오늘 해야 할 일 / 오늘 목표
- 오늘 부업 / 오늘 공부 / 오늘 운동 / 오늘 독서
- 오늘 행운번호 / 오늘 명언 / 오늘 AI조언
- 오늘 일정 / 오늘 알림

## 재방문 유도 메커니즘 (검색 유입보다 중요)

검색으로 100만명이 들어와도 다 나가면 의미 없음.  
**매일 들어올 이유를 만들어야 한다.**

- 출석 포인트
- 행운번호
- 오늘운세
- AI상담
- 미션 / 뱃지 / 레벨
- 성장기록

---

## 점운 OS 개념

> 운세앱이 아니라 사람의 인생을 관리하는 **운영체제(OS)**

```
아침 → 오늘운세
출근 → AI업무도우미
점심 → AI부업추천
퇴근 → AI창업
밤 → 꿈해몽 / 육아 / 명상 / AI상담
다음날 → 오늘운세 (반복)
```
