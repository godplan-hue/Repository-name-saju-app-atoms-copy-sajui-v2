## 각 채널 상세

### ✅ SEO 랜딩페이지 (현재 66개 운영 중)
- **비용**: 0원
- **원리**: 검색엔진에서 "사주/운세" 검색 시 유입 → 이미 구매 의향 있는 사람
- **장점**: 한 번 만들면 영구 무료 유입, 구매 전환율 최고
- **단점**: 효과 나타나기까지 2~8주 소요
- **현황**: 구글/네이버/다음/빙 4곳 심사 중 (2026-07-04)

### 🔴 네이버 키워드광고 — **한국 유일 필수 유료광고**
- **이유**: 한국인 70%가 구글 아닌 네이버에서 검색
- **비용**: 클릭당 500~3,000원 (사주 키워드 기준)
- **효과**: 즉시 네이버 검색 1페이지 상단 노출
- **권장 예산**: 하루 3만원 (월 90만원)부터 시작
- **계산**: 100클릭 → 5~10명 구매 → 990원 × 7명 = 6,930원 수익 vs 15만원 광고비
  → 처음엔 적자지만 데이터 쌓이면 최적화 가능

### 🟡 메타광고 (인스타그램 + 페이스북)
- **비용**: 하루 1만원~
- **타겟**: 20~40대 여성 정밀 타겟팅 가능
- **특징**: 검색광고와 달리 내가 먼저 보여주는 방식 (구매 의향 낮음)
- **추천**: 네이버 광고 다음 2순위

### 🟡 구글 애즈
- **비용**: 클릭당 300~1,500원
- **한국 상황**: 네이버가 더 중요하지만 구글 검색량 증가 중
- **추천**: 네이버, 메타 다음 3순위

### 🟢 네이버 블로그 (무료 중 최고 효과)
- **비용**: 0원
- **방법**: 사주 관련 글 꾸준히 작성 → 점운 링크 삽입
- **목표**: 글 1,000개 수준 → 네이버에서 상위 노출
- **특징**: AI로 글 대량 생성 가능 (추후 작업 예정)

### 🟢 틱톡 유기적 (무료)
- **비용**: 0원
- **가능성**: "990원 사주 해봤어요" 리뷰 영상 → 수십만 뷰 바이럴 가능
- **타겟**: 10~20대

### ⚠️ 헷갈리는 두 가지

**구글 애드센스** — 광고를 하는 게 아니라 광고를 받아서 돈 버는 서비스  
→ 우리 사이트에 광고 배너 달면 방문자 클릭 시 수입  
→ 직접 수익 모델 있는 서비스엔 비추 (지저분해지고 이탈 증가)

**구글 애드몹** — 스마트폰 네이티브 앱 안에 광고 넣는 서비스  
→ 점운은 웹앱 → 해당 없음 (나중에 네이티브 앱 만들 때 검토)

## 점운 맞춤 광고 로드맵

```
단계 0 (현재, 무료): SEO 랜딩페이지 66개 ✅
     ↓ 2~4주 후
단계 1: 검색 유입 시작 → 매출 데이터 확인
     ↓
단계 2 (유료 시작): 네이버 키워드광고 (월 30~100만원)
     키워드: 990원사주, 무료사주, 오늘의운세, AI사주 등
     ↓
단계 3: 인스타그램 광고 (월 30~50만원)
     타겟: 20~40대 여성, 연애/재물 관심사
     ↓
무료 병행: 네이버 블로그 1,000개 글 + 틱톡 영상
```

## SEO vs 유료광고 장기 비교

| 항목 | SEO | 유료광고 |
|------|-----|---------|
| 초기 비용 | 0원 | 월 30~100만원+ |
| 효과 시작 | 2~8주 | 즉시 |
| 지속성 | **영구** | 돈 내는 동안만 |
| 1년 후 트래픽 | 계속 증가 | 광고비 멈추면 0 |
| 구매 전환율 | **높음** (검색 의향 있음) | 중간 (노출 중심) |
| 5년 총비용 | **0원** | 1,800~6,000만원 |

**결론**: SEO는 장기적으로 가장 저렴하고 효과적. 유료광고는 SEO 효과 나오기 전 초반 매출 보완용.
