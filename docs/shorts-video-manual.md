# 채널 2 — 할머니 (신규)

## 참고 채널

운세천당 (유튜브 2.48만 / 인스타 13.1만)

## 제목 공식

```
[띠 2개] + [날짜] + "절대" + [행동] + "안 되는" + [명사] + [숫자]가지
```

**실제 예시**

```
뱀띠 양띠 7월 절대 받으면 안 되는 물건 3가지    36.9만
원숭이 양띠 8월 절대 받으면 안 되는 물건 3가지  14.5만
소띠 양띠 7월 31일 먹으면 안 되는 음식 3가지    9.5만
용띠 뱀띠 7월 먹으면 안 되는 음식 100억 내린다  8.2만
```

**소재 4개만 반복**

| 소재 |
|---|
| 받으면 안 되는 **물건** |
| 먹으면 안 되는 **음식** |
| 가면 안 되는 **장소** |
| 만나면 안 되는 **사람** |

12띠를 2개씩 묶어 6조합 × 소재 4개 = **24개 자동 생산**

## 대사 5단계 (원본 구조)

```
1. 띠 지목      "남자가 평생 못 이기는 기 센 여자띠 셋"
2. 크게 부풀림  "20년에 한 번 오는 대재물성이 열린다"
3. 명령 3개     "할미를 두 번 눌러라"
                "댓글에 대박운 적어라"
                "점운에서 복문 챙겨가거라"
4. 손실 경고    "안 챙기면 이 운이 그냥 지나간다"
5. 범위 좁히기  "특히 88년생, 음력 2·5·9·11월생은"
```

**5번이 핵심.** 띠로 넓게 걸고 뒤로 갈수록 좁혀서 끝까지 보게 만든다.

## 레퍼런스 영상 실제 구조 분석 (2026-09-18 추가 확정)

운세천당류 실제 레퍼런스 영상을 프레임 단위로 분석한 결과. 위 프롬프트 템플릿보다 이 구조가 우선한다.

**영상 자체는 거의 안 움직인다**
- 할머니가 촛불 앞에 앉아서 말만 한다. 배경 안 바뀌고 카메라 고정. 표정·입·손만 자연스럽게 움직임 (Veo로 잘 나오는 수준, 어려운 동작 아님)
- 컷 전환 없음 → 여러 개 이어붙여도 티 안 남

**움직이는 건 자막과 커서 화살표, 이 두 개뿐**

1. **자막이 핵심** — 큰 검은 글씨 + 흰 배경 박스, 화면 **정중앙**, 한 문장씩 교체됨
   ```
   세 분이 계십니다
   저를 두 번 누르고
   '대박 운'
   챙겨가 주세요!
   ```
   소리 꺼도 내용이 다 이해됨. **문장마다 바뀌는 자막**이라 Veo 고정 자막(TOP/BOTTOM held throughout)으로는 못 만든다.

2. **커서 화살표** — "저를 두 번 누르고"에서 파란 커서가 나타나 클릭 애니메이션. 따라 누르게 유도. Veo로 못 만듦, 편집으로 삽입.

**마지막 부적 장면** — 화면이 통째로 금색 부적 이미지로 전환, 반짝임 + "챙겨가 주세요!" 자막. 할머니 영상 → 부적 이미지 두 장면만 있으면 됨.

### 자막 방식 확정 — 캡컷 자동 캡션 사용

- Veo 프롬프트에 자막을 고정으로 넣는 방법도 있지만 한 문장씩 못 바꿈 (효과 덜함)
- **확정: 캡컷 자동 캡션 기능 사용**
  1. 캡컷에 영상 넣기
  2. 텍스트 → 자동 캡션 (말하는 대로 자막 자동 생성, 직접 타이핑 불필요)
  3. 글자 크기·색만 키우기
- 화살표는 그 다음 단계, 없어도 자막만 있으면 됨 (선택사항)
