## 공통 원칙

- 모든 앱은 **템플릿 기반** (실시간 AI API 최소화)
- 결제는 **Toss Payments** 통일
- DB는 **Firebase RTDB** 통일
- 스타일은 **인라인 스타일** (Tailwind 금지)
- 파트너 화이트라벨 구조 검토 (점운 파트너 시스템 참고)
