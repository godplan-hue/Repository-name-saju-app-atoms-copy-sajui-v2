---

## 핵심 포지셔닝 전환

```
현재 → "사주앱"
목표 → "사람의 인생 전체를 관리하는 AI 라이프 플랫폼"
```

### 점운 LIFE 비전

하루 전체를 점운 안에서:

```
아침: 오늘 운세 → 회사: 자소서 준비 → 퇴근: 부업 아이디어
밤: 꿈해몽 → 육아 고민 → AI 상담 → 다음날: 오늘 운세
```

사용자가 "어디로 갈까?" 고민할 때 항상 점운이 답을 주는 구조.

---

## 점운 LIFE — "인생 리포트" 핵심 기능

사용자 입력:
> "저 올해 퇴사해도 될까요?"

AI가 하나의 리포트로 제공:
- 사주·재물운 분석
- 현재 취업 시장 상황
- 적합한 부업·창업 옵션
- 자소서 준비 체크리스트
- 면접 준비 가이드
- 심리 성향 분석
- 구체적 행동 계획

**→ 국내에 거의 없는 구조. 차별화 최고.**
