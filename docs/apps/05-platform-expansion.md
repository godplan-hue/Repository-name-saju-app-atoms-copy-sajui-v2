## 사용자 흐름 (교차 이용 설계)

**꿈 유입 → 사주 전환:**
```
뱀꿈 검색 → 꿈해몽 → AI 분석 → "사주도 함께 보시겠어요?" → 점운 유료
```

**취업 유입 → 운세 전환:**
```
자소서 완성 → 면접 준비 → "이번 달 취업운" → "면접일 추천" → 사주 유료
```

**육아 유입 → 운세 전환:**
```
태몽 검색 → 꿈해몽 → 아이 사주 성향 → 이름풀이 → 점운 가입
```

**고민상담 → 전체 연결:**
```
"퇴사할까요?" → AI → 진로·부업 → 사주 → 재물운 → 자소서 → 면접 AI
```

## 플랫폼 운영 12대 원칙

1. **회원·결제·구독 하나** — 서비스마다 따로 만들지 말 것
2. **AI는 하나** — 어디서 질문해도 전체 서비스로 연결
3. **광고보다 SEO 먼저** — 검색·입소문·쇼츠로 무료 유입 먼저
4. **브랜드는 점운 하나** — 점운 꿈, 점운 자소서, 점운 육아
5. **AI 답변 > ChatGPT** — 더 편하고, 더 보기 쉽고, 더 자세하게
6. **매일 콘텐츠** — 꾸준히 쌓이는 DB가 장기 경쟁력
7. **기능보다 연결** — 서비스끼리 자연스럽게 이어지게 설계
8. **기능 하나씩** — 점운 → 꿈 → 자소서 → 진로 → 육아 순서로
9. **매출보다 재방문율** — DAU, 7일·30일 재방문율, 구독 전환율 KPI
10. **커뮤니티** — 질문·답변·후기·공유 공간 → 체류시간·검색 유입
11. **거짓 광고 금지** — "100% 보장", "무조건 합격" 표현 사용 금지
12. **결과 + 행동 가이드** — "운이 좋다"로 끝나지 말고 "오늘 이렇게 하세요"까지
