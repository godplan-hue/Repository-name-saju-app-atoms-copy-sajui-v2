# 02. 꿈해몽

> 상태: 🔲 기획 중  
> 결정 사항: 점운과 별도 도메인으로 분리 운영 (점운 브랜드 안 붙임)

---

## 기본 방향

- 꿈해몽 전문 사이트로 독립 운영
- 사주 연계 차별화: "꿈 + 사주로 오늘의 운세 함께 보기"
- 앱 경쟁보다 **웹 SEO** 공략 (앱 강자들이 웹 SEO는 약함)
- 템플릿 기반 — 실시간 AI 없이 꿈 키워드별 해몽 DB 활용

## 경쟁사 분석 (2026-07-05 조사)

### 시장 규모 추정 (비상장사 공시 없음 — 업계 추정치)

| 순위 | 앱 | 다운로드(추정) | MAU 추정 | 예상 연매출 |
|------|-----|------------|---------|-----------|
| 1 | 점신 (꿈해몽 포함) | 1,000만+ | 150~300만 | **80~200억 원** |
| 2 | 꿈해몽 (윈드림) | 100만+ | 20~40만 | **5~20억 원** |
| 3 | 꿈속 (AI 꿈해몽) | 10만+ | 3~10만 | **1~5억 원** |
| 4 | 기타 AI 꿈해몽 앱들 | 1~10만 | 1~5만 | **5천만~3억 원** |

> 공개 재무자료 없음. 다운로드·광고·인앱결제 모델 기반 추정.

### 각 경쟁사 상세

**1위: 점신 (꿈해몽 메뉴 포함)**
- 2025년 2월 기준 월 이용자 **95만 명** (운세 앱 전체 1위)
- 꿈해몽을 메인 탭으로 포함 — 단독 서비스는 아님

**2위: 꿈해몽 앱 (윈드림 / 인튜이션랩)**
- 서비스 기간: **15년 이상**
- 이용자: **85만 명+**, 데이터: **2만 개+**
- AI 해몽 기능 보유 / 광고 중심 수익 모델
- 플레이스토어: dream.main

**3위: 꿈속 (꿈해몽 AI해몽 꿈일기장)**
- AI 해몽 + 꿈일기 특화
- 플레이스토어: kr.nalab.dream

### 전략적 시사점
- **앱 시장**: 15년 된 강자 존재 → 앱 직접 경쟁은 불리
- **웹 SEO**: 꿈 키워드별 랜딩페이지 → 앱들이 잘 안 함 → **선점 가능**
- **핵심 인사이트**: 꿈해몽은 **트래픽 유입 채널** — 실제 매출은 사주·AI 상담·구독에서 발생
- **차별점**: 꿈 검색 → 사주 분석까지 자연스럽게 연결 (없는 조합)
- **목표 시장**: 꿈해몽만 → 상위권 5~20억 / 사주+운세+꿈해몽 통합 → 50~200억 이상

### 결론
꿈해몽을 별도 독립 서비스로 운영하되, **SEO 트래픽 유입 → 점운 사주 분석 유료 연계** 구조가 최적.

## 콘텐츠 계획

- 메인 페이지: 꿈 검색 + 오늘의 꿈 해몽 + 사주 연계 CTA
- 개별 꿈 페이지 **30개+** (위 키워드별)
- 각 페이지 하단: "꿈과 사주를 함께 보면 더 정확해요 → 점운에서 사주 보기"
