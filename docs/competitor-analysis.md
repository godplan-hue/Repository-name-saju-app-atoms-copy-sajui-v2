## 2. 사주아이 (saju-kid.com) 분석

### 브랜드 포지셔닝
- 990원 사주로 대중화
- 고양이 캐릭터 → 귀엽고 친근한 브랜드 (점운과 동일 방향)
- "즉시 소문 듣고 오셨나요? 20만원씩 내고 봤던 사주보다 더 세하고 정확해요"

### 주요 상품
| 상품 | 특징 |
|------|------|
| 990원 사주 | 타고난 성격, 재물운, 직업운까지 상세 분석 |
| 궁합 해설 | 꼭 커플만 궁합 보단 법 있나요? 자유롭게 조합 |
| 대운 해설 | 몸 들어올대 느껴지는 방법 일러드림 |
| 택일 | 좋은 날을 골라드려요 |
| 연도별 운세 | 특정 연도의 운세가 궁금하다면? (일부무료) |
| 오늘의 무료운세 | 만날하리 따뜻한 일일운세 (무료) |
| 사주 상담 | 더 궁금한 점이 있다면? (1냥) |

### 사주아이 SEO 해시태그 (공식 등록)
```
#사주 #사주아이 #990사주아이 #사주아이990 #990사주 #990원사주
#사주아이사이트 #사주아이이990 #공합 #신년운세 #오늘의운세
#운세 #무료운세 #택일 #대운 #만세력 #사주상담
#연도별운세 #사주추천
```

### 점운이 배워야 할 포인트
1. **990원 포지셔닝**: "20만원 사주보다 더 정확"한 카피
2. **무료 일일운세로 매일 유입** → 유료 전환 퍼널
3. **대운·택일 무료 미리보기** → 유료 업셀링
4. **사주 상담 채널** (1:1 유료 상담 — 점운 미구현)
