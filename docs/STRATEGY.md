## 4. 바이럴 / 후기 유도 전략

### 목표
사주아이처럼 맘카페·카카오톡을 통해 유기적 입소문 확산

### 구현 예정 기능 (아직 미구현)

#### A. 구매 완료 후기 팝업 — `app/payment-complete/page.tsx`
- 결제 완료 직후 팝업 표시
- 메시지: "후기 남겨주시면 다음 분석 할인권 드려요 🎁"
- 미리 작성된 카페 후기 텍스트 (클립보드 복사 버튼)
- 복사 완료 시 → 할인코드 자동 표시 (예: REVIEW20)
- 사용자 흐름: 팝업 열림 → 텍스트 복사 → 코드 수령 → 카페에 붙여넣기

**미리 작성된 카페 후기 예시:**
```
🔮 990원에 사주 봤는데 진짜 소름...

점운이라는 AI 사주앱에서 봤는데 생각보다 너무 잘 맞아서 공유해요
저 연애운 봤는데 올해 만남이 생긴다고 했거든요? 근데 진짜로 있었어요 😮

무료로 오늘의 운세도 볼 수 있고
재물운/연애운/건강운 등 유료로 더 자세히 볼 수 있어요

jeomun.com 접속하면 바로 됩니다 🐱
```

#### B. 결과지 하단 카카오 공유 버튼 (이미 구현됨)
- 공유하면 친구가 유입 → 바이럴 루프
- 추가 검토: 공유 시 할인코드 자동 포함

#### C. 파트너 인센티브 시스템
- 파트너 대시보드에 배너: "카페에 후기 올려주시면 수수료 추가 지급"
- 파트너들이 자기 카페/블로그에 홍보 → 수수료 인상으로 동기부여

#### D. 인플루언서 무료 체험 제공
- 틱톡/인스타 인플루언서에게 VIP 무료 체험 제공
- 리뷰 영상 하나가 수십만 뷰 가능 (사주 카테고리 바이럴 잘 됨)

## 5. 맘카페 바이럴 전략

### 왜 맘카페인가?
- 사주아이 성공 비결 = 맘카페 입소문
- 30~40대 여성 → 가장 구매력 높은 층
- 카페 글 → 신뢰도 높음 (광고처럼 안 보임)

### 실행 방법
1. **직접 후기 작성**: 실제 구매 고객이 후기 올리게 유도 (할인코드 증정)
2. **파트너 활용**: 파트너가 자기 카페에 홍보하게 (수수료 인상)
3. **직접 운영**: 맘카페에 일주일에 1~2개 후기성 글 작성

### 핵심: 자연스러운 후기처럼 보여야 함
- "사주앱 어디 좋아요?" 글에 답글로 추천
- "990원밖에 안 해서 한번 해봤는데 소름..." 형식
- 광고처럼 보이면 역효과

## 6. 꿈해몽 분리 도메인 전략

### 결정 사항 (2026-07-04)
- 꿈해몽을 점운 브랜드와 분리하여 **별도 도메인**으로 운영
- 이유: 점신이 꿈해몽을 메인 메뉴로 운영 중 → 독립 사이트가 SEO에 더 유리
- 도메인 후보: haemong.com / kkumhaemong.com / haemong.kr

### 꿈해몽 사이트 구조 (미착수)
- 메인 페이지: 대표 꿈 해몽 + 사주 연계
- 개별 꿈 페이지 30개+: 뱀꿈, 돼지꿈, 임신꿈, 물꿈, 이가빠지는꿈 등
- 각 꿈 페이지에서 점운 링크 (교차 유입)
- 독립 브랜드 — 점운 이름 안 붙임

### 점운 ↔ 꿈해몽 연결
- 점운 메인에 꿈해몽 도메인 링크 추가 가능
- 꿈해몽 메인에서 "정밀 사주 분석" → jeomun.com 링크

## 9. Firebase Blaze 전환 필수 안내

> **앱 정식 오픈 전 반드시 해야 함**

- 현재 Firebase Spark(무료) 플랜 → 트래픽 늘면 한도 초과 오류 발생
- Blaze(종량제) 전환: Firebase 콘솔 → Spark → Upgrade → Blaze
- 비용: 사용량 기준, 초반엔 거의 무료 수준
- 잊지 않도록 Claude가 주기적으로 리마인드
